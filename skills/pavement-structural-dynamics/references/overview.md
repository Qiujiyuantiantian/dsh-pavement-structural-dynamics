# 全书判断：章名与内容对照


> 2026-10-23。依据：ch2–ch8 的阶段 0 报告与四章验证结果。
> **这份文件的作用**：它是最终 SKILL.md 的边界声明底稿。每一条都有实测计数或复算支撑。

---

## 一、一句话结论

**这本书的价值不在"算"，在"判"。** 七章里没有一章能给出"照做即得数"的完整计算链；
能给的是**判据、边界、审计清单，以及一长串"抄走就错"的地方**。

这不是贬低。对一个要模型、要审报告、要判数据可不可用的读者，这些比公式更有用——
**但前提是有人在卡里把话说清楚，而不是把式子抄过去**。

## 三、全书反复出现的六类缺陷（每类都有多章实例）

### 1. 章名承诺了它没写的东西

ch2 无路面、ch5 无接缝脱空、ch6 无反演参数、ch7 无寿命。
**规律**：章名描述的是"这个领域应该有什么"，不是"这章写了什么"。

### 2. 表与正文打架，且表内自相矛盾

| 实例 | 问题 |
|---|---|
| ch3 表 3-2 | η 列装的是对数减缩 $\Lambda$，**列名错**（6/7 行满足 $\zeta=\eta/\sqrt{(2\pi)^2+\eta^2}$） |
| ch3 表 3-5 | 「20℃」组模量**高于** 15℃ 组（33.3 vs 18.1），与"升温降模量"相反；应为 −10℃ |
| ch6 表 6-5 | $f=50$ 行应 111.4 而印 133.5；**500 Hz 行的 174.5 是 750 Hz 的值**，而 750 行整行空 |
| ch6 表 6-6 | 第 2 组**大小关系反转**（相速法反超 15%），编号列与试件列不同步 |
| ch8 表 8-16 | 位移 0.625 来自 ζ=0.1、应力 0.140 来自 ζ=0.01，**两行不同源** |

### 3. 常数/系数多版本并存

| 实例 | 版本 |
|---|---|
| ch3 参考温度 | 40℃ 与 20℃ 并存（**20℃ 才对**：复算 4.522/−3.259/−5.276 与正文 0.0% 吻合） |
| ch6 $c_R/c_0$ | **0.57 / 0.587 / 0.575** 三版，0.57 不在表 6-1 六档内（≈μ0.34） |
| ch6 $\kappa_0$ 分母 | $1+\mu$ 与 $1-\mu$ 两版（取 6-16，弃 6-49——后者给表面波快于纵波） |
| ch8 频率单位 | **rad/s 而非 Hz**，正文未写，靠 8-11 复算反证 |

### 4. 量纲错误（最阴险，因为它不改公式形状）

| 实例 | 问题 |
|---|---|
| ch4 $G=\rho c_R$ | 左边 Pa、右边 kg/(m²·s)，**差一个 m/s**（应为 $\rho c^2$） |
| ch6 6-53 | $E$ 用 MPa、$\rho$ 用 g/cm³，**差 $\sqrt{1000}\approx31.6$ 倍** |
| ch5 5-5 | 剪切对角元缺 $(1-2\mu)$，μ=0.3 时差 **2.5 倍**（不是 3.37） |
| ch5 $K_v/K_\mu$ | 与 5-37 对调，**反算方向整个相反**；唯一能当场抓住的判据是量纲 |

### 5. 编号体系不可信

| 实例 | 问题 |
|---|---|
| ch4 | 206 块里 **32 块无号**，其中 10 块是 4.3 的命门（状态矩阵、基本方程、单元矩阵） |
| ch5 | 应有 64 号实见 63，**缺 5-35**（被切成 6 块无号），**重号 5 处** |
| ch6 | **6-52 缺号**；6.4 FWD 全节**零带号式子** |
| ch7 | **缺 7-26/7-27**（p144→p145 整段消失）、重 7-22、**7-35 有引用无号** |
| ch8 | 重号 2（8-27、8-39）、一号两式 1（8-11） |

### 6. 图无占位，而结论依赖图

| 章 | 情况 |
|---|---|
| ch3 | 23 张图里 **14 张只剩图注**，3 张连图注都没有 |
| ch5 | 10 张图 **0 个占位**；图 5-6「图示方向为正」恰是核对 5-15 符号的依据，而图没了 |
| ch7 | 图 7-26/7-27 是图号，检索"缺号"时会误命中公式号 |

## 五、跨章不可互引的三条（最重要）

这三条如果不写进 SKILL.md，读者一定会把不同章的数拼起来用：

1. **ch3 的 $|E^*|$ ≠ ch6 的反演模量**
   ch3 带频率与温度量；ch6 的去掉了两个依赖、且**全章无温度修正**（"温度"只出现 1 次）。
   → 不能互换、不能互校、**夏冬不可比**。

2. **ch4 的 4 m 底面 ≠ ch5/ch4 的半空间**
   解析侧要求波能一直往下走，数值侧把底面全钉死；两条链在书内没有对照，**也不许在卡里凑成对照**。

3. **ch8 的钢桥面铺装 ≠ ch4 的沥青路面结构**
   支承（钢板 vs 土基）、模量口径（常数 vs 随温频）、控制指标（铺装表面横向拉应力/层间剪应力/裂尖 K vs 弯沉/层底应力）**三样全不同**。

## 六、对最终 skill 的含义

如果照章名做，会得到 7 套"看起来完整、实际不可执行"的东西。
按实测做，得到的是：

- **判据卡**：这套参数能不能进动力模型、这份报告该怎么审、这条链缺哪几件
- **边界卡**：什么时候该停、停在哪一步、缺什么就该说缺
- **禁令卡**：哪些式不能抄、哪些数不能互引

**卡数预计**：ch2 7 + ch3 10 + ch4 10 + ch5 5 + ch6 8 + ch7 ? + ch8 ? ≈ **45–55 张**。
比书 3 的 76 张少，但每张的"停判点"密度更高——因为这本书能算的东西更少。
