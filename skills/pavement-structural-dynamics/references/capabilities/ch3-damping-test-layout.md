## R — 原文论点（转述，非摘录）

布置这一节先把料与件摊开：集料、矿粉、结合料都跟实际铺装用的一致，密级配，公称最大粒径写到 13.2 毫米，油石比取 6.5%；轮碾成型后先在 120℃ 里保温固化四小时，再切。为什么切成这么长这么粗？作者给的理由是采集信号的信噪比——太短太细采不干净，与梁理论适用与否无关。温度靠一台环境箱，控温偏差压在 0.5℃ 以内；支承用两套专用夹具分别做出悬臂与简支，简支一侧再加一条几何约束：跨距相对梁高要超过十倍。沿梁长布四只传感器，用小锤敲，信号进动态采集系统。再往后他排了两组试验：一组是激励条件对照，锤头换成橡胶、塑料、铝、铁四种材质，施加方式分单次脉冲与连续脉冲；另一组是温度试验，四个温度档各做一遍。结果落到一张八行的表上（四个温度、两种支承），50℃ 简支那格空着，作者只说高温下料变软、简支时梁挠下去，于是没有取这组数。表后三条小结：温度上去，基频下来、阻尼上去；同一温度两种支承的阻尼「相差很小」，考虑到夹具简化与理论推导的系统误差，可视为近似相等，并把它当作材料自身的取值；由已有的 η 与 ζ 还可以反算对数减缩与比例系数这类导出量。

（见 p45–46，§3.1.1.2；表与小结见 p48–49）

> **出处**：p46（材料、油石比、成型与固化、尺寸理由、温控、夹具、跨高比、四传感器、四种锤头、四个温度）＋ p48（八行表、50℃ 简支空格、三条小结）＋ p49（小结续）。

## I — 判据骨架

### I.1 布置清单：哪些是「可搬的几何与工艺」，哪些只是「这一批的做法」

| 项 | 本章给的 | 性质 | 搬走时要带的条件 |
|---|---|---|---|
| 试件 | 方截面长梁，截面 50 毫米见方，长 600 毫米 | 可搬（几何） | 尺寸理由是信噪比，不是力学充分条件 |
| 成型 | 轮碾法；120℃ 保温 4 小时后切割 | 可搬（工艺） | 固化温度与时长是这一种料的两段热历史，换料要重定 |
| 简支几何 | 跨距／梁高 > 10 | 可搬（必要条件，**非充分**） | 只压住剪切一项；支座转动自由与夹持段柔度它管不着 |
| 支承实现 | 两套专用夹具分别模拟悬臂与简支 | 可搬（形式） | 夹持段长度全章未给 |
| 温度控制 | 环境箱，偏差 ≤ 0.5℃ | 可搬（指标） | 温度档本身有四套写法（见 B·H1-2） |
| 量测 | 沿梁长四只传感器 + 小锤 + 动态采集 | 可搬（布置） | 四个通道的分工本章只提到「两个采集、一个正弦对照、一个噪声」 |
| 激励对照 | 四种锤头材质 × 两种施加方式 | **只搬设计，不搬结论** | 对比数据 0 条（`ce-A02` 的同源问题） |
| 温度档 | 方案 −20／10／30／50；结果表 5／10／30／50 | 不可原样搬 | 实测首行疑为 −5；−20℃ 无数据 |

**判据**：一次阻尼试验要能读数，至少要有四件——几何（截面、长度、跨距或悬臂自由长度）、温度（每档一个实测值）、支承（哪一套夹具）、频率（该行基频）。四件缺一，表里的 ζ 就不能脱离这批试件使用。

### I.2 排产：八格只能得七格

| | 简支 | 悬臂 |
|---|---|---|
| 低温档 | 可做 | 可做 |
| 中温档 | 可做 | 可做 |
| 高温档（料已变软） | **做不出来**：梁在自重下挠曲，线性基频与小转动假设一起失效 | 可做 |

这不是「漏做」，而是「做不了」。本章没有给「高到多少算做不了」的门槛（例如跨中挠度上限、或基频下降到的下限），所以这一格只能按现象记，不能按温度数值记。

### I.3 结果读取：三条小结与它们各自的支撑强度

| 小结 | 本章的说法 | 支撑强度 | 怎么读 |
|---|---|---|---|
| ① 温度升 → 基频降、阻尼升 | 由四档温度看出来 | 强（七行数据同向） | 可引趋势；但温度与频率共线，「频率降也导致阻尼升」在同一批数据上等价，拆不开 |
| ② 两支承阻尼「相差很小」，可并为材料常数 | 同温度下两支承对照 | **弱**：逐温度差约 4% / 22% / 14%，10℃ 那一档已不算小；且用「结果接近」反证「夹具简化没问题」，是用结论验前提 | 只能读「同一温度下两支承同量级」，不能读「支承无关」 |
| ③ 由 η 与 ζ 可反算对数减缩与比例系数 | 换算链的逆用 | 中：链本身自洽，但 η 列名错，须先改名 | 反算前先把那列认成 Λ |

### I.4 理论对照只能当量级（与卡 10 分工）

本卡只用到一条：拿理论基频与实测比，可以判「测到的是不是这根梁、这一阶」。**但**：理论表只做了两个温度、且两种支承都代同一个 600 毫米长度（`ce-B20`），四个数（96.4 / 68.2 / 34.4 / 24.3 Hz）的来历见卡 10。本卡不重复那套数，只提醒一句——**理论值整体低于实测**这件事本章没有交代，不能反过来当「夹具没问题」的证据。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章唯一那组阻尼实测已进 I 段登记，不作演练答案。下列四段给字段、出判断，**不给任何算出数**。

**演练一（排产，正常路径）**
输入：目标材料为一种热固性沥青混合料；设备为环境箱 + 两套夹具 + 小锤 + 四通道采集；自定低温、中温、高温三档。
→ 判：三档 × 两支承共六格；高温档的简支一格预计做不出来（料软、梁挠），须事先留出这一格。
→ 输出：一张排产表 + 「哪一格预计空着、为什么空」的说明 + 每格必须记录的四个量（温度、支承、该行基频、ζ）。
→ 不输出：任何频率或阻尼数值。

**演练二（否决：跨高比当充分条件）**
输入：报告只写「跨高比满足大于十」，不写实际跨距、不写悬臂夹持长度。
→ 判：跨高比只压住剪切变形一项；支座转动是否自由、夹持段柔度多大，全都没有交代。
→ 输出：**停**——要求补实际跨距与悬臂自由长度；补不出则结果只能当量级。

**演练三（否决：拿「两支承差不多」当夹具合格的证据）**
输入：报告写「两种支承测出的阻尼接近，说明简支与悬臂都做对了」。
→ 判：这是用结果去验前提；中间没有独立的支座标定（例如换跨距看反算量是否稳定）。
→ 输出：**出局**——「接近」只能说明两套夹具给出的量同量级，不能说明夹具做对了。

**演练四（停：把空格当缺数据）**
输入：一张四温度 × 两支承的表，某一格空白，要求「补齐后做温度趋势」。
→ 判：那一格是高温 + 简支，做不出来；本章也没有「高到多少算做不出来」的门槛，无从补。
→ 输出：**停**——空格保留并注明「未取」，趋势只能按七格写。

**预期输出表**：`格（温度×支承）｜可做/做不出｜记录的四个量是否齐｜能不能进趋势｜停在哪一步`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不排产）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 试件几何（截面、长度） | 数值对 | 必需 | 缺 → 停：跨高比与频率都无从核 |
| 简支实际跨距 / 悬臂自由长度 | 数值 | 必需 | 缺 → 结论只能到「几何未定，量级参考」 |
| 支承实现方式（夹具类型） | 文本 | 必需 | 缺 → 停：支承不同，频率与阻尼都不可比 |
| 温度档与控温偏差 | 数列＋数值 | 必需 | 缺 → 停：阻尼值的标签无从确定 |
| 每档实测基频 | 数列 | 必需 | 缺 → 只有 ζ 没有频率，数不可用 |
| 每档阻尼比（及其取峰口径） | 数列＋枚举 | 必需 | 缺 → 只能交付布置，不交付结果 |
| 激励对照（锤头材质／施加方式） | 列表 | 建议 | 缺 → 不写「与激励无关」这类结论 |
| 试件数量与重复次数 | 数值 | 建议 | 缺 → 只能给单件结果，不给离散性 |

**步骤**

1. **定几何**：截面与长度按信噪比选，同时写清「简支跨距」「悬臂自由长度」两个不同的数——不要用一个梁总长代两处。
2. **定跨高比**：简支一侧取跨距／梁高 > 10，并注明这是必要条件，不是充分条件。
3. **定温度档**：先写方案温度集，再核对结果表是否同名同号；两处不一致时以结果表为准并标出差异。
4. **排产**：列出温度 × 支承的全矩阵，标出预计做不出来的格子（高温 + 简支）。
5. **布传感器与激励**：沿梁长四只；小锤材质与施加方式若要作对照变量，每组单独成行，不许合并。
6. **采集与处理**：走卡 1 的换算链（峰比 → Λ → ζ），并把列名反查一并做掉。
7. **读结果**：按 I.3 三条分别标注支撑强度；「两支承差不多」只能读到同量级。
8. **写「不推出的项」**：阻尼与频率的关系、阻尼与激励方式无关、夹具合格。

**停判点**

1. 只给跨高比、不给实际跨距与夹持长度 → 停（`ce-A03` 方向）。
2. 要求把 50℃ 简支空格补成数 → 停（那一格做不出来，`ce-A04`）。
3. 要求由「两支承接近」推出夹具合格 → 停（用结论验前提）。
4. 要求用四种锤头的对照证明「阻尼与激励无关」 → 停（本章 0 条对比数据）。
5. 要求把理论基频当「已验证」 → 停，转卡 10 看四个数的来历。

**输出契约**——字段固定：

`格（温度×支承）｜可做/做不出｜简支跨距｜悬臂自由长度｜该行频率｜Λ｜ζ｜三条件是否齐｜三条小结的支撑强度｜不推出的项｜依据页`

表下固定三行：
- **公式状态**：全部 `〔公式待核〕`。
- **数值状态**：全部为转录值，未见原图；空格=未取。
- **依据页**：p45–46、p47–49。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把 50℃ 简支那一格填成 0 或「缺测待补」**：它是「做不出来」，不是「没做」（`ce-A04`）。填 0 会让温度趋势凭空多一个点。
2. **用一个梁总长同时代简支与悬臂**：理论表就是这么干的（两边都用 600 毫米），而实际简支要两端余量、悬臂要夹持段；基频与长度的平方成反比，长度差一成频率差两成（`ce-B20`）。凡引那四个理论频率，必须写「两支承都按全长算，实际几何未给」。
3. **写「简支约为悬臂的 2.8 倍」当通例**：只在 5℃ 那一行成立，逐行 2.81 / 2.63 / 2.49；同页还并存 2.77 与 2.787 两个比值（`ce-B03`、`g07`）。引用须指明取哪一个、哪一行。
4. **拿四种锤头的对照当「阻尼与激励无关」的证据**：设计给了、数据 0 条，结论只落在「几乎没区别」一句（`ce-A02` 同源）。可以说「作者这样设计过」，不能说「已证明无关」。
5. **把「两支承接近」当夹具合格**：逐温度差 4% / 22% / 14%，10℃ 那一档已不算小；而论证方向是用结论验前提。
6. **温度标签照抄**：见卡 1 的 B·H1-2，本卡不再重复，但同样适用。

**H2 — 用前必须声明**

1. **跨距与自由长度两个数**：一个梁总长不够用。
2. **温度档的来源**：方案集与结果表集可能不同名，须写清以哪个为准。
3. **空格的含义**：哪一格空着、为什么空、空着之后趋势按几格写。
4. **激励对照的数据状态**：有设计无数据，须标「未经数据支撑」。
5. **波形与曲线的可读性**：本章波形图只剩图注，凡「曲线看起来一致」一类判断只能定性。
6. **温度轴参考点**：只写 20℃（见卡头第 3 条）。

**本章三条覆盖缺口（对本卡的影响）**

| 缺口 | 对本卡 |
|---|---|
| 四种锤头的对比数据（0 条） | 本卡的「激励对照」只能交付设计，交付不了结论 |
| 「可忽略」的门槛（本节与围压一节都没有） | 本卡无法判「差多少算差不多」，只能照抄作者的「相差很小」并标为未量化 |
| 波形图无图片占位（3-4 至 3-7） | 单频与否、峰高稳定性都无法复核 |

**不要用本卡做的事**：给阻尼的设计取值（转卡 1）、用理论基频证明夹具合格（转卡 10）、把 50℃ 简支补成数、由锤头对照下「与激励无关」的结论。

**已知硬伤（不影响判据的，列此备查）**：方案写 −20℃ 而全章无该温度数据；理论表只有两行温度；小结②内部差值与「相差很小」不匹配；表 3-2 表头 ξ 与正文 ζ 并存。
