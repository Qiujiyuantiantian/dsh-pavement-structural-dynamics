## R — 原文论点（转述，非摘录）

作者把板的理论分成两套。薄的那套只留一个未知量——挠度；它假定变形后中面的法线仍然与中面垂直，转角不是独立量，挠度要有一阶导连续。代价写在后面：横向剪切与转动惯量被丢掉，板越厚、边长越短，丢掉的部分越不能忽略，作者因此提醒，对厚板做自由振动会把频率算高。厚的那套并列两家，共同点是把转角解放出来，未知量从一变成三，法线仍是直线但不再要求垂直，剪切应变保留。两套之间只有一句定性话，没有厚度与边长之比的阈值，也没有算例。内力那一节把五个量写成挠度的导数组合：两个弯矩与一个扭矩取二阶导，两个剪力在挠度的拉普拉斯量上再取一次方向导。到了正应力，作者给了不止一个版本，符号彼此打架。

（见 p97–100，§5.1.2–§5.1.3.1）

## I — 判据骨架

### I.1 薄与厚的分野

| 项 | 薄板（Kirchhoff 类） | 厚板（Reissner／Mindlin 类） |
|---|---|---|
| 未知量个数 | 1（挠度） | 3（挠度 ＋ 两个转角） |
| 转角是否独立 | 不是，由挠度的一阶导决定 | 是，与挠度脱钩 |
| 横向剪切 | 丢掉 | 保留 |
| 转动惯量 | 丢掉 | 保留 |
| 已知代价 | 对厚板高估频率 | 自由度从 1 变 3，矩阵规模上去 |
| 本章的切换判据 | 只有一句定性话：厚度与边长可比时误差不能略去 | 同左，无阈值 |

### I.2 选型三问

1. **这套分析里转角是独立未知量吗？** 是 → 厚板；否 → 薄板。这一条看的是未知量表，不看名字。
2. **厚度相对边长还是不是小量？** 只能定性判；本章没有阈值，所以这条只能用来判断「作者有没有意识到」。
3. **要不要频率、振动？** 要 → 记住薄板会把频率算高；这是方向判断，不是误差量。

### I.3 内力链（5-11）

| 步骤 | 输入 | 判据 | 输出 |
|---|---|---|---|
| 1 | 挠度场 | 两个弯矩由一个方向的二阶导与另一个方向的二阶导按泊松比组合 | 两个弯矩 |
| 2 | 挠度场 | 扭矩取两个方向的一阶导之积（混合二阶导） | 扭矩 |
| 3 | 挠度场 | 先取挠度的拉普拉斯量，再对两个方向各求一次方向导 | 两个剪力 |
| 4 | 板厚与材料 | 抗弯刚度按模量乘厚度三次方、再除泊松比修正 | 抗弯刚度（板厚须另给） |

> 5-11 与前面两个式子自洽（弯矩由应力沿厚度积分、剪力由弯矩再求导），是全章少数可直接编码的块。图 5-6 只剩图注，正负方向不可核（`g26`），这个前提必须随卡带走。

### I.4 应力为什么拿不到

| 版本 | 状态 | 后果 |
|---|---|---|
| 5-32a | 前头带负号 | 与 5-32b 反号 |
| 5-32b | 同一形状、前头带正号 | 同一层纤维不可能一压一拉 |
| p104 长式 | 又改成另一个泊松比组合，且被切成多块 | 第三个版本 |
| 5-36 | 用应力的二阶导去定义应力 | 量纲不闭合，一个系数全章无定义 |

**能交付的**：弯矩、扭矩、剪力五个量。
**不能交付的**：可信的正应力。要算应力，第一步必须先自己定死一个符号版本（以受压为负自校），第二步声明章内无可裁决的依据。

### I.5 本章明确拿不到的东西

- 板厚、模量、泊松比、密度的取值：0；抗弯刚度永远是待定常数。
- 厚度与边长之比的阈值：0。
- 正应力的唯一版本：0（三个版本并存）。
- 图 5-6 的正负方向：图只剩图注，不可核。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章 0 个算例、0 个频率、0 个板厚；下面四段给「一套板的分析」或「一个诉求」，输出「选哪套／走到哪一步／停在哪」，**不出任何数值**。

**演练一（正常路径：判薄厚）**
输入：别人交来一套板的分析，说每节点三个自由度、转角单列。
→ 判：转角是独立未知量 → 厚板；若对方文字里仍叫「薄板」，则以未知量表为准。
→ 输出：厚板 ＋ 未知量三个 ＋ 代价（自由度上去）＋ 须声明「本章不提供厚度比阈值」。
→ 不输出：频率、挠度或任何量值。

**演练二（停：要板底弯拉应力）**
输入：「按这套理论把板底弯拉应力算出来」。
→ 判：内力链可走；应力链有三个符号版本，唯一能给方向的图只剩图注。
→ 输出：**停**——先交付弯矩、扭矩、剪力；应力只写「须先自定符号版本，本章不裁决」。
→ 不输出：任何应力值或应力比。

**演练三（判方向：薄板算频率）**
输入：「薄板算出来的频率能不能直接用」。
→ 判：薄板丢掉横向剪切与转动惯量，对厚板会高估频率。
→ 输出：只能给方向（偏高），不能给幅度（无阈值、无算例）。
→ 不输出：任何频率修正系数。

**演练四（停：选厚板后要单元）**
输入：「既然选厚板，就用本章的四节点单元装配」。
→ 判：5-38 的形函数四个角点代入全为 0（应为 1），单位分解也不成立；照抄得全零刚度阵。
→ 输出：**停**——单元须自写；装配路线见卡 4 的 B 段。
→ 不输出：任何单元矩阵。

**预期输出表**：`未知量几个｜薄还是厚｜内力能不能出｜应力停在哪｜差什么｜依据页`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 未知量表（几个未知量、转角是否单列） | 表 | 必需 | 缺 → 先问；这是薄厚的唯一硬指标 |
| 板厚与边长（只为判「是否还算小量」，不取值） | 二元组 | 必需 | 缺 → 只能判「作者有没有意识到」 |
| 要的输出（内力／应力／频率） | 枚举 | 必需 | 缺 → 先问；要应力 → 走停判点 2 |
| 挠度场与抗弯刚度 | 场＋标量 | 内力类必需 | 缺 → 内力链走不了；刚度须含板厚，板厚章外补 |
| 符号约定（受压为负？） | 布尔 | 应力类必需 | 缺 → 按「未定」处理，停 |
| 是否要振动、频率 | 布尔 | 条件必需 | 为真 → 只给方向，不给幅度 |

**步骤**

1. **认未知量**：先看未知量个数与转角是否独立，定薄厚；名字不作数。
2. **判小量**：厚度相对边长是否还算小量，只能定性；写明「本章无阈值」。
3. **走内力链**：按 I.3 四步，先要挠度场，再要抗弯刚度（板厚须另给）。
4. **查自洽**：弯矩由应力沿厚度积分、剪力由弯矩求导——这两条与 5-11 对得上才继续。
5. **遇应力即停**：要正应力，先要求对方定死一个符号版本，并声明本章不裁决。
6. **查图**：凡引内力正负方向，必须声明图 5-6 只剩图注、方向不可核。
7. **出结论**：一套理论 ＋ 未知量个数 ＋ 能出的量 ＋ 不能出的量 ＋ 缺口。

**停判点**

1. 给厚度比阈值 → 停（0）。
2. 给可信的板底正应力 → 停（三个版本）。
3. 给频率修正幅度 → 停（只有方向）。
4. 照抄 5-38 装配单元 → 停（四角全零）。
5. 要板厚、模量、泊松比取值 → 停（0，`p13`）。

**输出契约**——字段固定：

`未知量｜薄还是厚｜内力出的量｜应力状态｜符号版本｜缺口｜依据页`

表下固定三行：
- **公式状态**：5-11 可用但〔公式待核〕；5-5、5-32、5-36、5-38 不带病不用。
- **数值状态**：本章 0 个板厚／模量／频率；任何数值须注明章外出处。
- **依据页**：p97–p100。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **照抄 5-38 写四节点板单元**：形函数在四个角点代入全为 0（应为 1），四点之和不等于 1，单位分解不成立；**照抄得全零刚度阵**——代码能跑，结果一片零（`B18`、`g28`）。选厚板必须先自写插值。
2. **用 5-5 建弹性矩阵**：第 4、5 个剪切对角元缺 $(1-2\mu)$，第 6 个是对的。错值与对值之比恒为 $1/(1-2\mu)$，$\mu=0.3$ 时是 **2.5 倍**——**不是 3.37 倍**（3.37 对应 $\mu\approx0.35$，阶段 0 记错，已按附三勘误改正）。弹性矩阵与 ch2、ch4 是同一个，本卡不建矩阵卡，**指回 ch2**；本章只留一句「剪切对角元有转录问题」（`B20`、`g09`）。
3. **把三个正应力版本当同一套符号**：同一层纤维不可能一压一拉；p104 还是第三版。图 5-6 只剩图注，方向不可核（`B07`、`g26`）。
4. **用 5-36 算另一个正应力**：它拿应力的二阶导去定义应力，量纲不闭合，系数全章无定义；只能改用补负号后的那一版自己算（`B27`）。
5. **抄「转动惯量等于厚度平方除十二」那句**：与另一页的三次方冲突；单位宽度截面的二次矩是三次方那版（`B06`、`g19`）。
6. **把剪切修正因子当已核参数**：它有一个具体取值 $\pi^2/12$，但没说对应何种边条件与振型，有限元那节又不用它；引用它等于替作者背书（`g18`）。
7. **把抗弯刚度当已知**：板厚全章只作符号，刚度永远是待定常数；要算数必须补板厚并注明章外（`g16`）。
8. **把薄板结果用于厚板，或反过来**：只会高估频率，没有阈值；只能判「作者有没有意识到」，判不了「该用哪一个」（`g12`、`g13`）。

**H2 — 用前必须声明**

1. 走的是哪套理论、未知量几个、转角是否独立。
2. 内力可以出，应力不可以出；要应力须先定符号版本。
3. 图 5-6 只剩图注，正负方向不可核。
4. 抗弯刚度里的板厚来自章外。
5. 数值状态：本章 0 个板厚／模量／频率。
6. 与 ch2 的边界：弹性矩阵不在本章建卡；与 ch4 的边界：时间积分归 ch4。

| 缺口 | 对本卡 |
|---|---|
| 厚度比阈值（0） | 判不了「该用哪一个」，只判得了「有没有意识到」 |
