# ch5-foundation-tier-choice — 地基四档怎么选、选错会偏哪边

> 卡类型：selection（四档地基假设的选型与偏差方向）｜主要取材：§5.1.1–§5.1.1.4（p95–97）｜挂靠 verified：`f01`｜边界素材：`A01`、`A02`、`A03`、`A04`、`B05`、`B08`、`B17`、`g03`、`g06`、`g07`、`g08`、`g10`
>
> **卡头必读**
>
> 1. **四档是四种假设，不是四档精度。** 参数从少到多，不等于结果从粗到细；作者自己说，两参数那档的两个系数比连续介质那档的模量与泊松比更难定（`A03`）。
> 2. **本章一个参数值都没有。** 基床系数、剪切参数、压缩模量、层厚、泊松比在原文里全是符号；要取值只能另找出处（`p13`，见卡 5）。
> 3. **偏差方向是作者自陈，不是复算。** 「弹簧档偏小、半空间偏大」只能当方向记账，不能写成百分比——本章没有可比的数。
> 4. **两参数那档在反算处写反了。** 与拉普拉斯算子相乘的必须是「模量×厚度」，这一条用纯量纲就能判死（见 B-4）；照原文那句对调去反算，压缩与剪切会整个互换。
>
> **importance**：high（理由见 `_ch5_report.md` §2）
>
> **公式**：只引四档接触压力的「形式」，一律〔公式待核〕；5-3、5-6、5-45 三处各有硬伤，见 B 段。
>
> **数值**：本章 0 个参数值；本卡 A1 为选型／否决演练，**0 个数值结果**。
>
> **页码**：PDF 页序（p95–p97）；印刷页 = PDF − 9。
>
> **本章缺位**：参数取值（0）、修正系数（0）、算例（0）、非线性本构（只有一个名词）。

## R — 原文论点（转述，非摘录）

作者把土体对板的反力整理成四种线性写法，按「相邻点之间有没有牵连」排成一条链。第一档把土想成一排彼此无关的竖向弹簧，接触压力只与本点挠度成正比；好处是只要一个系数，代价是土里的剪应力被丢掉，荷载不会往基底以外扩散，真实地面在基底外也会下沉这件事被抹平。第二档并联一个黏壶，本意是照顾蠕变；可那条式子里黏性系数直接乘位移、没有对时间求导，量纲对不上，而且此后三套求解路线一次也没再用它。第三档加一层只能承受横向剪切、本身不可压缩的夹层，用两个系数分别管压缩与传剪；把剪切那个系数取零，就退回第一档。第四档把地基当连续介质，给弹性矩阵与点载沉陷解，作者自己承认它把扩散范围与沉降都算大了、也不反映分层。全章没有给出任何一档的参数取值，也没有给出档与档之间的精度比较。

（见 p95–97，§5.1.1–§5.1.1.4）

## I — 判据骨架

### I.1 四档一览

| 档 | 邻点是否互牵 | 系数个数 | 它管什么 | 什么时候够用 | 什么时候出局 |
|---|---|---|---|---|---|
| 独立弹簧 | 不牵 | 1 | 本点压力与本点挠度成正比 | 只看荷载正下方，不要基底外沉降 | 要算板外地面下沉、相邻板格互相影响，或土中剪应力不可忽略（`A01`） |
| 弹簧加黏壶 | 不牵 | 2（多一个黏性） | 本意是蠕变 | 原文这条式子缺时间导数，此后全章弃用 → 实际不可用 | 任何要耗能的场合（`A02`、`B19`） |
| 双参数 | 牵（靠剪切层） | 2 | 一个管压缩，一个管传剪 | 邻点要互牵，但不想上连续介质 | 两个系数给不出出处（`A03`）；反算链本章写反（B-4） |
| 半空间 | 牵（连续介质） | 2（模量、泊松比） | 三维弹性体 | 需要连续介质，且能接受「扩散算大」 | 薄压缩层、上硬下软、要分层 → 出局或转 ch4（`A04`、`g37`） |

### I.2 选型五问（按序问，先否先出局）

1. **要不要算基底以外的沉降、相邻板格会不会互影响？** 要 → 弹簧档出局。
2. **土中剪应力能不能丢？** 不能 → 弹簧档出局，进双参数或半空间。
3. **要不要分层、模量是否随频率变？** 要 → 本章四档都不够，转 ch4（`g37`）。
4. **手头资料是什么？** 只有试验系数 → 只能停在一档并声明；只有压缩模量、泊松比、层厚 → 半空间可直接用，双参数须反算（而反算本章写反，见 B-4）。
5. **要不要算板角、板边荷位？** 要 → 本章几何里没有自由边（`A09`，见卡 5），停。

### I.3 偏差方向记账表

| 档 | 作者自陈的偏差 | 能不能写成数 |
|---|---|---|
| 弹簧 | 邻点牵连被设成零，基底以外沉降被抹掉，远场系统性偏低 | 不能；无修正系数 |
| 半空间 | 扩散范围与沉降都算大，且不反映分层与非均质 | 不能；作者只说存在局限 |
| 双参数 | 参数更难定；定不准时偏差方向取决于参数误差，不取决于模型本身 | 不能 |

> 这张表只记方向。作者没有给任何一档的修正系数，也没有一个可比的算例；把「偏大／偏小」写成百分数就是自造数。

### I.4 单位层：先写单位，再写式（`B17`、`g06`）

- 基床系数被印成 N·L⁻²，而「压力 = 系数 × 位移」要求 N·L⁻³；p96 自己给的压缩系数单位 Pa/m 正是后者，两处对不上。
- 剪切参数被印成 Pa，而它乘的是挠度的二阶导（1/L），要与压缩项相加，必须多一个长度的量纲。
- 5-3 两项的单位差一个长度；谁管压缩、谁管剪切，要按式子认，不能按正文印的单位认。
- **动作**：凡引系数定义，先写单位再写式；单位不闭合就当场标出，不许带着往下算。

### I.5 本章明确拿不到的东西

- 四档各自的参数取值：0。
- 档与档之间的精度比较或修正系数：0。
- 非线性地基的本构：只有名词（`g02`）。
- 分层与模量随频率变：一句话指路，转 ch4（`g37`）。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章 0 个算例、0 张表、0 个参数值；下面四段给「一份资料 + 一个诉求」，输出「走哪一档／停在哪一步」，**不出任何数值**。

**演练一（正常路径：选档）**
输入：一块板搁在土上；手头有压缩模量、泊松比这类资料，另加层厚；诉求是算板下挠度，并明确关心板外地面会不会跟着沉。
→ 判：第一问命中「要算基底外沉降」→ 弹簧档出局；第二问剪应力不能丢 → 剩下双参数与半空间；第三问不要求分层 → 本章可办。
→ 输出：连续介质档（或双参数档，若两个系数有出处）＋系数个数＋偏差方向记账（半空间偏大）。
→ 不输出：任何参数取值，任何「偏大多少」。

**演练二（否决：拿弹簧档算相邻板格）**
输入：诉求是「两块板挨着，算一块对另一块的影响」。
→ 判：弹簧档把邻点牵连设成零（`A01`），这个诉求在模型里没有对应项。
→ 输出：**出局**——换双参数档，或承认这已出了本章能答的范围。
→ 不输出：把影响折算成「很小」的结论。

**演练三（停：要参数取值）**
输入：「基床系数取多少」「剪切参数取多少」。
→ 判：全章 0 个参数值（`p13`）；双参数反算链还在 5-45 处写反（B-4）。
→ 输出：**停**——取值须另找出处；反算须先按量纲把两个参数换回来，而本章给不出形状函数，仍积不出数。
→ 不输出：任何建议值或量级。

**演练四（停：要板角、板边）**
输入：「用这套模型评板角临界荷位」。
→ 判：解域是无限长条带、两侧简支，没有自由边（`A09`）。
→ 输出：**停**——本章只有板中一档荷位；选型到此为止，荷位问题转卡 5。
→ 不输出：任何「板角更不利」的判断。

**预期输出表**：`诉求｜第几问拦住｜走哪档｜系数个数｜偏差方向｜停在哪步`。

**步骤**

1. **定诉求**：写清要算什么（板下挠度、基底外沉降、相邻影响、内力），一句话。
2. **走五问**：按 I.2 顺序逐条问，先否先出局，不跳步、不倒序。
3. **数系数**：记下这一档要几个系数、各自管压缩还是管剪切。
4. **查出处**：每个系数写出来源；无出处即停（`p13`）。
5. **记偏差**：把作者自陈的偏差方向写进结论，禁止写成百分数（I.3）。
6. **写不做的项**：板角、接缝、脱空、分层、耗能——逐项写明「本章不覆盖」。
7. **出档**：一档 ＋ 系数个数 ＋ 偏差方向 ＋ 缺口清单。

1. 要参数取值 → 停（0 个，`p13`）。
2. 要板角、板边荷位 → 停（`A09`）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **要算基底以外沉降、或相邻板格互相影响，却仍用弹簧档**：这一档把邻点牵连设成零，土中剪应力被丢掉，基底以外被当成不沉（`A01`）。
2. **想用黏弹性档算耗能**：全章唯一带黏性系数的式子缺时间导数，量纲不成立；此后三套求解路线都没用它（`A02`、`B19`）。本章对阻尼是零供给。
3. **以为双参数档「参数多所以更准」**：作者自评两个系数比模量与泊松比更难定（`A03`）；参数多只意味着需要更多出处。
4. **照 5-45 之后那一句反算两个地基参数**：与拉普拉斯算子相乘的写成压缩参数、与挠度相乘的写成剪切参数，正好对调。用纯量纲判死——形状函数无量纲，它的一阶导是长度的倒数，故压缩参数的量纲为 Pa·m⁻¹（力／体积，正是基床系数），剪切参数为 Pa·m（模量×厚度）；挠度是 m、挠度的拉普拉斯量是 m⁻¹，所以与拉普拉斯算子相乘的只能是剪切参数，与挠度相乘的只能是压缩参数。原文那样摆，代进去一项是 Pa·m⁻²、另一项是 Pa·m²，没有一项是 Pa，量纲不成立（`B05`）。**附三勘误已改正一处**：反的是 5-45 这一处的摆位，不是行 654 的分工描述——那句分工与定义式、与 5-37、与量纲三者一致。
5. **拿半空间的「偏大」当模型误差忽略过去**：作者自陈扩散范围、沉降量、分层三件事，未给修正系数（`A04`）；这是已知偏差，不是可忽略的噪声。
6. **把点载沉陷的第一个版本拿去建柔度阵**：那个版本少一个距离的倒数，量纲是面积不是长度（`B08`、`g10`）；取带 πr 的那版。
7. **引 k 或 K 不先按节号定身份**：同一物六个名、两处符号相反（`B01`，卡 3）；压缩系数与剪切系数隔九页、无换算句（`g07`），跨节引用必须写明「此处 k 即压缩系数」。
8. **把四档当精度排序、或把「非线性」当第五档**：非线性全章只有名词（`g02`）；四档是并列的假设，不是阶梯。

**H2 — 用前必须声明**

1. 走的是哪一档、几个系数、各自管压缩还是管剪切。
2. 每个系数的出处；无出处就不许往下算。
3. 偏差方向（弹簧偏小、半空间偏大），并声明这是作者自陈、不是复算。
4. 单位口径：本章印出的两个系数单位与式子差一个长度（`B17`）。
5. 本章不覆盖的：接缝、传荷、脱空、板角荷位、分层、耗能。
6. 数值状态：本章 0 个参数值，任何数值都来自章外。
