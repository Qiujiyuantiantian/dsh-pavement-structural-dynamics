# ch7-crack-length-calibers — 缝有多长：三套尺度不许互换

## R — 原文论点（转述，非摘录）

作者先交代一件事：缝长在试验里很难直接量，常规做法是量梁的柔量，再由柔量间接反映缝长。接着他把初始缝长写成一个从试验结果倒推出来的量——用速率式从目标长度往回积，积到某个次数，剩下的就是起点。他随后给它定性：这个起点只是「当量值」，因为微裂缝阶段的实际缝数极多、尺寸远小于它，单缝模型管不到它们汇合的过程。也就是说，**这个数是等效出来的，不是看见的**。

第二套尺度来自那个研究计划。它把疲劳失效一切两段：前段是受拉区累积微断裂、后段是宏观缝往前推；切口定在 7.5 mm，理由是损伤累积到肉眼可辨时缝开始扩展。作者对这个模型给了三条自己的质疑：材料被当成各向同性，而微裂缝的尺度与集料、结合料、孔隙同量级；推导时把缝放在单元中心，预测模型给出的却应是表面缝；参数靠反算得来，有效性要大量试验去证。

第三套尺度出现在有限元那一节。模型里假定基层中存在一条横缝，它贯通整个基层，缝尖顶到面层底面。而表里基层是两层，厚度各是十九厘米与十八厘米——两层的名字都叫基层，正文说「基层厚度变化」时也没说是哪一层。于是「那条缝有多长」在这三处各有一个答案，三者之间没有一处换算过，也没有一句话说明它们指的不是同一件事。（见 p138–140、p140–141、p149–150）

## I — 判据骨架

### I.1 三套标签：定义、来源、用途、能不能互换

| 标签 | 数值 | 怎么来的 | 能干什么 | 不能干什么 |
|---|---|---|---|---|
| **当量初缝** | 3.3、3.6、4.0、5.2、3.8 mm（表 7-2 五个） | 由柔量反算的等效长度 | 同一次试验、同一条件下的料间比较 | 不能进有限元当缝长；不能说它在路面哪个位置 |
| **两段分界** | 7.5 mm | 某个研究计划的规定 | 分段；判「这段算启裂还是算扩展」 | 不能当材料性质；不能与另两套互换 |
| **几何缝深** | 19 cm 或 37 cm（未说明） | 模型里那条贯穿基层的缝 | 只对那一个模型、那一个缝位成立 | 不能代表现场任何一条缝；不能说它属于哪一层 |

> 三者之间**没有换算关系，本章也没给**。任何一处把两个标签并排写在同一句话里的地方，都是错。

### I.2 当量初缝是反算出来的：这条路在本章走不通

| 环节 | 本章状态 | 后果 |
|---|---|---|
| 反算式 | 7-2：下限写成 1，含义未交代；被积项写 $K$ 而 7-1 写 $\Delta K$ | 照它反算，结果依赖积分起点 |
| 反算要的 $K(a)$ | 本章没有 | 积分号里的场强不随缝长变，积不出来 |
| 柔量与缝长的标定 | 只有一句「量柔量间接反映缝长」，没有标定式、没有标定点 | 这一步是黑箱 |
| 初始缺陷的独立性 | 作者把它与 $C$、$n$ 并列为「相同的材料参数」 | 与「它只是当量值」自相矛盾 |

> **输出只剩一句**：本章给到的 3.3–5.2 mm 是**当量值**。凡要问「这个数是怎么算出来的」，本章答不了（`b03`、`f03`）。

### I.3 7.5 mm 是口径不是料性

判据只有一条，问法要精确：**这个 7.5 mm 从哪来、换成另一个阈值后两段的参数要不要重算？**

| 问 | 答 |
|---|---|
| 它是材料性质吗 | 不是。它是某个研究计划为分段而定的切口 |
| 换一个阈值会怎样 | 启裂段与扩展段的样本重新划分，两段参数都要重标定 |
| 启裂段那套算法能用吗 | 不能。7-6 不可用（$\alpha^2$ 连写两次、$\lambda$ 未进式、$C_\alpha$ 与 $\omega$ 无定义） |
| 那这条判据能交付什么 | 只交付「分段这件事存在，且分界是别人定的」——不交付启裂段的算法 |

> 所以本卡在 7.5 mm 这一层**只到阈值**；再往里一步（启裂段怎么算）本章没有可用的载体（`f04`、`ce-a07`、`g03`）。

### I.4 $K\propto\sqrt{a}$：跨标签比较会把 $K$ 拉出近十倍（可复算示例）

同一缝端场强下，两条缝的 $K$ 之比只由缝长之比的平方根决定：

$$\frac{K_1}{K_2}=\sqrt{\frac{a_1}{a_2}}$$

| 从哪一套到哪一套 | 缝长比 | $K$ 之比 |
|---|---|---|
| 当量初缝最小 3.3 mm → 当量初缝最大 5.2 mm（同一套内部） | 1.58 | 1.26 |
| 当量初缝 4.0 mm → 几何缝深 190 mm（按单层基层算） | 47.5 | 6.9 |
| 当量初缝 4.0 mm → 几何缝深 370 mm（按两层基层算） | 92.5 | 9.62 |
| 两段分界 7.5 mm → 几何缝深 370 mm | 49.3 | 7.02 |

**读法（三条）**：

1. **同一套内部**（3.3 对 5.2）差别只有 1.26 倍，可以当同量级处理。
2. **跨套**（毫米级对厘米级）差别 7–10 倍——这不是精度问题，**是换了物理对象**。
3. 上面的比只说明「跨套不可比」，**不能反过来说「几何缝深的 $K$ 是当量初缝的 $K$ 乘 9.62」**：两条缝的缝位、约束、模型都不同，比例法在这里不成立。

### I.5 每个缝长数必须带的四件

1. **标签**：当量初缝／两段分界／几何缝深，三选一。
2. **来源**：反算（哪次试验、什么条件）／别人的规定（哪个计划）／模型设定。
3. **位置**：若为几何缝深，必须写层位（面层底？基层中？贯穿到哪层底？）。
4. **单位与量级**：mm 还是 cm——本章三套里两套是 mm、一套是 cm，混写就错。

### I.6 一份「缝长」表述的审查清单

1. 这句话里的缝长属于哪一套？答不出 → 停。
2. 有没有把当量值当几何尺寸？有 → 立刻改口（`ce-a06`）。
3. 有没有把 7.5 mm 当材料参数？有 → 改口为「别人定的分段切口」。
4. 几何缝深写在层位上了吗？没有 → 补层位，否则 19 与 37 两个数无法区分。
5. 有没有把两套缝长的 $K$ 并排放在一张表里？有 → 删，或加「不可比」。
6. 有没有说「同一条缝」？说了 → 必须给出这三套之间的一次换算，本章没有。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章 0 条缝长实测、0 个缝长—柔量标定点、0 张缝位图；下面四段给「一个数 ＋ 一个诉求」，输出「属于哪一套／能不能进模型／停在哪一步」，**不出任何数值**。

**演练一（把当量值当几何缝长）**
输入：「表里那个初始缝长，帮我画成模型里那条缝。」
→ 判：它是柔量反算的等效长度，作者自己强调只是当量值（I.2）。
→ 输出：**不能进模型**——当量值等效的是刚度损失，不是几何长度；进模型要另给几何缝深与层位。
→ 不输出：一个「换算后的缝长」。

**演练二（三套混在一句话里）**
输入：「初始缝长、分段切口、模型缝深都是同一个 $a$，按最大的那个算就行。」
→ 判：三套并存且从未换算（I.1）；跨套的 $K$ 本来就不该放在一起比（I.4）。
→ 输出：**必须拆成三句**，每句一个标签；不许出现「同一个 $a$」。
→ 不输出：任何跨套的比例。

**演练三（问分段阈值能不能改）**
输入：「我把分段切口改小一点，两段的参数还用原来的行不行？」
→ 判：那个分段切口是口径不是料性；换阈值，两段样本重划、参数要重标定（I.3）。
→ 输出：**不行**——要重标定；且启裂段那套式子在本章不可用，只能换来源。
→ 不输出：新的参数值。

**演练四（停：要一条缝的绝对长度）**
输入：「我就想知道现场那条缝到底几毫米。」
→ 判：本章给不出。当量值不是量出来的，几何缝深是模型设定；现场那一侧只有光纤读数（见卡 6、卡 7），且只到量级。
→ 输出：**停**——本章能给的只有「按哪一套口径、这个数属于谁」。
→ 不输出：任何绝对长度。

**预期输出表**：`数｜属于哪一套｜来源｜层位｜能不能进模型｜能不能互比｜依据页`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 一个缝长数（或一句话里的缝长） | 数值＋单位 | 必需 | 缺 → 无判据可用 |
| 标签（当量／分界／几何） | 枚举 | 必需 | 缺 → 先问，不许替它选 |
| 来源（哪次试验／哪个规定／模型设定） | 文本 | 必需 | 缺 → 只能当「无出处」处理 |
| 若几何：层位 | 文本 | 条件必需 | 缺 → 19 与 37 无法区分，标「层位不明」 |
| 若当量：反算条件（试验／温度／频率） | 文本 | 条件必需 | 缺 → 只可同条件比较 |
| 是否要跨套比较 | 布尔 | 条件必需 | 为真 → 直接判不可比 |
| 是否要进有限元 | 布尔 | 条件必需 | 为真 → 当量值一律拒绝 |

**步骤**

1. **贴标签**：先问这个数属于哪一套，答不出就停。
2. **查来源**：当量 → 哪次试验、什么条件；分界 → 哪个计划；几何 → 哪一层。
3. **查自陈矛盾**：当量初缝被当成材料参数，同时又只是当量值（I.2 第四行）。
4. **算比值（仅在需要说明「跨套不可比」时）**：按 I.4 给缝长比的平方根，并立刻声明这**不是换算系数**。
5. **定用途**：同条件比较 → 可；进模型 → 否；跨套并排 → 否。
6. **写四件**：标签、来源、位置、单位（I.5）。
7. **报缺**：柔量—缝长标定、$K(a)$、启裂段算法，逐项注明本章不覆盖。

**停判点**

1. 要一条缝的绝对长度 → 停（三套都不给绝对值）。
2. 要把当量初缝进有限元 → 停（等效的是刚度损失）。
3. 要把 7.5 mm 当材料参数或改阈值不重标定 → 停。
4. 要跨套比较或换算 → 停（$K$ 差 7–10 倍，且比例法不成立）。
5. 要启裂段的算法 → 停（7-6 不可用）。
6. 要由缝长算次数或年数 → 停（转卡 1：缺 $K(a)$、缺 $N_f$）。

**输出契约**——字段固定：

`数｜标签｜来源｜层位｜可否同条件比较｜可否进模型｜可否跨套｜本章不覆盖｜依据页`

表下固定三行：
- **公式状态**：7-2 待核（下限为 1、被积项与 7-1 不同源）；7-6 不可用。
- **数值状态**：五个 $a_0$ 为转录值；7.5 mm 为他人规定；几何缝深为模型设定且层位未说明。
- **依据页**：p138–141、p149–150。

**反解核对（记录在案）**：三套缝尺度的比值可以当场自证。把当量初缝上界 5.2 mm 与 SHRP 分界
7.5 mm 相除得 $7.5/5.2=1.44$；几何缝深取 19 cm 时，$190/5.2=36.5$、$190/7.5=25.3$，

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把当量初缝当真实缝长。** 它是柔量反算的等效值；毫米级与米级一撞，$K$ 差近十倍（`ce-a06`、`b22`、`g10`）。
2. **把 7.5 mm 当料性、或改了阈值不重标定。** 它是别人为分段定的切口（`p08`、`g03`）。
3. **说「同一条缝」却跨了两套。** 三套并存且从未换算，本章没有任何一条换算关系（`b22`、C16）。
4. **按 7-2 反算 $a_0$。** 下限写成 1、被积项与 7-1 不同源，且反算要的 $K(a)$ 本章没有（`b03`、`f03`）。
5. **以为柔量到缝长有一条现成的标定。** 全章只有一句「量柔量间接反映缝长」，没有式、没有点（`f03`）。
6. **用 7-6 的当量能量式反算参数。** 不可用；且那套模型有三条作者自陈的前提（各向同性、缝在单元中心、参数靠反算），用前必须前置声明（`ce-a07`、`g13`、`f04`）。
7. **引用缝位与缝长时不管图缺。** 模型图与四条参数图的图片元素在本文件里都不存在，只剩图注；凡「从图上读缝位」的结论都要注明「图缺，数取自正文转录」（`b26`）。
8. **几何缝深不写层位。** 表里两个基层都叫基层，19 与 37 无法区分（`b21`、`b20`）。
9. **把三套里的任一套写成「本章的缝长」而不带标签。** 这是本章最隐蔽的一处：三个数都印在同一章里，读起来像一件事。

**H2 — 用前必须声明**

1. 这个数属于三套中的哪一套。
2. 来源：反算／他人规定／模型设定。
3. 若几何：层位与模型总高的取法（土基厚度两说）。
4. 跨套不换算，且本章没有换算关系。
5. 本章不覆盖的：柔量—缝长标定、$K(a)$、启裂段算法、现场绝对缝长。
6. 结论的措辞边界：只到「按某一套口径，这个数属于谁」。

**本章缺口对本卡的影响**

| 缺口 | 对本卡 |
|---|---|
| 三套缝长并存（硬约束 7） | 本卡的主要交付物就是这张标签表 |
| 无 $K(a)$ | 缝长变化的后果算不出来，只能给 $\sqrt{a}$ 的比例 |
| 7-6 不可用 | 启裂段整段落空 |
| 柔量标定缺 | 当量值的来路只剩一句定性 |
| 图缺 | 缝位只能引正文 |

**不要用本卡做的事**：给绝对缝长、给换算系数、把当量值进模型、改分段阈值不重标定、反算 $a_0$、给启裂段参数、算次数。

**已知硬伤（备查）**：7-2 下限为 1 且被积项与 7-1 不同源（p138）；7-6 的 $\alpha^2$ 连写两次、$\lambda$ 未进式、$C_\alpha$ 与 $\omega$ 无定义（p140）；表 7-3 土基 1000 cm 与正文 1 m 冲突（p150）；模型图与四条参数图缺图片元素（p149–150、p153）。
