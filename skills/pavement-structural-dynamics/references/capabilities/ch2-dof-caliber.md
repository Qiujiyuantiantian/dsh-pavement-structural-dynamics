## R — 原文论点（转述，非摘录）

作者从「用多少个独立参数才能把系统的空间位置说清」这个问题切入：先设在 n 个质点、s 个完整约束的条件下，约束方程允许把其中 s 个坐标用剩下的那些表示出来，于是能把位形完全定住的独立参数就是 $N = 3n-s$ 个〔公式待核〕；他把这组独立参数叫广义坐标，并直接宣布：对完整系统而言，广义坐标的个数就是自由度的个数。约束方程的形式被限定为只含位置与时间、不含速度的一类〔公式待核〕，这一点他没有再讨论别的类型。到 2.2 节开头，他又从「任一瞬间的形态能否用一个坐标说清」给出单自由度系统的操作性说法。换句话说，本章给出的自由度是一个**计数口径**，不是一个**建模规模的选择**：它告诉你方程该有几个，不告诉你一个连续体该切成几块。

（见 p22，§2.1.3.1；p25，§2.2）

> **出处**：p22（广义坐标与 $N=3n-s$、约束方程 (2-11)）＋ p25（自由度定义、单自由度系统的操作性说法）。
>
> **口径提醒**：这条定义在本章是**理论力学式**的（数坐标、减约束），与结构动力学里「为定模型规模而选自由度」是两件事。混用这两套口径是审模型时最常见的错。

## I — 判据骨架

### I.1 三个数不能混：3n、N、振型阶数

| 符号 | 是什么 | 什么时候能用 | 常见误用 |
|---|---|---|---|
| $3n$ | 质点坐标总数 | 只在报「未消约束前有多少个坐标」时用 | 把 $3n$ 直接说成自由度（任务 #16 的靶子） |
| $N=3n-s$ | 完整约束下的独立参数个数＝广义坐标个数＝自由度〔公式待核〕 | 约束方程**不含速度项**时 | 对含速度的约束照用（ce06） |
| 振型阶数 | 特征值个数，等于 $N$ | 与 $N$ 同源，但它是「解出来几个」，不是「设了几个」 | 用阶数反推模型规模 |

**判据只有一条**：先看约束方程里有没有速度（或速度的导数）。没有 → $N=3n-s$ 可用〔公式待核〕；有 → 该式不成立，须另立速度约束并降阶（ce06）。

### I.2 审模型用语的四问

1. **自由度报的是几？** 与方程的个数对不对得上（本章的口径是「方程数 = 自由度数」）。
2. **这个自由度是怎么数出来的？** 如果对方说「3n」，问它减掉了几个约束、约束是不是完整。
3. **广义坐标选的是哪一组？** 同一系统可以换一组广义坐标，$N$ 不变但方程形式变（本章未展开换法）。
4. **质量阵是对角还是满阵？** 本章默认对角，但同时承认「有些系统不按对角形成」，**没有给构造办法**（ce17）。报告写「质量阵为对角阵」而不交代依据，是一处必须追问的点。

### I.3 本章没给、但审模型必须问的三件事

| 要问的 | 本章状态 |
|---|---|
| 连续体怎么切成 N 个集中质量（形函数、一致质量阵、离散化步骤） | **未给，0 处**。本章只有「质量阵有时非对角」一句承认，没有构造法 |
| 边界条件怎么定 | 只有简支梁与悬臂梁两种（p40–p41），层间连续、半空间、侧向无限一条都没有 |
| 非完整约束怎么处理 | 只有一句「乘子法把非完整约束也照顾到了」，而全章的约束形式写的是不含速度的方程（矛盾见 `cb49`），**论证与方程形式不匹配** |

### I.4 计数口径与建模规模是两套语言

- 计数口径问：**这个系统理论上该有几个方程**。
- 建模规模问：**我打算用几个自由度去近似它**。
- 后者可以小于前者（这是所有近似方法的前提），但报告必须写清「我用了几个、依据是什么」。本章只交付前者的判据，**后者的判据在本章为 0**。

## A1 — 演练（合成场景，无书中数字）

【合成演练，非书中案例】本章无自由度算例，下列四条为**口径核对**演练：给字段 → 出「这个词用得对不对」，**0 个数值结果**。

**演练一（正常路径：完整约束）**
输入：质点数 n、约束条数 s、约束方程的形式（是否含速度项）。
1. 判约束类型 → 不含速度 → 完整。
2. 按「坐标总数减约束数」计数〔公式待核〕，与报告里的方程数比对。
3. 输出「口径一致／不一致」；一致时再核广义坐标是否为独立参数。

**演练二（否决：把坐标总数说成自由度）**
输入：报告写「本模型有若干个自由度」，同处又给出质点数与约束数。
→ 输出「**出局**：那个数是坐标总数，不是自由度；两者差一个约束数」，并要求改称。

**演练三（否决：非完整系统照用计数式）**
输入：约束方程里出现速度项（滚动接触、轮—面接触一类）。
→ 输出「**停**：这条计数式只对完整约束成立，此处的独立参数个数要另算」（ce06）；本卡不给替代算法。

**演练四（半覆盖：审边界条件）**
输入：一份把路面结构简化成若干自由度的报告，边界条件一栏写「固支」。
→ 输出「**无法用本章核对**：本章只出现简支与悬臂两种梁的边界，其它边界无判据」；只能提示「边界未在原文范围内」。

**预期输出表**：`报告用语｜应为｜依据｜本章能不能核`。

## A2 — 触发场景（用户口吻）

1. 「这份动力分析里说模型是几个自由度，我怎么判断它数得对不对？」
2. 「有人把自由度直接写成 3n，这个说法错在哪？」
3. 「我的系统带滚动接触，还能不能按质点数减约束数来数自由度？」
4. 「报告里质量阵是对角阵，这个假定要不要它交代依据？」
5. 「它把路面简化成几个集中质量，这个切法本章有没有依据？」

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入判定）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 质点数 n | 整数 | 必需 | 缺 → 停，计数无从谈起 |
| 约束条数 s | 整数 | 必需 | 缺 → 停 |
| 约束方程形式（含不含速度项） | 布尔／文本 | 必需 | 缺 → 停：这是唯一的判据入口 |
| 报告声明的自由度 | 整数 | 建议 | 缺 → 只能正向计数，不能比对 |
| 广义坐标清单 | 文本 | 建议 | 缺 → 无法核独立性 |
| 质量阵形态（对角／满阵） | 枚举 | 建议 | 缺 → 记一处「未交代」 |
| 边界条件 | 文本 | 条件必需 | 缺 → 记一处「未交代」；本章也无判据 |

**步骤**

1. **读约束方程**：只看有没有速度项。有 → 出口（ce06）；无 → 进第 2 步。
2. **计数**：$N=3n-s$〔公式待核〕，记下这个数。
3. **比对**：与报告声明的自由度、方程个数三方对齐。
4. **核用语**：报告有没有把 $3n$ 当自由度、把振型阶数当模型规模。
5. **记模型审查两项**：质量阵形态、边界条件——本章对后者无判据，只记「未交代」。
6. **写「不推出的项」**：这套自由度是否够用来近似真实结构（本章无判据）。

**停判点**

1. 约束含速度项却仍要按 $3n-s$ 数 → 停（ce06）。
2. 要求本章给「连续体切成几个集中质量」的步骤 → 停：**本章未给离散化**（硬前提 A1）。
3. 要求本章判边界条件选得对不对 → 停：只有简支、悬臂两种。
4. 要求本章回答「要几个自由度才够精确」 → 停：本章 0 处。
5. **问共振放大几倍 → 本章答不了，去 ch4/ch7 找。**（2.2.1.4 缺位）
6. 约束方程本身没给、只给了自由度的数 → 停，不能反推。

**输出契约**——表格字段固定：

`报告用语｜应为（3n／N／振型阶数）｜判据｜本章能不能核｜缺什么`

表下固定三行：

- **公式状态**：$N=3n-s$ `〔公式待核〕`，仅作计数口径。
- **不推出的项**：建模规模是否足够、边界是否合理、离散化步骤。
- **依据页**：p22（定义与计数）、p25（单自由度说法）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **约束方程里含速度项**：$3n-s$ 的前提是完整约束，含速度就不能用这个计数（ce06）。滚动接触、轮—面接触一类，先判类型再谈个数。
2. **把 $3n$ 当自由度**：坐标总数与独立参数个数差一个 s；这是审模型用语里最高频的一处。
3. **默认质量阵一定是对角阵**：本章只给了一个对角阵的例子，同时承认有非对角的情形，**没有构造办法**（ce17）。要主张对角，得自己给依据。
4. **要求本卡给离散化步骤**：本章 0 处。没有形函数、没有一致质量阵，连「切几块」的原则都没有。
5. **拿本章判边界条件**：本章只出现简支与悬臂两种梁（硬前提 A5），层状体系、半空间、侧向无限全部缺位。
6. **拿本章判非完整约束的处理**：全章约束形式是不含速度的方程，正文却称乘子法照顾了非完整约束，两处不匹配（`cb49`）。本卡不背这个结论。

**H2 — 用前必须声明**

1. **约束类型**（完整／非完整）：这是唯一判据的入口，不声明则计数无意义。
2. **$n$ 与 $s$ 的口径**：$n$ 是质点数还是别的计数单位、$s$ 数的是方程条数还是别的，必须写清。
3. **自由度是「计数所得」还是「建模所选」**：两套语言，本章只支持前者。
4. **公式状态**：$N=3n-s$ 与约束方程 `〔公式待核〕`；本章指标上限在质点数与自由度数之间摇摆（`cb52`），引用时统一到 $N$。
5. **质量阵形态与边界条件**：即使本章无判据，也要在输出里记「未交代」，不要沉默。

**本章三条覆盖缺口（对本卡的影响）**

| 缺口 | 对本卡 |
|---|---|
| 连续体 → 集中参数的离散化步骤（本章未给） | **本卡的核心缺口**：能数已有模型的自由度，不能替你把连续体切块 |
| 模量随温度与加载频率变化（本章不涉及） | k、E 全按常数；本卡的计数不受影响，但等效刚度取哪个值须外部给 |
| 移动车轮荷载下的动力放大系数（缺移动荷载、缺有阻尼受迫、缺层状体系） | 本卡不涉及荷载，只到「方程有几个」 |

**不要用本卡做的事**：给离散化步骤（本章无）、判边界条件（本章只两种）、算任何频率或响应（转 `ch2-sdof-frequency-resonance`、`ch2-two-dof-modes`）。
