# ch4-audit-moving-load-report — 审一份移动荷载报告：七查与硬门槛

> **卡位**：第 9 张 / 共 10｜**重要性**：high
> **挂靠 verified**：f27、A12
> **B 段随卡**：A02、A03、A04、B63（中）、B67（中）；术语侧 g10
> **页**：PDF p83–p93，印刷 p74–p84
> **引式纪律**：凡引式一律带〔公式待核〕；4.3 的式子只按节 + 页引。本卡引算例的数（两个荷载分量与七个结果值），故六缺必须同列——本卡把六缺放在七查里，逐项对得上。
> **一句话**：本章最可迁移的产出不是解，是七查；七项都能判"缺不缺"，一项都判不了"够不够"，而其中三项是硬门槛。

## R — 原文论点（转述，非摘录）

本章最有用的东西是一张检查表：作者把模型假定分散在四五处写，从没集中交代——各层均质各向同性且线弹性、界面完全连续、最下一层无限深、小变形、移动荷载幅值恒定且无加速度、相邻车不叠加、轴对称只对单个圆荷载、阻尼按比例取、计算域截到某个深度并全约束、时间推进按稳定性选参数。假定散着写，读的人就会漏；把它们收成七查，一份报告的可比性当场能判。七查里三项是硬门槛：时间步与两个积分参数给没给、阻尼比的口径写没写、结论有没有超出单结构单车速。本章对七项一个合格阈值都没给——它能判"缺不缺"，判不了"够不够"。（PDF p83–p93，印刷 p74–p84）

## I — 判据骨架

### I.1 七查（逐项可判，不需要数值）

1. **模量**：是不是当成了常数？有没有与频率、温度、车速挂钩？本章算例四个模量是常数，与频率温度无关；拿它当动态模量用，判口径错。
2. **界面**：按什么条件？本章只有"不滑不脱"一种，一个界面参数都没有；滑移、半连续、脱空一概无。层底拉应力类的结论必须标这一条，否则数值不可移植。
3. **计算域与底面**：多大、底面怎么约束？底面钉死会反射波；解析链要的是"往下没有底"。两者是两件事，不许拿一个验另一个。
4. **时间推进**：步长给了没有？两个积分参数给了没有？稳定校核做了没有？——**硬门槛**。
5. **阻尼**：形式是什么？取自哪两阶？阻尼比是比值还是百分号？前两阶频率的数值有没有？——**硬门槛**（口径差一百倍）。
6. **荷载与车速**：图形是什么（半正弦、矩形、双圆）、水平力怎么来的、车速多少、有没有把冲击系数当水平力系数用。
7. **结论范围**：有没有超出单结构、单车速、单荷载图形？两个拉应力有没有被塞进"都小于静力值"那句概括？——**硬门槛**。

### I.2 六缺逐项落到七查里（这是本卡的接线）

- 第 4 查覆盖：时间步、两个积分参数、网格尺寸、荷载起始坐标；
- 第 5 查覆盖：前两阶频率的数值、阻尼比的口径。

所以六缺不是另开一张清单，它就是第 4、5 两查的展开。凡引算例的数（含 0.3 与 0.21 两个荷载分量、以及那七个结果值），必须连六缺一起写；把它们固定在第 4、5 查里，就是为了不被打散。

### I.3 三项硬门槛怎么用

- 第 4 查缺任一项 → 判"不可复现"。
- 第 5 查缺口径 → 判"参数不可比"。
- 第 7 查越界 → 判"概括无效"，但分项结论仍可引。

判据只看给没给，不看数大小——这是它比"校核结果"更耐用的原因。

### I.4 七查里两处必须当场拆开的术语

1. **冲击系数与水平力系数不是一回事。** 规范体系里冲击系数是竖向荷载的动力放大，与平整度、车速有关；水平力另有一套系数，与制动、启动有关。本章取 0.3 乘竖向压力得水平力，并把这个 0.3 叫冲击系数。做报告对照时这两个数不能互换：引用时只能写"本章把 0.3 当水平力系数"，不许反过来说成"冲击系数 0.3"。
2. **图不可复核。** 车速那两条结论靠的两张图在源文件里没有图片，正文却写"由图可见"。审报告时，凡"由图可见"而图不可得的结论，一律降为"作者口述"。

### I.5 本章给不出的两件事（缺口，不是疏忽）

1. **底面截多深才够**：本章只提醒"边界约束影响较大"，只调了荷载起始位置，没调计算域，也没有收敛试算 → 只能提醒，不能回答。这一条是全章三个缺口之一。
2. **与实测对照**：全章零个实测值、零条落锤式弯沉数据、零处现场验证；算例的对照对象只有静力值 → 拿本章的数去对实测，这条路在本章内不通。这是另一个缺口。

### I.6 审完给什么

一份七行打勾表 + 三个硬门槛的结论 + 一句"这份报告的结论能用到哪一步"。不给"通过/不通过"的总评——本章没有阈值，任何总评都是审的人自己加的。

## A1 — 演练（合成场景，零数值结果）

**【合成演练，非书中案例】**

场景：甲方递来一份移动荷载有限元报告，要你签字说"结论可用"。

走哪支：

① 按七查逐项打勾，能走完。
② 第四查若缺步长或两个积分参数 → 停，判不可复现，不必往下看数。
③ 第五查若没写口径 → 停，判参数不可比。
④ 第三查若它用底面钉死的算例去证解析解 → 停，两者不许互验。
⑤ 第七查若概括里含两个无对照的拉应力 → 停，分项结论可引、概括无效。
⑥ 第六查若它把水平力系数说成冲击系数 → 停，先改术语再谈。
⑦ 想拿本章的数对实测 → 停，本章无实测。

停判点：第二步与第三步是硬停（不可复现、不可比）；第四步是"不许互验"；第六步是术语硬停。

缺什么：七项都没有合格阈值——本章能判"缺不缺"，判不了"够不够"，尤其"底面截多深"这一项本章只能提醒。签字时只能写"据这七项，缺什么"，不能写"够用"。

## A2 — 触发场景（用户口吻）

1. 我要审一份移动荷载有限元报告，先看哪几项。
2. 报告只写"采用 Newmark 法"，这一项算不算硬伤。
3. 阻尼比那一列有百分号，我怎么判断它用的是哪种口径。
4. 报告用四米底面全约束的算例，去证明解析解对，这样可以吗。
5. 报告说"冲击系数取 0.3"，这个 0.3 到底是什么。
6. 报告结论覆盖了两个没有静力对照的拉应力，我该怎么处理。

## E — 执行步骤

**输入契约**：

- 一份移动荷载路面有限元报告（或有解析部分）；
- 它的假定清单（没有就自己从正文抽）；
- 它的参数表、时间推进设置、阻尼设置；
- 它的结论段（要逐句看覆盖范围）。

**步骤**：

1. 抽假定：模量是否常数、界面条件、计算域与底面、荷载图形、时间推进、阻尼，六行。
2. 打勾七查，每项记"给了/没给/给得不全"。
3. 查硬门槛三项：第 4、5、7。任一不过，先记结论。
4. 拆术语：冲击系数与水平力系数、百分号与比值。
5. 查互验：有没有拿底面钉死的算例去证解析解。
6. 查"由图可见"：图能不能拿到；拿不到就降为口述。
7. 写缺口：底面够不够、能不能对实测——这两条本章答不了，报告若声称答了，判越界。
8. 交付：七行打勾表 + 三项硬门槛结论 + 一句"能用到哪一步"。

**交付物**：一张七查表 + 三项门槛结论 + 两处缺口登记。

## B — 边界

- **A02 · 常模量、各向同性、线弹性、小变形，四件套同时成立。** 这条假定同时关掉三件事：混合料的摊铺方向差异、模量的温度与频率依赖、重载高温下的非线性。处理：引用本章任何数值都必须挂"常模量、线弹性"两个词，否则会被当成动态模量算例。
- **A03 · 界面不滑不脱。** 本章只有完全连续一种，没有界面参数，也没讨论界面状态改变后层底拉应力怎么变。处理：凡引用层底拉应力类结论，必须注"完全连续界面"，否则数值不可移植。
- **A04 · 解析用半空间，算例把底钉在四米。** 前者要求波能一直往下走，后者把底面全部约束；钉死会反射波。作者自己说边界约束影响较大，但只调了荷载起始位置，没做计算域尺寸的敏感性试算。处理：卡里必须把两件事分开写，禁止拿算例去验解析解。
- **B63（中）· 冲击系数被拿去当水平力系数。** 本章取 0.3 乘竖向压力得水平力，再合成一个合力（合力本身算得对）。但规范体系里两者不是一回事。处理：引用时写"本章把 0.3 当水平力系数"，不得反过来说成"冲击系数 0.3"。
- **B67（中）· 两张关键图在转录里不存在，正文却写"由图可见"。** 车速对弯沉与剪应力的两条结论全靠这两张图；文本里只剩图注。处理：这两条只能标"作者口述，图形不可复核"，不得写成"由图可知"。
- **术语侧**：g10 只作词条登记，不作判据。
- **与别章的界**：板与地基的体系归第 5 章；模量随频率温度的取值属材料参数那一章；底面截断的收敛判据本章没有，且不许从别章借。
- **六缺**：已按 I.2 落到第 4、5 查里；凡引算例的数，两查必须同时在场。
