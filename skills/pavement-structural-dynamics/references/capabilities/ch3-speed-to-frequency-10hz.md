## R — 原文论点（转述，非摘录）

这一小节要解决的是「室内该用哪个频率」。作者先把九家单位给的车速与加载时长（或频率）的对应关系搬成一张表：有的把时速折成一个时长，有的给频率与时速的线性系数，有的干脆给一个区间。表列完，他没有逐条裁决，而是挑了一条自己用的路子：先把频率折成加载时长，再把时长与行车速度对上，得到一个大致的时速段；接着拿国内计算行车速度的常用区间去比，说明这个时长落在实际范围内；于是本试验的频率就定为 10 Hz。同一张表里还有一条把时速写成频率的固定倍数，按那条算，10 Hz 只落到三十几公里的位置，与前面那个答案差近一倍；作者取了前者，弃用后者的理由没有写，各式是否同一套单位也没有交代。这张表还被切成两块跨了两页，注引的一条文献在本章参考文献里根本不存在。

（见 p63–64，§3.4.1.2 与表 3-4）

## I — 判据骨架

### I.1 三段链条：频率 → 时长 → 车速

| 段 | 式子 | 可靠度 | 说明 |
|---|---|---|---|
| 频率 → 时长 | t = 1/(2πf)〔公式待核〕 | **高**（一步可复算） | 只依赖圆周率，无经验系数 |
| 时长 → 车速 | 各家的经验式 | **低**（九条互不一致） | 至少两种算法给出相差近一倍的答案 |
| 车速 → 频率 | 同上，方向相反 | **低** | 同一条式子反向用，误差同样带进来 |

**判据**：第一段可以照用；第二段必须**声明用哪一条、为什么**，并写明该条式的量纲约定（时速当成公里数还是米每秒）。

### I.2 同表分歧的登记（不是错误清单，是「只能看分歧」的理由）

| 分歧 | 表现 | 后果 |
|---|---|---|
| 同一频率两个车速 | 一条按固定倍数给三十几公里，一条按时长倒数给六十余公里 | 相差近一倍，取哪个必须自己裁决 |
| 量纲不统一 | 有一条式只有把时速数字直接当代入量才成立 | 换算前须先统一单位，否则结果无意义 |
| 单点巧合 | 10 Hz 处两套算法恰好重合 | 换一个频率立刻分裂，不能当通则 |

### I.3 为什么是 10 Hz（可复述的理由，不是结论）

作者定 10 Hz 的实际理由是三条叠加：一是折出来的时长落在国内常用车速区间之内；二是与国外多数同类研究取的频率一致；三是这一档在试验设备的能力范围里。**这三条都不是从材料性质推出来的**，所以本卡的输出只能是「10 Hz 是本试验选定的频率」，不能是「10 Hz 是本材料的特征频率」。

### I.4 与主曲线的接口：频率必须挂参考温度

主曲线上的横轴是「折算到某个参考温度之后的等效频率」。因此「10 Hz 对应多快」这句话，只有连同参考温度一起说才完整。本章能自洽的参考温度只有 20℃ 那一组（三个移位因子 4.52 / −3.26 / −5.28，`c06` 可复算到 0.01）。**书里的程序是两轮**：第一轮拿 **40℃ 当假定参考温度**，代入两个普适常数 $C_1^*=8.86$、$C_2^*=101.6$ 去**反解基准温度** $T_c$（两组解里按"沥青类 $T_c$ 落在 30~60℃"取第二组，均值 56.6℃）；第二轮把 56.6℃ 代回，改以 **20℃** 为参考温度算移位因子。所以 **40℃ 只是解中间量的假定值，不是主曲线的参考温度**。另需分清两层：**移位因子可复算（与正文 0.0%）**，而表 3-3 的 $T_0(2)$ 列（55.6 / 59.9 / 54.3℃）**不可由文中路径唯一复现**——(3-22) 分母里有个全章未定义的 $T_1$，外部复算差 3%~9%，那三个数只能算"作者报的"。**判据**：凡把频率映射到模量，必须同时给出参考温度；给不出就只谈时长，不谈模量。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章只有一个换算点被走过，不作演练答案；下列四段给「输入哪一端」，输出「走哪一段、要声明什么、停在哪」，**不给任何算出数**。

**演练一（频率 → 时长，正常路径）**
输入：一个试验频率。
→ 判：走第一段（频率与加载时长互折那条式子），这一段无经验系数。
→ 输出：一个加载时长 + 「此步可一步复算」的说明。
→ 不输出：任何时速。

**演练二（时长 → 车速，必须裁决）**
输入：上一步得到的时长，要求折成时速。
→ 判：第二段有至少两条互不一致的经验式；必须先选一条并写明理由与量纲约定。
→ 输出：一个时速段 + 「按某条式换算」的声明 + 「同表另一条给出不同答案」的登记。
→ 不输出：把两个答案都写上去当结论（那是并列，不是换算）。

**演练三（否决：把单点重合外推）**
输入：要求给出「频率减半时对应多快」。
→ 判：本章那对数值的重合只在单点成立；换一个频率，两套算法立刻分裂。
→ 输出：**出局**——不许外推；要外推须先裁决用哪条式，并重新统一量纲。

**演练四（停：不声明参考温度就要模量）**
输入：要求「给试验频率下这块料的模量」。
→ 判：频率要落到主曲线上，必须带参考温度；本章只有一组参考温度能自洽，且主曲线本身无参数、图上读不出数。
→ 输出：**停**——要么补参考温度（只能是本章那组自洽值）并承认模量只能自拟曲线给，要么只谈时长。

**预期输出表**：`输入哪一端｜走哪一段｜声明（式子/量纲/参考温度）｜裁决结论｜停在哪一步`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不换算）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 输入端点（频率／时长／车速） | 枚举 | 必需 | 缺 → 停：不知道从哪一段起算 |
| 输出端点 | 枚举 | 必需 | 缺 → 停 |
| 拟用的经验式（哪一家） | 文本 | 时速段必需 | 缺 → 停：九条互不一致，必须选一条 |
| 该式的量纲约定 | 文本 | 时速段必需 | 缺 → 结果无意义，须先统一 |
| 校验用的车速区间 | 数值对 | 建议 | 缺 → 无法判「落没落在实际范围」 |
| 参考温度 | 数值 | 落模量时必需 | 缺 → 停：不声明参考温度就不能映射到模量；本章只许 20℃ |
| 用途（选频率／校核报告） | 枚举 | 建议 | 缺 → 只给换算，不给建议 |

**步骤**

1. **定端点**：从频率、时长、车速三者中定一个起点与一个终点。
2. **走第一段**：频率与时长互折，t = 1/(2πf)〔公式待核〕；这一步标「可复算」。
3. **裁决第二段**：选一条经验式，写清选它的理由与量纲约定；把同表其他式的不同答案作为「分歧登记」附上，不当结论。
4. **校验区间**：把结果与自定的车速区间比一遍，说明覆盖或未覆盖。
5. **落到模量前补参考温度**：只能写 20℃；并声明主曲线本身无参数、不可从图上读数。
6. **写「不推出的项」**：其他频率下的对应、九条式的取舍规则、现场温度场。

**停判点**

1. 要求把某一频率—车速的对应外推到其他频率 → 停（单点重合）。
2. 要求同时采用两条经验式的结果 → 停（必须裁决一条）。
3. 不声明量纲就换算时速 → 停。
4. 不声明参考温度就要模量 → 停（只许 20℃）。
5. 要求引表 3-4 注的那条文献 → 停（该文献在本章参考文献里不存在）。

**输出契约**——字段固定：

`输入端点｜输出端点｜走的式子｜量纲声明｜是否裁决（选了哪一条）｜参考温度｜校验区间｜不推出的项｜依据页`

表下固定三行：
- **公式状态**：`〔公式待核〕`。
- **数值状态**：转录值；单点重合不得外推。
- **依据页**：p63–64。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把「10 Hz 约合 60~65 km/h」外推到别的频率**：那对数值的重合只发生在 10 Hz 附近（2πf 与 62.5 撞在一起）；换到 5 Hz，两套算法立刻分成 31.4 与 16.5（`ce-B18`）。凡写这条，必须加「按某条式换算；同表另一条给三十几公里」。
2. **把表 3-4 的九条式子互相换算**：值互不一致，量纲也不统一；只能当「业界存在分歧」的证据，不能互算。
3. **引用表 3-4 注引的那条文献**：本章参考文献里没有它（只列到 22，正文却引到 28）。
4. **不声明参考温度就把频率映射成模量**：参考温度只能 20℃（4.52 / −3.26 / −5.28 那一组）；40℃ 不得作参考温度（`ce-B06`）。
5. **按行解析表 3-4**：这张表跨页被切成两块，续块的表头在转录里变成了标题，按行取数会把表头当节标题；取值前先拼回一张表。
6. **把 10 Hz 说成材料的特征频率**：它是本试验选定的频率，理由是三条外部条件，与材料性质无关。

**H2 — 用前必须声明**

1. **走的是哪一段**（频率↔时长 / 时长↔车速），以及哪一段可复算、哪一段不可。
2. **用了哪一条经验式、它的量纲约定**。
3. **同表分歧**：其他式给出的不同答案，作为登记附上。
4. **参考温度**：只写 20℃。
5. **单点性质**：所有频率—车速对应都只在被算过的那一点有效。
6. **公式状态**：`〔公式待核〕`。
