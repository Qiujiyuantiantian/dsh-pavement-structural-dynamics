## R — 原文论点（转述，非摘录）

作者的例子是两个质量块，各由弹簧与固定端相连、彼此之间再接一根弹簧，限定只能沿一个方向移动，且不计摩擦。先写出两个联立的二阶方程，令外激励项为零得到齐次组；随后沿用单自由度的经验，假设两块以同一个角频率、同一个初相位作简谐运动，只是幅值不同，记作两个待定常数。把这个假设代进齐次组，得到一组关于两个幅值的线性代数方程。他指出：两个幅值同时取零虽然满足方程，但那对应静止，读不出任何振动信息；要让方程有非零解，只有让这两个幅值的系数行列式等于零〔公式待核〕。行列式展开后是角频率平方的二次式，称为频率方程，其两根都是正实数，并且按从小到大排列。把某个根代回代数组，他强调**得不到幅值的真实大小**，只能得到两个幅值之比；两个根各给一个比值，这两个比值就是两个固有振型的形状，且只由四个物理常数决定。两阶主型线性叠加即为通解，四个任意常数由初始位移与初始速度定出。他最后补了一句限制：除非两阶角频率成整数比，这种合成运动一般不是周期性的；只有一开始就按某一主型起动，系统才作纯谐运动。

（见 p32–p34，§2.2.2.1）

## I — 判据骨架

### I.1 一条链，五个关口，每个关口都有否决条件

| 关口 | 要做的事 | 否决条件（不过就停） |
|---|---|---|
| ① 建模 | 写齐次方程组，确认质量与刚度都取常数 | 有阻尼、有大变形、参数随频率变 → 本章不适用 |
| ② 假设 | 设两个坐标同频同相的简谐解 | 两坐标不同频 → 那是受迫或非主型运动，不走这条链 |
| ③ 非零解 | 令系数行列式为零〔公式待核〕 | 拿零解当物理解 → 出局（ce26） |
| ④ 取根 | 解 ω² 的二次式，取两个正根，小根在前〔公式待核〕 | 出现负根或复根 → 模型或系数有错，先查再算 |
| ⑤ 振型 | 把根代回，只取比值 $r=A/B$〔公式待核〕 | 把比值当绝对幅值 → 出局（ce15） |

### I.2 输出物只有三样，别多给

1. **两阶固有角频率**（各对应一个 ω² 根）。
2. **两个振型比**（无量纲的比值，不是位移）。
3. **通解的形式**（主型叠加，四个待定常数），以及「一般不为周期运动」这句限定。

**拿不到的东西**：绝对幅值（缺初始条件与归一化约定）、稳态响应（本章缺有阻尼受迫）、任意初始条件下的时程（要四个初始条件，本章只给形式不给解）。

### I.3 振型比的口径：它是形状，不是大小

- 比值由 m、k 决定，与初始条件无关——这正是它被称为「固有」振型的原因。
- 比值可以任意缩放（本章未给归一化约定），所以两个振型不能直接比「谁大」。
- 报告里出现「第一振型幅值 = 某个位移量」的写法，即把比值当绝对值（ce15）。

### I.4 通解的三条限定（容易被漏）

1. **四个常数**：两个幅值、两个初相角，由四个初始条件（两位移 + 两速度）定。
2. **一般非周期**：除非两阶频率成整数比，合成运动不重复；这一点与「看起来像拍」是同一件事。
3. **纯谐运动的条件**：只有初始条件恰好落在某一主型上，系统才按单一频率振动（ce16 的反面）。

## A1 — 演练（合成场景，无书中数字）

【合成演练，非书中案例】本章的两自由度例题不可用（式体损坏 + 图文不符），下列演练只走**流程与口径**，**0 个数值结果**。

**演练一（正常路径）**
输入：两个质量、两根弹簧的常数，且系统无阻尼、线性。
1. 写齐次组 → 设同频同相简谐解 → 令行列式为零〔公式待核〕。
2. 得 ω² 的二次式 → 取两个正根，小根在前。
3. 各根代回 → 得两个比值 → 输出「两阶频率 + 两个振型比」。
4. 不输出：任何位移的绝对大小。

**演练二（关键否决：把振型比当幅值）**
输入：报告写「第一振型下质量块的振幅为某值」，但只给过比值。
→ 输出「**出局**：代回只给比值，绝对幅值要初始条件与归一化约定，本章两样都没给」（ce15）。

**演练三（否决：把零解当振动解）**
输入：求解程序返回两个幅值同时为零，报告称「该阶振型振幅为零」。
→ 输出「**出局**：零解对应静止，是齐次方程的平凡解；要非零解得先让行列式为零」（ce26）。

**演练四（否决：一般初值按单频算）**
输入：给定四个初始条件，报告只用一阶频率写响应。
→ 输出「**停**：一般初值下是两个主型的叠加；只有初始条件落在某一主型上才是纯谐运动」（ce16）。

**演练五（半覆盖：要稳态响应）**
输入：给定简谐外激励，要求两自由度的稳态幅值。
→ 输出「**本章答不了**：本章的两自由度部分只做自由振动，受迫段只有单自由度且无阻尼；放大倍数与相位差整节缺位」。

**预期输出表**：`两阶 ω｜两个振型比｜通解形式｜限定（非周期／主型起动）｜不推出的项`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入判定）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 两个质量 $m_1,m_2$ | 数值 | 必需 | 缺 → 停 |
| 刚度（两根弹簧常数，或整张刚度阵） | 数值／矩阵 | 必需 | 缺 → 停；只给柔度阵时先转 `ch2-stiffness-flexibility-swap` |
| 阻尼情况 | 枚举（无／有） | 必需 | 有阻尼 → 停：本章无有阻尼两自由度解 |
| 坐标定义（每个质量块沿哪个方向） | 文本 | 必需 | 缺 → 方程符号易错，先补 |
| 外激励 | 枚举（零／简谐／其它） | 必需 | 非零 → 只到「无阻尼受迫」且仅单自由度有；两自由度 → 停 |
| 初始条件（四位） | 数值 | 条件必需 | 缺 → 只给通解形式，不给具体运动 |
| 归一化约定 | 文本 | 建议 | 缺 → 声明「振型比可任意缩放」 |

**步骤**

1. **写齐次组**：令外激励为零，两个方程联立。
2. **设解**：同频、同相、不同幅值；写清这是假设，不是结论。
3. **令行列式为零**〔公式待核〕，展开得 ω² 的二次式。
4. **解根**：取两个正根，小根记为第一阶；出现负根或复根先回头查系数。
5. **回代求比**：每个根给一个比值〔公式待核〕；明确「只到比值」。
6. **写通解**：主型叠加，标四个待定常数与它们的来源（四个初始条件）。
7. **加限定**：一般非周期；仅主型起动时纯谐；比值可缩放。

**停判点**

1. 系统有阻尼 → 停（本章无有阻尼两自由度解）。
2. 要求振型的绝对幅值 → 停（ce15）。
3. 拿零解当物理解 → 停（ce26）。
4. 一般初始条件却要求单频响应 → 停（ce16）。
5. 要求稳态受迫幅值或相位差 → 停：**有阻尼受迫整节缺位**。
6. **问共振放大几倍 → 本章答不了，去 ch4/ch7 找。**
7. 要求三自由度以上 → 转本章 2.2.3 的矩阵写法（`f09` 判 needs_review，式体有硬伤，不在本卡范围）。

**输出契约**——表格字段固定：

`阶次｜ω（两个根）｜ω² 的正负｜振型比 r｜通解形式｜限定｜不推出的项`

表下固定三行：

- **公式状态**：全部 `〔公式待核〕`，带号式子仅作定位。
- **不推出的项**：绝对幅值、稳态幅值、相位差、任意初始条件下的时程。
- **依据页**：p32–p34，§2.2.2.1–§2.2.2.2。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把振型比当绝对幅值**：回代只能得到比值，绝对大小要初始条件与归一化约定（ce15）。报告里出现「第一振型振幅 = 某位移」即误用。
2. **拿齐次方程的零解当物理解**：零解对应静止，不是「该阶振型没有位移」（ce26）。
3. **一般初始条件按单一频率算响应**：通解是两个主型的叠加；只有初始条件落在某一主型上才是纯谐运动（ce16）。
4. **默认质量阵一定是对角阵**：本章只给了一个对角阵的例子，并承认有非对角的情形，却没有构造办法（ce17）。
5. **以为本章能给稳态响应**：两自由度部分只做自由振动；受迫只有单自由度且无阻尼。要放大系数、相位差 → 本章 0 处。
6. **拿图 2-9(a) 的文字描述当刚度阵的依据**：正文说两块都与地面相连，而给出的刚度阵只体现一块接地（矛盾 C7）；两套读法导出的柔度阵不同。用前须指定按哪一个建模。

**H2 — 用前必须声明**

1. **阻尼是否为零**：本卡全部结论建立在无阻尼上。
2. **坐标与方向**：两个坐标各指哪个自由度，符号错一处整条链就错。
3. **小根在前的排序约定**：本章按 ω₁ < ω₂ 写根，报告换序时必须标出，否则「第一振型」指哪一个会歧义。
4. **振型比的归一化约定**：本章未给，比值可任意缩放。
5. **公式状态**：全部 `〔公式待核〕`；`(2-76)` 在本章同页有两个互相冲突的版本，第二版与 (2-77)(2-79)(2-88) 全都对不上（`cb33`），**取第一版**。

**本章三条覆盖缺口（对本卡的影响）**

| 缺口 | 对本卡 |
|---|---|
| 连续体 → 集中参数的离散化步骤（本章未给） | 本卡的 m、k 必须是已经折好的；连续梁要几个自由度、每个取多少质量，本章不给 |
