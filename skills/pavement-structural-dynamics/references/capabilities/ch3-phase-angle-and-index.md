## R — 原文论点（转述，非摘录）

作者先给出两个量的分工：一个是幅值比，量的是「多硬」；另一个是滞后角，量的是「多黏」。随后他把两者拼成一个比值——幅值比除以滞后角的正弦——并从两个端点说明它的走向：滞后角趋近零时，分母趋零，比值发散；滞后角趋近四分之一周期时，正弦趋一，比值退回到幅值比本身。中间那一段，材料越接近弹性、滞后角越小，比值越大，于是他把它读作抗车辙能力的一个排序量。类比的对象是结合料那边一个同形的指标。这一段只给方向：没有门槛，没有分级，也没有与车辙深度建立对应。另一处讨论滞后角随温度怎么走时，他先说温度上来黏性成分增、角度该大，随即承认实测在高温端反而回落——高频时最高温度那一组低于次高温那一组，并用矿料骨架嵌挤所占比例上升来解释。到了弯拉那一节，第 (3) 条又把角度写成随温度上升。两句话隔了八页，方向相反，中间没有一句交代；而弯拉那一句所依赖的表格里，另一个温度整行的角度是空的。

（见 p51–52，§3.2.3；相位角方向见 p57–58 与 p65）

> **出处**：p51–52（两个量的分工、比值指标、两个端点）＋ p57–58（温度与频率下的非单调）＋ p65（弯拉那节的第 (3) 条与那张表）。

## I — 判据骨架

### I.1 指标怎么用：一条排序判据，两个端点

| 情形 | 指标的行为 | 能不能用 |
|---|---|---|
| 滞后角趋零（近弹性） | 分母趋零，比值发散 | 不能用数比大小，只能说「更接近弹性」 |
| 滞后角趋四分之一周期（近黏性） | 正弦趋一，比值退化为幅值比 | 等于只看模量，指标没有增量信息 |
| 两者之间 | 同一幅值比下，角度越小比值越大 | **可排序**：比值大者抗车辙能力更强 |

**判据只有一条**：同一批条件下，比值大的排在前面。**没有第二条**——本章不给阈值、不给分级、不给「大到多少算好」。

### I.2 两个量的分工（别用一个顶另一个）

| 量 | 它回答什么 | 单独用它漏掉什么 |
|---|---|---|
| 幅值比（模量） | 多硬 | 漏掉耗能能力：两块一样硬的料，黏性成分可以差很远 |
| 滞后角（相位角） | 多黏 | 漏掉绝对刚度：角度一样，硬软可以差几倍 |
| 比值 | 硬与黏的合成排序 | 漏掉两端退化（见 I.1），也漏掉任何绝对门槛 |

### I.3 相位角的写法规则（本卡最实用的一条）

1. **不许写单方向断言**。本章的证据是：低温段随温度升而增、高温段反而回落（高频时最高温那组低于次高温那组）。所以只能**分温段写**，并给出转折发生在哪一档附近的定性说明。
2. **转折点的数值本章给不出**：承载这条论证的图没有图注、也没有坐标数值，只能定性。
3. **两个温区的结论不许互相搬**：4–60℃ 那一段的走势不能搬到 −10~15℃ 那一段，反之亦然；两段是两套试验。
4. **弯拉那一节的依据要打折**：它引的表格里，一个温度整行的相位角是空的；跨温度的方向实际上只有一列数据在支撑。

### I.4 本章拿不到的东西（先声明）

- 指标的阈值、分级、与车辙深度的对应：0。
- 相位角随温度的唯一裁决：0（本章两节未调和）。
- 相位角随频率的拐点位置：0（图无坐标）。
- 复合模量实虚部的可写表达式：0（定义式空号，另一式符号坏）。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章没有相位角算例，也没有指标算例；下列四段输出「能不能排序 / 能不能写这句话」，**不给任何算出数**。

**演练一（排序，正常路径）**
输入：两种混合料，同一温度、同一频率下各给一对（幅值比、滞后角）。
→ 判：先看两个滞后角是否都远离两个端点（零与四分之一周期）；都在中间段 → 用比值排序。
→ 输出：一句「甲的抗车辙排序优于乙」，并附条件（温度、频率、试验路径）。
→ 不输出：比值本身、任何门槛判断。

**演练二（否决：拿指标做验收）**
输入：要求给出「该指标大于多少算合格」。
→ 判：本章零阈值、零分级、零车辙对应。
→ 输出：**出局**——只能排序；要做验收，须另找带阈值的规范或试验。

**演练三（否决：写单方向断言）**
输入：报告草稿把相位角写成随温度单调变大的一句话。
→ 判：本章同一材料在高温端出现回落（高频时最高温那组低于次高温那组），且弯拉那节的方向与之相反；两节未调和。
→ 输出：**停**——改成「分温段：低温段随温度升而增，高温端回落」，并标明转折只有定性依据。

**演练四（停：一端退化还要比数）**
输入：其中一种材料的滞后角已接近零，要求给出比值的具体大小并排序。
→ 判：分母趋零，比值发散，数没有意义；此时只能说「更接近弹性」。
→ 输出：**停**——退化为定性比较；若滞后角接近四分之一周期，则指标退化为只看模量，另行说明。

**预期输出表**：`两个量是否齐｜是否落在端点附近｜能不能排序｜相位角写法（分温段/单方向）｜不推出的项`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 幅值比（模量） | 数值 | 必需 | 缺 → 指标算不出，只能各自单看 |
| 相位角 | 数值 | 必需 | 缺 → 停：第二个量没有 |
| 温度 | 数值 | 必需 | 缺 → 排序结论不带条件，不可用 |
| 频率 | 数值 | 必需 | 缺 → 无法与工况对应 |
| 加载路径（轴向／弯拉） | 枚举 | 必需 | 缺 → 两套试验的数会被混起来 |
| 比较对象的数量 | 数值 | 必需 | 缺 → 只能描述单材料，不能排序 |
| 是否接近端点 | 布尔 | 条件必需 | 缺 → 须自行判断，判不了则只给定性 |
| 阈值来源 | 文本 | 建议 | 缺 → 只排序，不做验收 |

**步骤**

1. **核两个量**：模量与相位角是否同一条件（同温度、同频率、同路径）；不同条件则先配对，配不上就分别单看。
2. **判端点**：相位角是否接近零或四分之一周期；接近则指标退化，改用定性描述。
3. **算比值**：幅值比除以相位角的正弦〔公式待核〕；分母写 φ，不写角频率。
4. **排序**：同条件下比值大者抗车辙能力更强；排序结论必须带条件。
5. **写相位角结论**：分温段写，标转折的定性位置；不许单方向。
6. **查依据强度**：若引弯拉那节的方向，须注明其依据表格里有一整行角度为空。
7. **写「不推出的项」**：阈值、分级、车辙深度对应、转折点数值。

**停判点**

1. 要求给指标的合格门槛 → 停（0）。
2. 要求相位角给单方向断言 → 停（高温端回落）。
3. 要求把两节的相位角方向当成「数学互斥」来引 → 停（是未调和，且分属两套试验两个温区）。
4. 相位角接近端点还要比数值 → 停（发散或退化）。
5. 要求从图上读相位角的拐点 → 停（图无坐标、无图注）。

**输出契约**——字段固定：

`两个量是否齐｜条件（温度/频率/路径）｜是否近端点｜排序结论｜相位角写法（分温段）｜不推出的项｜依据页`

表下固定三行：
- **公式状态**：`〔公式待核〕`；分母一律 φ。
- **数值状态**：本卡不交付数值。
- **依据页**：p51–52、p57–58、p65。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **给这个指标设阈值或分级**：本章零阈值、零分级、零车辙对应；它只能排序。
2. **把相位角写成随温度单调变大这类单方向句**：高温端出现回落，弯拉那节方向相反，两节未调和（`ce-B09`）。必须分温段。
3. **把两节的相位角分歧说成「数学互斥」**：两处测的是不同温区、不同加载路径，低温端其实同向；能成立的只是「没有调和」加「弯拉那节的依据在自己表里整行是空的」。说成互斥是过度断言。
4. **用 |E*|/sinω**：分母写成角频率会让指标带上量纲，不再是无量纲比值；小结那一处是错字（`ce-B16`）。
5. **在相位角接近零时比指标数值**：分母趋零、比值发散（本章明确点了这个端点）；此时只能说「更接近弹性」。
6. **照本章写复合模量的实虚部表达式**：定义式整条缺失（3-10 空号），另一式虚部符号与「应变滞后」相反（`g11`、`g12`）；要写回复数形式，须自己按模量与相位角补这一步。
7. **拿指标与另一条加载路径的数混排**：轴向与弯拉的相位角不可互换（见卡 5）。

**H2 — 用前必须声明**

1. **两个量各自的条件**：温度、频率、加载路径。
2. **端点的处理**：是否接近零或四分之一周期，以及退化之后怎么读。
3. **相位角的写法**：分温段，并声明转折只有定性依据。
4. **指标的分母**：φ，不是 ω。
5. **依据强度**：弯拉那节的方向只由一列数据支撑。
6. **公式状态**：`〔公式待核〕`，实虚部定义式在本章为空号。
