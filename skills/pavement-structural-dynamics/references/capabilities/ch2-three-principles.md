## R — 原文论点（转述，非摘录）

作者按三条原理依次展开，层层收窄前提。

**第一条（达朗贝尔）**：把质量与加速度的乘积取负号，当作一个补上去的项，与主动力、约束力并列，令三者的和为零。他强调这个补项是人为加的，三者只是**在形式上**凑成一个平衡力系，因此动力学问题可以照静力学那套平衡写法处理；质点系层面则对每个质点各写一条。

**第二条（虚功）**：先定义虚位移——在约束允许的范围内、任意、无限小的位移，记作变分，它只改位形不改时间；虚功是力与虚位移的点积。接着用「全部约束力在任何虚位移上作功之和恒为零」把理想约束定义下来，作为一条可检验的判据；在这一前提下，令主动力的虚功和为零，即得虚功方程。他说这条对平衡既必要又充分，但充分性只写「可以证明」并引了文献，本章没有给证明。

**第三条（拉格朗日）**：把前两条合起来——对每个质点同时写主动力与惯性项，在理想约束下令整个力系的虚功和为零，得到动力学普遍方程；再用广义坐标做变换，引入与坐标配对的广义力（量纲随坐标走），由此分成两条岔路：留着约束的走乘子法，乘子项对应约束力，方程个数与未知量对不上，必须回头与约束方程联立；消掉约束的走第二类方程，个数正好等于自由度数。

（见 p20–p25，§2.1）

> **出处**：p20（惯性力 (2-2)、质点与质点系两层 (2-3)(2-4)）＋ p21（虚位移、虚功、理想约束 (2-5)）＋ p22（虚功方程 (2-6)~(2-10)、充要性、广义坐标与 $N=3n-s$）＋ p23（广义力量纲、动力学普遍方程 (2-17)(2-18)、乘子法起点）＋ p24（第一类方程 (2-23)、约束力解释、第二类推导起点）＋ p25（(2-26)~(2-32)、第二类方程及其保守力形式）。

## I — 判据骨架

### I.1 三条原理的分工：改性质 → 改形式 → 改坐标

| 原理 | 干了什么 | 一句话判据 | 什么时候选它 |
|---|---|---|---|
| 达朗贝尔 | 把「运动」改写成「平衡」 | 主动力 + 约束力 + 惯性项 = 0（形式上）〔公式待核〕 | 已有一个静力平衡的写法，想直接搬过来 |
| 虚功 | 把「一堆力的平衡」压成「一个标量等式」，并让约束力整块退出 | 理想约束下，主动力虚功和为零〔公式待核〕 | 约束多、约束力不想求 |
| 拉格朗日 | 把「一组建模」换成「一组广义坐标上的方程」 | 方程个数 = 自由度数（第二类）〔公式待核〕 | 坐标多、想要最少的一组方程 |

### I.2 前提是三条，不是一条

1. **理想约束**：全部约束力在任意虚位移上作功和恒为零〔公式待核〕。有摩擦、有阻尼支承就不成立（ce03）。
2. **完整约束**：约束方程只含位置与时间，不含速度。含速度的约束本章形式容不下（ce06 / `cb49`）。
3. **坐标原点**：取静平衡处，重力才允许不进方程（`ce08`）。换原点必须把静位移补回来。

### I.3 两条岔路怎么选

| 岔路 | 能得到什么 | 代价 | 本章的式子 |
|---|---|---|---|
| 第一类（带乘子） | 乘子项就是约束力，能量出约束反力 | 方程数与未知量数对不上，**必须与约束方程联立**（ce05） | (2-23)〔公式待核〕 |
| 第二类（消约束） | 只剩 N 个二阶方程，个数等于自由度 | 约束力在这条路上被消掉，拿不到 | (2-31)(2-32)〔公式待核〕 |

### I.4 立方程的输入只有四类，缺一类就写不下去

① 系统的力（主动力、约束力各是什么）；② 约束的数学形式（含不含速度）；③ 选定的广义坐标（几个、怎么配对）；④ 坐标原点与是否计重力。

## A1 — 演练（合成场景，无书中案例）

【合成演练，非书中案例】本章无立方程算例（三条原理在原文里只有推导没有例题），下列四条为**原理选择**演练：给字段 → 出「该走哪条路／停在哪一步」，**0 个数值结果**。

**演练一（正常路径：约束多、不要约束力）**
输入：质点数、完整约束条数、约束是否理想、广义坐标清单。
1. 判约束类型 → 完整、理想 → 通过。
2. 选原理 → 虚功（约束力整块退出）。
3. 立方程 → 得「只含主动力」的标量等式，再转广义坐标。
4. 输出：方程形式与方程个数（等于自由度）。

**演练二（否决：把惯性项当真实荷载）**
输入：自由体图上画了质量乘加速度的反向项，并被当作一项外荷载参加强度校核／荷载组合。
→ 输出「**出局**：惯性项只进平衡方程，不进荷载工况；同一份加速度效应被计了两遍」（ce01）。

**演练三（否决：非理想约束下删掉约束力项）**
输入：系统含摩擦或阻尼支承，报告仍只写主动力虚功。
→ 输出「**出局**：删项那一步靠的是理想约束判据；摩擦型约束力作功不为零」（ce03），须保留该项或把摩擦并入主动力。

**演练四（停：要么约束力、要么非完整）**
输入：要求同时给出约束反力与最少的方程个数；或约束方程里含速度项。
→ 输出「**停**：要约束力就走第一类且须联立约束方程（ce05）；含速度的约束本章的形式容不下（ce06）」。两条不能兼得。

**预期输出表**：`选的原理｜约束类型（理想/非理想）｜完整/非完整｜方程个数｜能不能给约束力｜不推出的项`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入判定）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 质点数 | 整数 | 必需 | 缺 → 停 |
| 约束清单与方程形式（含不含速度） | 文本 | 必需 | 缺 → 停：完整/非完整是第一条判据 |
| 约束是否理想（有无摩擦、阻尼支承） | 布尔 | 必需 | 缺 → 停：决定能不能删约束力项 |
| 力系（主动力、约束力各是什么） | 列表 | 必需 | 缺 → 停 |
| 广义坐标（个数、与哪个量配对） | 列表 | 必需 | 缺 → 只能到虚功方程，到不了拉格朗日 |
| 坐标原点（是否取静平衡处） | 文本 | 必需 | 缺 → 重力项可能漏，先补（`ce08`） |
| 是否要约束反力 | 布尔 | 必需 | 缺 → 岔路选不了 |

**步骤**

1. **判约束**：完整／非完整。含速度 → 停（ce06）。
2. **判理想性**：理想 → 可用极简形式；非理想 → 保留约束力虚功项（ce03）。
3. **选原理**：要「平衡写法」→ 达朗贝尔；约束多且不要约束力 → 虚功；坐标多 → 拉格朗日。
4. **补惯性项**（达朗贝尔路径）：质量乘加速度取负，只进平衡方程（ce01）。
5. **写虚功方程**：主动力虚功和为零〔公式待核〕；取变分时时间固定（ce04）。
6. **转广义坐标**：引入配对的广义力，注意量纲随坐标走。
7. **选岔路**：要约束力 → 第一类，并**同时列出约束方程联立**（ce05）；不要约束力 → 第二类，方程个数等于自由度。
8. **校核**：方程个数、量纲、符号（见 H2 第 4 条的已知符号错）。

**停判点**

1. 约束含速度项 → 停（本章形式容不下非完整约束）。
2. 系统非理想约束却要求删掉约束力项 → 停（ce03）。
3. 要求把惯性项当荷载 → 停（ce01）。
4. 要求第一类方程单独解出运动 → 停（必须联立约束方程，ce05）。
5. 要求本章给动力响应时程 → 停：本章无外荷载时间历程、无阻尼矩阵装配、无数值积分。
6. **问共振放大几倍 → 本章答不了，去 ch4/ch7 找。**
7. 要求非完整约束的处理办法 → 停：正文称乘子法照顾了它，但全章写出的约束方程容不下（`cb49`）。

**输出契约**——表格字段固定：

`选的原理｜约束类型｜是否理想｜方程的个数｜能否给约束力｜岔路｜不推出的项`

表下固定三行：

- **公式状态**：全部 `〔公式待核〕`；带号式子只作定位。
- **不推出的项**：动力响应时程、约束力的具体值（要联立约束方程才有）、任何频率。
- **依据页**：p20–p25，§2.1。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把虚加的惯性项当真实荷载**：它只进平衡方程，不进荷载组合、不进强度校核；否则同一份加速度效应被计两遍（ce01）。判据很直接：自由体图、荷载组合或校核式里出现「质量乘加速度」作为一项外加荷载，即判误用。
2. **约束含摩擦却仍删掉约束力虚功项**：极简形式是拿理想约束换来的；摩擦型约束力在虚位移上作功不为零，抹掉等于凭空承认了一个保守系统（ce03）。每个虚功式子都要标出约束类型。
3. **取一个越出约束的虚位移**：虚位移必须在约束允许的方向上，越界则约束力作功不为零，删项失去依据（ce02）。
4. **把变分当全导数**：虚位移只改位形不改时间；混用会把时间偏导项带进方程，多出一份来路不明的功（ce04）。
5. **第一类方程单用**：乘子把 s 个约束力变成 s 个新未知量，方程数与未知量数同步增加，系统仍欠定；缺的那 s 个关系由约束方程给（ce05）。
6. **要求本章处理非完整约束**：全章约束方程写成不含速度的形式，正文却声称乘子法照顾了非完整约束，两处不匹配（`cb49`）。

**H2 — 用前必须声明**

1. **约束类型**（完整／非完整）与**理想性**：这两条决定方程能省到什么程度。
2. **坐标原点**：取静平衡处才允许不计重力；换原点后静位移必须补回（`ce08`）。
3. **广义坐标与广义力的配对**：量纲跟坐标走，角坐标配的是力矩不是力。
4. **公式状态与已知符号错**：本章 `(2-30)` 与 `(2-31)` 对动能偏导项的**符号相反**——`(2-30)` 写成减号，而 `(2-31)` 与 `(2-32)` 写加号且彼此自洽，故**以 `(2-31)`／`(2-32)` 为准，`(2-30)` 那一项符号是错的**。这是一处**确切的符号错误**，不是「待核」两字能盖过去的：照 `(2-30)` 推出来的保守力项会反号，解从振动变成发散。凡写第二类方程，一律以保守力形式复算一遍符号再落笔。
5. **字母与指标口径**：`B`、`Q`、`λ` 在本章都有多义；指标上限在质点数与自由度数之间摇摆（`cb52`），引用时统一到 $N$。
6. **`(2-25)` 在本章连排两遍**，第二版少一个质点下标（`cb26`），取第一版。
