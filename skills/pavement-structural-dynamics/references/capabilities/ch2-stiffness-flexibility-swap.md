## R — 原文论点（转述，非摘录）

作者先把前面那两个联立方程改写成矩阵形式：质量阵乘加速度列、加上刚度阵乘位移列、等于外激励列；刚度阵的元素是刚度影响系数，质量阵在例子里是对角阵。随后他另起一条路——对静定系统，可以改用位移作未知量：先定义柔度（单位力引起的位移），把静力位移写成柔度阵乘力列；再把动力情形接上去，办法是把惯性力一起塞进右边括号，于是位移等于柔度阵乘以「外力减惯性项」。为了跟前面那条路对照，他把作用力方程对位移求解，得到刚度阵的逆乘同一个括号，两式一比就得到「柔度阵等于刚度阵之逆」这条关系。他接着把二阶逆阵完整展开，指出算出来正是前面那个刚度阵；并写下一句限制：**刚度阵一旦奇异，柔度阵就不存在**。最后他比较两条路的适用面：静定系统的柔度阵好导出，静不定系统通常不容易；多数振动系统用刚度系数那条路较省事，但也有不少情形柔度法更方便。

（见 p34–p36，§2.2.2.2–§2.2.2.3）

> **出处**：p34（矩阵形式 (2-88)~(2-91)、质量阵说明）＋ p35（柔度定义 (2-92)、静位移 (2-93)~(2-96)、动力位移方程 (2-97)~(2-99)）＋ p36（$F=S^{-1}$ (2-101)、逆阵展开 (2-102)、静定／静不定说明、奇异一句）。

## I — 判据骨架

### I.1 前置两问，缺一问就不许往下算

| 问 | 判据 | 不过怎么办 |
|---|---|---|
| ① 系统静定吗？ | 本章只对静定系统说「柔度阵容易导出」 | 静不定 → 柔度法退为「不易」，须另找方法（ce18）；本章不给静不定的解法 |
| ② 刚度阵可逆吗？ | $\det S\neq 0$ 才可求逆〔公式待核〕 | $\det S=0$ → 柔度阵不存在（ce19）；**本章到此为止，不给判因** |

### I.2 两条等价的路，选哪条

| 路 | 未知量 | 系数阵 | 好用在 |
|---|---|---|---|
| 作用力方程 | 位移 | 刚度阵 S | 多数振动系统（本章原话） |
| 位移方程 | 力／惯性项 | 柔度阵 F | 静定且柔度系数好求时 |

两路的桥是 $F=S^{-1}$〔公式待核〕。注意这条关系成立的前提是**同一系统、同一组坐标**；换坐标后两个阵都要重写。

### I.3 可以做的三种校核

1. **互逆校核**：把算出的 F 与 S 相乘，看是否得到单位阵（本章的逆阵展开正是这条校核的一个特例）。
2. **静位移校核**：用 F 乘一组静力，与手算／实测位移比。
3. **量纲校核**：刚度影响系数的量纲是力／位移，柔度影响系数是位移／力；两者相乘必须无量纲。这条能抓住「把柔度写成刚度倒数以外的量」这类错。

### I.4 本章明确不给的那一步：奇异之后怎么办

$\det S=0$ 只换来一句「柔度阵不存在」。**是模型建错（约束漏了、连接写错）还是系统本身含刚体位移（自由漂浮、缺约束）——本章没有判因步骤。** 因此本卡的输出只能到「不能求逆」，不能到「所以是模型错了」。这一条对应覆盖审计的第 8 条（半覆盖）。

## A1 — 演练（合成场景，无书中数值）

【合成演练，非书中案例】本章无矩阵算例，下列四条为**门槛判定**演练：给字段 → 出「能不能换／停在哪一步」，**0 个数值结果**。

**演练一（正常路径：静定且可逆）**
输入：刚度阵 S（或柔度阵 F）、系统的约束清单、坐标定义。
1. 判静定 → 是。
2. 判刚度阵的行列式是否为零 → 不为零。
3. 求逆 → 互逆校核 → 输出 F（或 S）与校核结论。
4. 不输出：具体位移值。

**演练二（否决：刚度阵奇异还求逆）**
输入：刚度阵的行列式为零。
→ 输出「**停**：柔度阵不存在，不能求逆」；并注明「本章不判是模型错还是刚体位移」（ce19）。

**演练三（否决：静不定硬用柔度法）**
输入：系统静不定，仍要求直接写出柔度阵。
→ 输出「**停**：本章只说静定系统的柔度阵容易导出，静不定通常不容易，且不给解法」（ce18）。

**演练四（口径核对：换坐标后仍用旧阵）**
输入：报告换了位移坐标，却沿用原来的刚度阵与柔度阵。
→ 输出「**出局**：「柔度阵等于刚度阵之逆」只在同一系统同一组坐标下成立，换坐标两阵都要重写」。

**预期输出表**：`静定性｜det S 是否为零｜走哪条路｜互逆校核结论｜不推出的项（奇异判因、动力响应）`。

## A2 — 触发场景（用户口吻）

1. 「别人只给了刚度阵，我要换成柔度阵做静位移校核，先得判断什么？」
2. 「刚度阵行列式算出来是零，这到底是模型建错了，还是结构本来就能刚体位移？」
3. 「静不定体系能不能直接用柔度法？」
4. 「我算出的柔度阵和刚度阵乘起来不是单位阵，问题出在哪？」
5. 「同一套结构换了一组位移坐标，原来的柔度阵还能用吗？」

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入判定）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 已知的是 S 还是 F | 枚举 | 必需 | 缺 → 停 |
| 矩阵元素（数值或符号） | 矩阵 | 必需 | 缺 → 停 |
| 坐标定义（每个自由度指什么） | 文本 | 必需 | 缺 → 互逆关系不成立，先补 |
| 静定性判断（约束数 vs 平衡方程数） | 枚举 | 必需 | 缺 → 停：这是第一道门槛 |
| 行列式（或可判奇异的依据） | 数值／布尔 | 必需 | 缺 → 先算，不许跳 |
| 荷载（做静位移校核时） | 列阵 | 条件必需 | 缺 → 只做互逆校核 |

**步骤**

1. **判静定**：静定 → 可走柔度法；静不定 → 停（ce18）。
2. **判可逆**：$\det S\neq 0$〔公式待核〕；为零 → 停（ce19），并声明本章不判因。
3. **求逆**：按 2×2 展开式〔公式待核〕或数值求逆。
4. **互逆校核**：$F\cdot S$ 是否为单位阵〔公式待核〕。
5. **量纲校核**：两组影响系数的量纲互逆。
6. **静位移校核**（有荷载时）：用 F 乘静力列。
7. **写「不推出的项」**：奇异的原因、静不定系统的柔度阵、动力响应。

**停判点**

1. $\det S=0$ 仍要求逆 → 停（ce19）。
2. 静不定却要求柔度法 → 停（ce18）。
3. 要求本章判「奇异是模型错还是刚体位移」 → 停：**原文只有一句「柔度阵不存在」，无判因步骤**。
4. 要求动力放大系数或受迫响应 → 停：**有阻尼受迫整节缺位**。
5. **问共振放大几倍 → 本章答不了，去 ch4/ch7 找。**
6. 矩阵与坐标定义不配套（换坐标没换阵） → 停。

**输出契约**——表格字段固定：

`静定性｜det S｜走的路（力法／位移法）｜互换结果｜互逆校核｜量纲校核｜不推出的项`

表下固定三行：

- **公式状态**：$F=S^{-1}$ 与逆阵展开 `〔公式待核〕`。
- **不推出的项**：奇异判因、静不定系统的柔度阵、任何动力响应。
- **依据页**：p34–p36，§2.2.2.2–§2.2.2.3。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **刚度阵奇异还去求逆**：本章明写此时柔度阵不存在（ce19）。含刚体位移的模型（自由漂浮、约束不足）正是这一类，求出来的逆阵是伪逆或溢出。
2. **对静不定体系硬用柔度法**：本章只说静定系统的柔度阵容易导出，静不定通常不容易，且不给解法（ce18）。
3. **要求本章判「奇异是模型错还是刚体位移」**：原文只有一句结论，没有判因步骤（覆盖审计第 8 条：半覆盖）。
4. **拿位移方程算动力响应**：位移方程只把惯性项搬进括号，本章没有阻尼矩阵、没有外荷载时程，算不出响应。
5. **换坐标后沿用旧的 S 或 F**：$F=S^{-1}$ 的前提是同一系统、同一组坐标。
6. **把 p36 那句「阵奇异、其逆存在」当依据**：同一句里两个判断不能同真（`cb44`），这一句只能读作笔误。

**H2 — 用前必须声明**

1. **静定性**：不声明，柔度法这条路的合法性就没有着落。
2. **$\det S$ 的值或奇异性结论**：不声明就求逆，是最常见的越界。
3. **坐标定义**：两组影响系数都跟坐标绑定。
4. **公式状态**：`(2-102)` 的逆阵前置因子**分母写成了同一个柔度自乘 $\delta_1\delta_1$，按 2×2 求逆应为 $\delta_1\delta_2$**（即行列式）。这是本章一处**确切的系数错误**，不是「待核」两字能盖过去的：照原式算不出前面那个刚度阵。凡引用该式，必须按 $\delta_1\delta_2$ 复算，并在卡内注明「原式分母有误」。相关旁证：同一页正文先说刚度阵「非常奇异」，紧接着又说它的逆存在，两句不能同真（`cb44`）。
5. **质量阵形态**：位移方程里 $M$ 是否对角会改变装配方式；本章只承认有非对角情形，未给构造法（ce17）。

**本章三条覆盖缺口（对本卡的影响）**

| 缺口 | 对本卡 |
|---|---|
| 连续体 → 集中参数的离散化步骤（本章未给） | 本卡的 S、F 都是已装配好的；层状体系怎么由层间连续条件装出柔度阵，本章 0 处 |
| 模量随温度与加载频率变化（本章不涉及） | 柔度系数按常数 E 折；沥青层的温频依赖须外部补 |
| 移动车轮荷载下的动力放大系数（缺移动荷载、缺有阻尼受迫、缺层状体系） | 本卡只到静位移校核；移动荷载下的柔度—动力互换须去 ch4 |

**不要用本卡做的事**：判奇异的原因、给静不定系统的解法、算动力响应、判振型（转 `ch2-two-dof-modes`）。

**已知硬伤（列此备查）**：`(2-102)` 逆阵分母写成 $\delta_1\delta_1$（应为 $\delta_1\delta_2$，`cb18`）；p36 同句「非常奇异／逆矩阵存在」自相矛盾（`cb44`）；`(2-93)`/`(2-95)` 的静位移下标被拆成「,t」（`cb36`，实为 $st$）；`(2-98)` 质量阵第一个对角元丢了编号（`cb37`）。
