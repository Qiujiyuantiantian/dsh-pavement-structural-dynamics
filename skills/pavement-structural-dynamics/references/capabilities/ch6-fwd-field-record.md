# ch6-fwd-field-record — FWD 一份现场记录怎么打、怎么判它合格

> 卡类型：规程／合规审查（全章唯一闭环）｜主要取材：§6.4.1–§6.4.2（p129–p131）｜挂靠 verified：`f08`、`A15`｜边界素材：`B26`、`g10`、`g15`、`f10`、`g16`

> **卡头必读**
>
> 1. **这是全章唯一能照着做一遍的节。** 四条数字既是做法，也是判一份记录合不合格的门槛（`f08` 教怎么做，`A15` 把它翻成不合格判据）。别的节都只到原理。
> 2. **程序一致不等于结果一致。** 本章没有重复性数据、没有两台设备互测、没有与钻芯或开挖的对照；所以这四条全过只能保证「两家是照同一套程序打的」，判不了「谁的数对」。

> 5. **传感器远近没有任何定量依据。** 全部依据只有一张示意图（`f10`），锥角、交点深度、要几个传感器，全章一个数都没有。

## R — 原文论点（转述，非摘录）

作者先用一页交代这台设备的构造：拖挂式，测梁长三点五米，速度传感器最多九个，直径三百毫米的承载板拆成四块拼装；再用一页把现场怎么做写成条文。条文里四件事是硬的：同一个点位要打三锤以上、结果取最后两锤的平均、两锤之间留一到两分钟、一个盆至少六个读数。他给了理由——首锤只用来让板坐稳，读数不作数；间隔太短，路面还在回弹，读数会失真；间隔太长，效率塌下去。测点间距他给了四套，交竣工验收、对比试验、路况调查、缺陷诊断各一套，行车道与超车道建议交叉布点。荷载级位在他笔下只是一个旋钮，靠换锤重或改落高来调，此后一句未提它跟反算有什么关系。这一节没有任何带号公式，规程停在「把盆记下来」，怎么由盆反算各层模量被推到后面的 6.4.3.2。

（见 p129–131，§6.4.1–§6.4.2）

## I — 判据骨架

### I.1 四条合规判据（照 `A15` 写成不合格判据，不许降格成建议）

| # | 判据 | 门槛 | 作者给的理由 | 不合格的后果 |
|---|---|---|---|---|
| 1 | 每点锤数 | 不少于三锤 | 首锤只确认承载板坐稳了没有 | 首锤读数被当结果，等于把就位过程当响应 |
| 2 | 采用值 | 末两锤的算术平均 | 首锤不稳，不能反映结构特性 | 取三锤平均或取首锤，两种都不可比 |
| 3 | 锤间间隔 | 一到两分钟 | 太短打在回弹过程中，太长掉效率 | 间隔不记，两份记录无法判断是否同口径 |
| 4 | 盆点数 | 不少于六个读数 | 盆要撑得起形状判断 | 点数不足，连「远处反超近处」都看不出来（卡 2 法一失效） |
| 5 | 梁底贴合 | 贴不住就测不到 | 靠传感器测头端部的弹簧压住路面 | 不是偏差，是整点作废；记录上必须写明 |

### I.2 一份记录的最小字段（缺一项就不可比）

1. **点位与场景**——场景决定用哪套间距（I.3），不写场景就不知道该套哪一套。
2. **锤序读数**——三锤各自的读数，而不是只写平均值；否则第 2 条判不了。
3. **采用值与其来源**——写明「末两锤平均」，不写就等于默认。
4. **锤间实测间隔**——不是「约一到两分钟」，是每点实际记下的间隔。
5. **传感器间距序列与盆点数**——盆是「若干距离上的读数」，只写六个值、不写它们铺在哪些距离上，等于没写（`g15`）。
6. **设备与承载板规格**——梁长、传感器个数、板径与分块，换设备即换口径。
7. **贴合情况**——有没有点位贴不住、贴不住的点怎么处置。

### I.3 间距：四套场景值，本章没有选用依据

| 场景 | 作者给的间距 | 他的措辞 | 问题 |
|---|---|---|---|
| 交竣工验收 | 二十到二十五米 | 「规定为」 | 与下面一行同段并存 |
| 对比试验 | 十到十五米 | 「没有明确规定，建议」 | 建议值，不是门槛 |
| 路况调查、监测 | 一百到两百米 | 「规范也没有作明确规定」 | 与首行的「规定为」正面冲突 |
| 缺陷诊断、详细调查 | 二十到五十米 | 「为宜，可加密」 | 最密的一套，仍无判据 |

> 动作：写间距时必须连场景与措辞一起写，并声明「选哪一套本章无依据」。把四套折成一个数，就是替原文消解它自己没消解的矛盾。

### I.4 本节给得出与给不出

| 能给 | 给不出 |
|---|---|
| 一份可比的记录（四条判据 ＋ 七个字段） | 各层模量（反算在 6.4.3.2，空的） |
| 「两家守没守同一套程序」的判断 | 「两家谁的数对」（无重复性、无设备互测） |
| 四套场景间距的原文口径 | 该用哪一套 |
| 盆点数下限 | 六个读数该铺到多远（`g15`） |
| —— | 荷载级位对结果的影响（`coverage-audit.md` 缺口 6） |

### I.5 弯沉盆在这本章里的两种身份，本节只认第一种

盆在第 129 至 133 页被当作两样东西用：评价整体强度的指标，与反算层模量的数据。本节（6.4.2）只承担前者——把盆按规矩记下来。后者要层数与厚度先进场，而那笔账挂在卡 5 上。本节还有一个沉默的缺口：FWD 的峰值荷载与弯沉时程，本章一句没写，只写盆（`g10`），所以任何按时程做的分析接不进来。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本节 0 个算例、0 条实测盆、0 个反算结果；下面四段给「一份记录 ＋ 一个诉求」，输出「合格／不合格／停在哪一步」，**不出任何数值**。

**演练一（合格路径：判一份记录）**
输入：一份现场记录，写明点位与场景、每点三锤的读数、采用末两锤平均、锤间实记间隔、传感器间距序列与盆点数、设备规格、以及各点贴合情况。
→ 判：I.1 的五条逐条过；四条加贴合全过。
→ 输出：**程序合格**——这份记录可以与**同批、同设备、同场景**的记录横向比。
→ 不输出：任何模量、任何「这段路强度够不够」的结论。

**演练二（不合格：首锤当结果）**
输入：某点只打了两锤，且采用值写的是第一锤。
→ 判：第一条与第二条同时违反；第一锤恰好是作者明说「不作数」的那一锤。
→ 输出：**该点作废，重点补打**；整份记录降为参考。
→ 不输出：把这一点的数「修正」成末两锤的样子。

**演练三（停：该用哪套间距）**
输入：「这段路按多少米一个点布？」
→ 判：四套场景值并存，且同一段里「规定为」与「没有明确规定」并存（I.3）。
→ 输出：**停**——只能按场景报出原文那套值，并写明「选哪一套本章无依据」。
→ 不输出：一个折中的推荐间距。

**演练四（停：盆到手了，反算吧）**
输入：「盆已经按规矩打完了，帮我反算各层模量。」
→ 判：6.4 全节零带号式子，规程不含反算；反算在 6.4.3.2，那一节只有「连续迭代」一句，六件参数一件没有（卡 5）。
→ 输出：**停**——本卡交付的是记录，不是模量；转卡 5 做缺参审查。
→ 不输出：一套「先假设再迭代」的流程。

**预期输出表**：`诉求｜五条判据过否｜合格还是作废｜停在哪一步｜能否横向比｜依据页`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 场景（交竣工／对比试验／路况调查／缺陷诊断） | 枚举 | 必需 | 缺 → 先问；场景决定间距 |
| 每点锤数 | 整数 | 必需 | 缺 → 按不合格处理 |
| 采用值来源（首锤／末两锤／三锤平均） | 枚举 | 必需 | 缺 → 按不合格处理 |
| 锤间实测间隔 | 时长 | 必需 | 缺 → 记录降为参考 |
| 盆点数与传感器间距序列 | 整数 ＋ 序列 | 必需 | 只给点数不给序列 → 盆不可用 |
| 设备与承载板规格 | 文本 | 必需 | 缺 → 不能跨设备比 |
| 贴合情况 | 逐点布尔 | 条件必需 | 缺 → 按「全部贴合」处理并标注 |
| 是否要反算模量 | 布尔 | 条件必需 | 为真 → 停（转卡 5） |

**步骤**

1. **认场景**：先定这趟检测属于四套里的哪一套，写下来。
2. **数锤**：逐点核锤数是否不少于三；不足即判不合格，不许补算。
3. **核采用值**：确认写的是末两锤平均；写「平均」而不写锤序的，追到原始读数。
4. **核间隔**：读实测间隔，落在一到两分钟内为合格；只写「约」的，标为不可核。
5. **核盆**：点数不少于六，且间距序列在记录上；缺序列即盆不可用。
6. **核贴合**：贴不住的点单独标出，按作废处理，不许混进统计。
7. **写输出**：合格／不合格 ＋ 七字段清单 ＋ 能不能横向比的声明；需要模量则转卡 5。

**停判点**

1. 要各层模量 → 停（本节 0 个带号式子，反算那一环在 6.4.3.2 且为空）。
2. 要「两家谁对」→ 停（无重复性、无设备互测、无钻芯对照）。
3. 要一个统一间距 → 停（四套并存，本章无选用依据）。
4. 要六个读数该铺多远 → 停（`g15`，作者只给点数不给距离）。
5. 要荷载级位对结果的影响 → 停（`coverage-audit.md` 缺口 6，全章无落点）。
6. 要按荷载时程做的分析 → 停（`g10`，本章只写盆，不写峰载与时程）。

**输出契约**——字段固定：

`场景｜锤数｜采用值｜间隔｜盆点数与间距序列｜贴合｜合格或作废｜能否横向比｜依据页`

表下固定三行：
- **公式状态**：本节 0 个带号式子。
- **数值状态**：本节数字全是操作参数，不是检测结果。
- **依据页**：p129–p131。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **拿「守了规程」当「结果可信」。** 四条判据只管程序；本章没有重复性数据、没有两台设备互测、没有与钻芯或开挖的对照，所以合格只到「同口径」，到不了「对」。
2. **在这张卡上要模量。** 6.4 全节零带号式子；反算落在 6.4.3.2，那一节只有一句「连续迭代直到差值满足精度」，而层数、厚度、初值、目标函数、收敛阈值、唯一性六件一件没有（`B25`、卡 5）。本章任何一处都不许写成「照此可反演」。
3. **把四套间距折成一个数。** 四套是四个场景，且同一段里「规定为」与「没有明确规定」并存；折中即替原文消解矛盾（`B26`）。
4. **把断句当完整判据。** 盆点数那句断在「个别」处，后半句丢了；只能引「不少于六个」这一半，不能替它补后半句（`B26`）。
5. **用六个读数当「盆已完整」。** 作者只给下限，不给距离铺排；六个值全挤在荷载附近，形状判断仍然做不了（`g15`）。
6. **以为传感器远近有依据。** 全部依据是一张示意图（`f10`、`g16`），锥角、交点深度、传感器个数一个数没有；布点只能照图意，不能声称有定量依据。
7. **把荷载级位当已研究过的变量。** 级位靠换锤重或改落高来调，此后一句未提；它对反算值的影响方向与量级全章为零（缺口 6）。
8. **拿本节的盆去和按时程算的响应比。** 本章只写盆，不写峰值荷载与弯沉时程（`g10`），两种数据接不上。

**H2 — 用前必须声明**

1. 场景（四套里的哪一套），以及选它的理由——理由只能来自任务，不能来自本章。
2. 每点锤数与采用值来源；首锤不作数这一条要写明。
3. 锤间间隔是实测还是「约」。
4. 盆点数与传感器间距序列；两者缺一即声明盆不完整。
5. 贴不住的点有几个、怎么处置。
6. 本卡不覆盖：反算、重复性、设备互测、钻芯对照、荷载级位影响、时程分析。
