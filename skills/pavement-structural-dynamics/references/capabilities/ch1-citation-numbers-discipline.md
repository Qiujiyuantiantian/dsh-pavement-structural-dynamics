## R — 原文论点（转述，非摘录）

作者在章末附了编号连续的一批著录，正文用方括号角标回指。实际被回指到的号只有一部分；另有三个号在清单里根本不存在，一处角标写成区间夹横杠的畸形形态，还有三处是同一条著录被排了两遍或两对号指向同一份文献。最集中的问题在 1.5 开头：那一句把「动载下的响应明显异于静力、并影响疲劳寿命」分派给四组人，印出的四个号与清单里同号条目的作者、年份、题目全不相干，按内容反查才对得上另一组号，四个差值恒为同一个数，形态上是整段停在清单扩充之前。p15 两处区间号方向相反，且右端越出清单最大号。同一章里还有一处一个号被两次占用，而被它挤掉的那个号在全章一次都没出现。数字方面，全章除年份外只有六个可复现数，作者用其中两个互相矛盾的速度效应数当立论的两根柱子，而这两根柱子一根没有角标、源头也不在清单内，另一根的归属被记成了单个人。

（见 p10 数据段、p14–p15 角标、p16–p18 著录主体）

**三种形态，三种处置**（不许混为一谈）：

1. **整段平移**（#1–#4，差值恒为 −30）：形态上是整段角标停在清单扩充之前。处置：整段按表改写。
2. **区间越界**（#5、#6，偏 +10 且右端超出清单最大号）：处置见 I.2，**越界即整句作废**。
3. **单点复用**（#7）：同号两用时，第二次必错。处置：按内容给第二次重新定号，并在卡里记明改动。

**另有一处不计入 7 处**：表面波那一段与佛罗里达动力弯沉各用同一个号，前者在清单里没有对应条目，所以只能标「挂错」，给不出正确号——这与 #7 不同（#7 有号可归）。它按「不可纠正」处理。

### I.2 区间号三步（遇区间号一律走完三步才准引）

1. **拆**：把区间展开成逐个号，不许整体当「一组文献」。
2. **查越界**：右端大于清单最大号 → 该号不存在。**越界出现，整句角标作废，不许只删越界那两个。**
3. **对内容**：逐个号回清单看作者／年份／题目，与本句说的是不是同一件事；只保留对得上的那一条（或那几条），条数不符也要写明。

### I.3 账目：著录条数不等于文献篇数

| 项 | 结论 |
|---|---|
| 著录条数 | 66 条，编号连续无缺号 |
| 重复著录 | 1 处（同一条排两遍，一遍截断在「Publica-」） |
| 异号同文 | 2 对（同一篇四人会议论文两个号；同一本剑桥博士论文两个号、题目写法不同） |
| **去重后** | **最多 64 篇** |
| 正文实际回指到的号 | 49 个 |
| 引了但清单里没有 | **3 个**（一个是 0 号，两个越界） |
| 畸形角标、无法定位 | 1 处（区间夹横杠；该四条里混进一条他人专著，不能整捆也不能挑一条） |
| 「未被引用」的 17 条里，其实被引只是号错的 | **9 条** |
| 从头到尾没人引的 | 4 条 |

> 报数纪律：文献量写区间（「66 条著录，去重后不超过 64 篇」），**不写确数**。它影响「综述覆盖度」的判断，不影响「成书年代」的判断。

> 一句话：六个数的三道关**没有一个是全过的**。3 年全年只有「工期」这一层意思；7 个自由度的数对不对不靠这条文献；其余四个连条件都没写。

### I.5 三道关的定义（照此执行，不许简化）

1. **关一 · 有没有角标**：没有角标 → 直接降为「作者转述，原始出处未核」，不得当量值。
2. **关二 · 角标指向的是不是这件事**：把该号回清单，比作者、年份、题目三者与正文描述是否同一件事。对不上 → 该角标作废，数随之降格（**号的错不能靠数看上去合理来补**）。
3. **关三 · 条件齐不齐**：结构、层位、深度、轮载、测点，五样里缺一样即写「条件缺失」；缺三样以上，这个数只能当「有人报过这个量级」。

### I.6 p19 那一页：整页丢弃

清理前的源文件末尾有一个只开不闭的公式环境块，里面是三百余行纯编号（从第 4 章开头附近一直排到它的第三百多个式子），一行一个号，没有任何数学内容。它是第 4 章的编号清单被排到了本章文献之后：**既不是本章的式子，也不能拿去反推第 4 章的式子数**（与第 4 章概览记的块数不符）。该块已隔离到 `books\_quarantine\` 下的独立文件。本章正文本身是 0 个式子。

### I.7 本卡给得出与给不出

| 能给 | 给不出 |
|---|---|
| 一个可以照改的角标纠正表（7 处 ／ 9 条） | 原文献内容是否被正确转述（一条原文都没核；只能凭标题判「落不上」） |
| 一句「这个数能不能当量值」的是／否 | 任何比值、趋势、内插、换算 |
| 「66 条 ≠ 66 篇」的报数口径 | 66 篇的去重后确数（只能说「最多 64」） |
| 一串「不可纠正、只能标记」的清单（畸形角标、转述不符、越界号） | 正确号（源头不在清单内的，改不出来） |
| 成书年代的两端（最新到 2008 年学位论文，最老到 1972 年专著） | 各章公式数、各章页数（本章不给；p19 那页也不能用） |

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章无算例、无实测、无复算；下面四段给「一句正文 ＋ 一个诉求」，输出「能不能引、降到哪一档、停在哪一步」，**不出任何数值**。

**演练一（数：降格）**
输入：「导论里说车速从零提高以后内应力涨了一个百分数，我想拿它证明车速影响很大，行不行？」
→ 判：过三道关——有角标，但角标指向的是四个人的合著而正文写成了一个人；条件五项一项没写（I.4 第一行）。
→ 输出：**降档**——只能写「某研究算过速度效应」，并且必须带「条件缺失」；不得写成「车速影响很大」这个结论。
→ 不输出：任何幅度、任何「每提高多少涨几成」。

**演练二（号：整句作废）**
输入：「正文那个跨四个号的区间，看着像一组同主题文献，我能不能照它建四条索引？」
→ 判：拆号 → 右端越界（清单最大号都不够）→ 条数也对不上，目标其实只有一条（I.2）。
→ 输出：**整句角标作废**，只保留按内容定到的那一条；并在卡里记明「原文印的是越界区间」。
→ 不输出：三条凭区间想象出来的条目。

**演练三（号：先过表）**
输入：「第五节开头那四个号，我按书上印的抄进报告可以吗？」
→ 判：四个号全在纠正表内，且属「整段平移」形态（I.1）。
→ 输出：**先改写再用**；未改写的号不得进卡、不得进引文。
→ 不输出：任何「照印可用」的判断。

**演练四（账目）**
输入：「这本书引了多少篇文献？我想说它综述覆盖很广。」
→ 判：著录条数 ≠ 篇数，有三处重复（I.3）。
→ 输出：**报区间**——「若干条著录，去重后不超过某个数」；并声明「覆盖度」这个判断本卡给不了。
→ 不输出：一个确数，也不输出「覆盖广」这个评价。

**预期输出表**：`诉求｜过几道关｜号是否要改｜降为哪一档｜停在哪一步｜依据页`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 一句话描述（作者／年份／题目任一） | 文本 | 必需 | 缺 → 无法回查，先问 |
| 正文印的号（或「无角标」） | 文本 | 必需 | 缺 → 按「无角标」处理并标注 |
| 位置（页锚点 ＋ 节编号） | 文本 | 必需 | 缺 → 先定位；不许只按标题猜 |
| 要引的是数还是判断 | 枚举 | 必需 | 缺 → 默认「判断」，数一律降档 |
| 是否要比值／趋势／内插 | 布尔 | 条件必需 | 为真 → 直接进停判点 1 |
| 是否要 p19 的编号 | 布尔 | 条件必需 | 为真 → 直接进停判点 3 |

**步骤**

1. **定位**：页锚点 ＋ 节编号，二者缺一不判。
2. **拆号**：区间先展开成逐个号（I.2 第一步）。
3. **查越界**：有号大于清单最大号 → 整句角标作废，跳到第 6 步。
4. **过纠正表**：命中 I.1 七行之一（或那第八处）→ 按表改写，记明改动。
5. **对清单**：逐个号比作者／年份／题目；对不上 → 标「转述与著录不符」，不许当支撑。
6. **判数**（若诉求含数）：走 I.5 三道关，落 I.4 那一行，输出档位。
7. **写输出**：可引的号（或「不可纠正」）＋ 数能不能当量值 ＋ 已改动的记录 ＋ 依据页。

**停判点**

1. 要比值、要趋势、要做内插 → 停（六个数一个都撑不起）。
2. 要 40% 的原始出处 → 停（无角标，清单里也没有那一年的那条试验；改不出号）。
3. 要 p19 的编号、或要拿它反推某章的式子数 → 停（整页不属本章）。
4. 要 66 篇的确数 → 停（只能说「最多 64」）。
5. 要畸形角标定到某一条 → 停（该区间混进他人专著，只能标「无法定位」）。
6. 要「原文献是不是真这么说的」→ 停（一条原文都没核；只能说标题落不上）。

**输出契约**——字段固定：

`位置｜印的号｜是否过纠正表｜改写后｜转述对得上否｜过几道关｜档位（可当量值／某人算过／不可追溯）｜依据页`

表下固定三行：
- **公式状态**：本章无式（本卡无一处可代值）。
- **数值状态**：不出比值、趋势、内插；凡引数必带「条件缺失」。
- **依据页**：p10、p12、p13、p15（数）；p14–p15（号）；p16–p18（著录）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **照书上印的号引 1.5 段。** 那一开头四个号全错，按印的去查四条都指向别人；未过 I.1 不得进卡（`ce-B01`）。
2. **把区间号当一组文献。** 两处区间一拆就出现越界号，条数也不符；越界出现即整句作废（`ce-B02`）。
3. **把 40% 当「只是漏了个角标」。** 它不只是没角标：清单里根本没有那一年的那条试验，源头不在文献表内，纠正表也救不了（`ce-B04`）。
4. **把 7% 写成单人结论。** 那是四人合著的会议论文；单人那篇是另一个号、另一个年份（`ce-B07`）。
5. **把文献条数当篇数。** 三处重复，去重后最多 64（`ce-B09`）。
6. **拿 p19 的编号做任何推断。** 它属第 4 章、已被隔离，且与那一章的式子数不符（`ce-B18`）。
7. **把「标题大致相关」当对上了。** 四例能凭标题判的错引，都是「正文说的那件事」与「标题实际那件事」不是一回事（`ce-B10`）。
