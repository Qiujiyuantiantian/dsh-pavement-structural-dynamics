# ch3-dynamic-modulus-caliber — 动态模量的口径与五项验收

> 卡类型：caliber（术语收窄 + 报告验收清单）｜主要取材：§3.2.1（p49）、§3.3.1.2–3.3.1.3（p53–55）｜挂靠 verified：`f07`、`ce-A08`｜边界素材：`ce-B04`、`ce-B19`（C19）、`g09`、`g10`、`ce-A09`（弯拉与轴向不可互换，见卡 5）
>
> **卡头必读**
>
> 1. **本卡只认一种口径**：正弦稳态下、应力幅除以应变幅、且同时配一个相位角。「动态模量」这四个字在文献里是宽口径的，凡「非静态条件下测出来的模量」都往里装；本书把它收窄了，收窄后的量记作复合模量之模（`ce-A08`、`g09`、`g10`）。
> 2. **本章没有与任何规范数值对照**：既没有 AASHTO 那类典型区间，也没有国内规范的模量取值区间。因此「这个数是不是套规范值填的」不能靠数值比对，只能靠五项条件是否齐来判断。
> 3. **禁止以本章为据主张「动态参数优先于静力参数」**：作者在 3.2.1 立了三项承诺，第三项（与静态参数对比）全章 0 数据，动静比值一个数都没有（`ce-B19`）。
>
> **importance**：critical（理由见 `_ch3_report.md` §2.3）
>
> **公式**：本卡只用一个关系——|E*| = 应力幅 / 应变幅，相位角由滞后时间占周期的比例折算。两者都未与原版面图核对，`〔公式待核〕`；复合模量的实虚部表达式在本章整条缺失（3-10 空号）。
>
> **数值**：本卡不交付任何模量数值（本章 |E*| 没有一个绝对值落地，只有曲线）；A1 为报告审查式演练，**0 个数值结果**。
>
> **页码**：PDF 页序；印刷页 = PDF − 9。
>
> **本章缺位**：两种口径之间的换算（0 处）；与规范数值的对照（0 处）；三轴结果折算成单轴设计输入的规则（0 处）；控制模式全章未统一。

## R — 原文论点（转述，非摘录）

这一节先做一件术语上的事。作者承认外面用得很宽：只要不是在静力条件下量到的模量，各种叫法都能挂上「动态」两个字，回弹的、冲击的、弯拉的，各说各的。他随即把本书的用法收紧到一条：材料在正弦稳态下，应力幅与应变幅之比，另配一个相位角描述两者错开多少。收窄之后，凡不合这三个条件的，他一律归到「广义」那一类，只用来划界，不再给定义、也不给数。接下来他排了三件要做的事：测这套动态模量、再测一路弯拉劲度、以及与前章的静力参数作个对照。前两件后来各自落到专门的小节里；第三件从头到尾没有一张表。术语约定之后，参数的取法落在试验方案里：几个温度、九档频率、三级围压、随温度递减的主压、以及一条应变上限。这五样正是别人拿一份模量报告来问「这个数能不能用」时需要逐项核对的入口。

（见 p49，§3.2.1；五项落在 p54–55，§3.3.1.2–3.3.1.3）

> **出处**：p49（宽口径与收窄、广义动态模量、三项承诺）＋ p54–55（温度、频率、围压、主压与应变上限、控制模式两处说法）。

## I — 判据骨架

### I.1 口径判定：三个条件决定「这个模量是不是本书说的那个量」

| 条件 | 问什么 | 是 | 否 |
|---|---|---|---|
| 波形 | 加载是不是正弦稳态（连续等幅循环，不是一次冲击、不是单调加载） | 可能同口径 | 归入宽口径，不能与本书的 E* 同表比 |
| 量 | 报的是不是应力幅与应变幅之比 | 可能同口径 | 是割线模量、回弹模量、弯拉劲度，另立一行 |
| 配套量 | 有没有同时给相位角与频率 | 可判黏性成分，可进动力模型 | 只有一个数，用途受限 |

三条全过，才叫「本书口径的动态模量」。**三条缺一条，就不能与本书的数放进同一张表**（`ce-A08`）。

### I.2 五项验收：一份模量报告能不能用，逐项勾

| # | 项 | 本章给的取值（转录值） | 缺了会怎样 |
|---|---|---|---|
| 1 | 温度 | 四档：4℃、20℃、40℃、60℃（图注另有一套写法，见 B·H1-5） | 模量对温度极敏感，无温度即无法归位 |
| 2 | 频率 | 九档：0.1／0.2／0.5／1／2／5／10／20／25 Hz | 无频率即无法与车速对应，也无法配对主曲线 |
| 3 | 围压 | 三级：0／100／200 kPa | 无法判它报的是单轴量还是三轴量 |
| 4 | 控制模式 | **本章自己不统一**：p54 写应力控制，p55 写应变控制（`ce-B04`） | 谁被设定没定，模量的算法与截断规则都跟着变 |
| 5 | 应变上限 | 作者声称压在不高于 125 微应变以内 | 无上限即无法判是否已出线性区；且这条上限本身带循环依赖（见卡 9） |

**验收判据**：五项齐 → 这个数可以进「有条件的可用」；缺一项 → 用途收窄一档；缺温度或频率 → 判为「不可用于温频分析」，无论数值多漂亮。

### I.3 本章自己不满足其中一项（这一点必须写明）

第 4 项「控制模式」，本章两页之内给了两个相反的答案：讲主压那一段说走应力控制，讲步骤那一段说走应变控制，中间没有过渡句。**内证偏向应力控制**：那条应变上限、以及「温度越高主压越低」的四档设置，只有在应力控制下才讲得通——应变控制直接设定应变，不必为主压费心。另一条线（3.4 的小梁弯曲）明写应变控制，两条线本就分属两套。所以本卡的用法是：**验收别人的报告时，第 4 项要求对方明确写出；验收本章数据时，按应力控制读，并把这一句争议标出来。**

### I.4 本章拿不到的东西（先声明）

- 宽口径与窄口径之间的换算系数：0 处。
- 与规范的数值区间对照：0 处。
- 动静模量比值：0 处（作者承诺过对比，实际只有一句趋势语）。
- 三轴结果如何折算成单轴设计输入：0 处。
- |E*| 的绝对值：0 处（只有曲线，见卡 2 的读图限制与此处 I.5）。

### I.5 读图限制

本章有六张模量曲线图，其中四张只剩图注一行字、没有图片占位；图 3-19 承载「相位角随温度与频率怎么走」这条核心论证，却连图注都没有。**凡「从图上看出来」的判断，本章只能给趋势，不给数**；要数只能拿自己的试验重做。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章没有任何一个 |E*| 绝对值可当答案样本，下列四段全部输出「齐不齐 / 哪种口径 / 能不能用」，**不给任何算出数**。

**演练一（口径判定，正常路径）**
输入：一份报告，报了一个模量，注明「正弦稳态、应力幅比应变幅」，并给了相位角与频率。
→ 判：波形、量、配套量三条全过 → 属本书口径。
→ 继续：进 I 段的五项验收。
→ 不输出：模量的量级评价。

**演练二（否决：只给一个数）**
输入：报告写「本材料动态模量为某值」，无温度、无频率、无相位角、无控制模式。
→ 判：三条口径条件中，波形与配套量均无据；五项验收缺四项。
→ 输出：**出局**——不能与本书 |E*| 同表；只能记为「未标口径的模量」。

**演练三（否决：拿弯拉劲度顶 |E*| 的位置）**
输入：一份四点弯曲报告，量的是弯拉方向的劲度，另配相位角，要求填进动力模型的 |E*| 一栏。
→ 判：应力状态（轴向受压 vs 纯弯段应变梯度）、试件体积、应变梯度都不同；本章不给换算（`ce-A09`，详见参数完备性那张卡）。
→ 输出：**停**——两个量各自引用、各自标条件，不许互相填位。

**演练四（停：把作者态度当成已验结论）**
输入：一份汇报稿想把「作者认为动态参数更该用」写成「本章已经给出验证」。
→ 判：3.2.1 的第三项承诺（与静力参数对比）全章零数据，动静比值一个都没有；作者在收口处只表了态，没给数（`ce-B19`）。
→ 输出：**停**——只能引作者的态度，不能把它写成已验结论；要主张优先，须另找同材料的静力试验。

**预期输出表**：`口径判定（三条件）｜五项齐缺｜控制模式声明｜能用到哪一步｜不推出的项`。

## A2 — 触发场景（用户口吻）

1. 「审一份报告，看它的模量是实测的还是套规范值填进去的。」
2. 「别人给了一个『动态模量』，我怎么知道跟书里这个 |E*| 是不是一个东西？」
3. 「这份模量报告只写了温度没写频率，能拿去做温度分析吗？」
4. 「报告说控制应力，另一处又说控制应变，我该按哪个理解？」
5. 「我能不能说这个材料动态模量比静态模量大好几倍？」
6. 「三轴室里做出来的模量，能直接当单轴设计输入用吗？」

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 加载波形（正弦稳态／冲击／单调） | 枚举 | 必需 | 缺 → 停：口径判定的第一关 |
| 报的量（幅值比／割线／回弹／弯拉劲度） | 枚举 | 必需 | 缺 → 停：量不同，表不能并 |
| 相位角 | 数值 | 必需 | 缺 → 降级为「无黏性信息」，不进动力模型 |
| 频率 | 数值或数列 | 必需 | 缺 → 判「不可用于频率分析」 |
| 温度 | 数值或数列 | 必需 | 缺 → 判「不可用于温度分析」 |
| 围压 | 数值 | 条件必需 | 缺 → 只当单轴量，不许说三轴 |
| 控制模式（应力／应变） | 枚举 | 必需 | 缺 → 判「算法不明」，须补（本章自己也没统一） |
| 应变上限或实测应变幅 | 数值 | 建议 | 缺 → 不能判线性区，结论降级 |

**步骤**

1. **判口径**：波形 → 量 → 配套量，三条逐条打勾；任一条不过，先归类，不进入数值比较。
2. **查五项**：温度、频率、围压、控制模式、应变上限，逐项记「有/无/不明」。
3. **处理第 4 项的特殊性**：本章自己两页两说，验收时必须要求对方写出；写不出的按「不明」处理，不许替它默认。
4. **定用途**：五项齐 → 「有条件可用」；缺温度或频率 → 「不可用于温频分析」；缺相位角 → 「不可进动力模型」。
5. **查是否与别路混用**：弯拉劲度、回弹模量、冲击模量都不得填 |E*| 的位置（`ce-A09`／`ce-A09`）。
6. **写「不推出的项」**：动静比值、与规范区间的差、三轴折算系数。

**停判点**

1. 要求把宽口径与窄口径的数直接比大小 → 停（无换算，`ce-A08`）。
2. 要求以本章为据主张动态优先 → 停（`ce-B19`，0 数据）。
3. 报告缺控制模式 → 停，先补；补不出则数据只能作量级参考。
4. 要求用三轴结果直接当单轴输入 → 停（本章未给折算）。
5. 要求从本章图上读出某个 (T, f) 下的模量数 → 停（图无刻度与参数，见 I.5）。

**输出契约**——字段固定：

`口径三条件（波形/量/配套量）｜五项（温度、频率、围压、控制模式、应变上限）｜控制模式声明｜可用范围｜不推出的项｜依据页`

表下固定三行：
- **公式状态**：`〔公式待核〕`。
- **数值状态**：本章 |E*| 无绝对值，本卡不交付数值。
- **依据页**：p49、p53–55。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **拿本书的 |E*| 与未标口径的「动态模量」直接比大小**：同名不同义，量级可以差几倍（`ce-A08`）。要比，先按 I.1 三条把对方归类。
2. **把五项验收当成「数值区间验收」**：本章不给任何规范区间，五项只能判「条件齐不齐」，判不了「数对不对」。
3. **以本章为据主张「动态参数优先于静力参数」**：`ce-B19`，第三项承诺 0 数据、动静比值 0 个。作者的态度可以引，证据引不到。
4. **用弯拉劲度或回弹模量填 |E*| 的位置**：`ce-A09`（详见卡 5），两个量不可互换。
5. **照抄本章的温度档而不核图注**：同一批试验的温度标签有好几套写法，图 3-18 的图例前三项带负号（`ce-B12`），与正文的四个正温度不符；温度清单只取 3.3.1.2 那一处。
6. **默认本章数据是应力控制**：两页两说（`ce-B04`），要么写明按应力控制读并标出争议，要么按「不明」处理。

**H2 — 用前必须声明**

1. **口径**：「正弦稳态 + 幅值比 + 配相位角」三条件，缺一条就降档。
2. **五项状态**：逐项写有/无/不明，不写「基本齐全」。
3. **控制模式**：本章未统一，引用前必须表态。
4. **温度与频率的来源页**：本章同一组试验的温度标签有多套，须指明取哪一处。
5. **读图限制**：曲线图只剩图注者，只能给趋势。
6. **数值纪律**：本章 |E*| 一个绝对值都没有落地，凡写出具体数字，必是别人给的和自己算的，不是本章的。

**本章三条覆盖缺口（对本卡的影响）**

| 缺口 | 对本卡 |
|---|---|
| 动静比值（0 处） | 本卡只能判「口径与条件」，判不了「动态比静态优越多少」 |
| 两种口径之间的换算（0 处） | 本卡能判「不是一个量」，给不出「差多少」 |
| 三轴 → 单轴的折算（0 处） | 五项里围压那一项只能判「有没有做」，判不了「怎么用」 |

**不要用本卡做的事**：判一个模量数「准不准」（本章无规范区间）、给动静比值、给宽窄口径的换算式、从图上读数。

**已知硬伤（不影响判据的，列此备查）**：3.2.1 三项承诺第三项未兑现；复合模量实虚部表达式整条缺失（3-10 空号）；(3-9) 把复模量写成两个正弦函数之比；(3-11) 虚部符号与「应变滞后」差一个共轭号。
