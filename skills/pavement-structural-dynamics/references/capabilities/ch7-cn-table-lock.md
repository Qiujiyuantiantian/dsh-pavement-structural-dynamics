# ch7-cn-table-lock — 一张 C、n 表能不能用：六项锁定 ＋ 量纲 ＋ 排序窗口

> 卡类型：参数引用纪律（入口在排除侧，出口给一个受限的排序能力）｜主要取材：§7.1.1.1（p138–140）、表 7-1（p139）、表 7-2（p139）、7-5（p139）｜挂靠 verified：`f05`、`c02`｜边界素材：`b01`、`g06`、`g07`、`g08`、`b06`、`c03`、`b02`、`ce-a03`、`f06`、`b07`、`ce-a09`、`g28`
>
> **卡头必读（三句，顺序不许换）**
>
> 1. **$C$ 的完整量纲是「长度 ×（$K$ 的量纲）的 $-n$ 次方」。本章所有 $C$ 只写到 mm/cycle，后半截缺了。** 而 $n$ 在表 7-1 里跨 1.26–8.70 七档：丢掉的这一截错多少，取决于碰巧用了哪个 $n$。**这不是笔误，是整张表不可移植**——既验不了单位，也反查不出 $K$ 用的是 MPa·m$^{1/2}$ 还是 kgf/mm$^{3/2}$。
> 2. **$C$、$n$ 是回归参数，不是材料常数。** 作者自己列了六项：料种、加载条件、试验方式、试件初始状况、尺寸、支承。六项缺一项，表值就从「条件化可用」变成「查不到出处」。
> 3. **排序只在同一个 $\Delta K$ 窗口内成立。** $C$ 与 $n$ 此消彼长，只看一列会把名次排反；而「窗口在哪」本章没有原始 da/dN–$\Delta K$ 点可查，所以排序只能给「同窗口内谁快谁慢」，给不出「跨窗口谁更抗裂」。
>
> **本章硬约束 3、6 的落点**：量纲那一句必须贴在每个 $C$ 旁边；六项锁定必须逐项打勾。**本章的 $C$ 不可以跨表代算，不可以拿两张表的 $C$ 直接比大小。**
>
> **importance**：high（理由见 `_ch7_report.md` §二）
>
> **公式**：7-1 待核（$C$ 缺量纲、$R$ 零次）；7-4a／7-4b 不可用（$n$ 两个身份）；7-5 待核（log 自变量未加括号、$n$ 在等号两侧）。**本卡的排序示例只用表值，不代任何式块。**

> **数值**：表 7-2 的五个 $C$、五个 $n$、五个 $a_0$ 与表 7-1 的十二组为转录值，未见原图。A1 **0 个数值结果**。

## R — 原文论点（转述，非摘录）

作者把 Paris 型速率式当作那两支断裂力学路线的共同发动机，然后围绕它做了三件事：抄历史值、指出这组值的性质、给一张可比的表。

抄的部分：先用一个反算式把初始缝长从试验里倒推出来，再给一个四项多项式（幂次从一次跳到五次，中间省掉三次项，末项带负号），最后用一条回归式把劲度和拉伸强度换算成速率系数。到这一步，他明确说了一句话——这两样只是拟合出来的截距与斜率，随料种、加载条件、试验方式、试件初始状况与尺寸、支承而变，不是材料固有的量。紧接着他又补一句：那个初始缝长不能凭假设定，得靠试验验证。

表的部分：两张表。一张按温度与频率分栏，列出四类混合料在不同温频组合下的两个速率参数；另一张是某位研究者在固定条件下对五种混合料做的切口小梁直接拉伸，条件——温度、频率、切口宽度、加载形式——全部写在正文，表里只有三列数。作者还在同一段里提了一句频率与车速的对应，把那个频率说成相当于某个车速。

性质的部分：他两次自陈边界。一次是在给出某组著名数值的同一页，说材料在高温下已经不是完全弹性，那组结论代表不了断裂特性；一次是在讨论两段法之前，说那条一条式管全程的路子管不到微裂缝汇合。此外还有一句只在讨论参数时出现、此后全章再没用过的提醒：高周段那个指数大约落在四到八之间，低周段在二附近——而表里最大的那个值已经越过了这条自陈的边界。

（见 p138–140；表 7-1、表 7-2 在 p139，四个试验条件在 p139 正文第 105 行）

## I — 判据骨架

### I.1 六项锁定（逐项打勾，缺一项即降级）

| # | 要锁定什么 | 本章表 7-1 | 本章表 7-2 | 缺了会怎样 |
|---|---|---|---|---|
| 1 | 料种（含级配类型） | 有，但双栏合并单元格使归属可疑 | 有，五种 | 同名料在两半各出现一次，混排即错 |
| 2 | 试验方式 | 无 | 有（切口小梁直接拉伸） | 拉与弯的 $C$ 不可比 |
| 3 | 加载条件（温度、频率） | 有列，但 25 ℃ 那一行频率格是空的 | **无**（写在正文：25 ℃、8 Hz） | 该行/该组无法归因到条件 |
| 4 | 试件初始状况（切口宽度等） | 无 | 有（切口宽 5 mm，在正文） | 切口宽改一次，$a_0$ 与 $C$ 都要重标定 |
| 5 | 试件尺寸 | 无 | 无 | 尺寸效应无法排除 |
| 6 | 支承条件 | 无 | 无 | 简支与弹性支承的 $C$ 不可比 |

> 表 7-2 那张看起来最完整的表，六项里只有三项在表内、一项在正文；表 7-1 六项只有一项半。**「抄表」这个动作本身就丢条件**（`b07`）。

### I.2 量纲检查（第 5 步，本章硬约束 6）

对任何一个 $C$，按下面顺序问：

1. 它后面有没有 $(\mathrm{MPa}\cdot\mathrm{m}^{1/2})^{-n}$？**本章全部没有。**
2. 这个 $n$ 是多少？表 7-1 的 $n$ 跨 1.26–8.70，表 7-2 的 $n$ 跨 2.80–4.32。
3. 把缺掉的那一截按 $n$ 补回去以后，量纲闭合吗？不闭合 → 只能同条件比较。
4. 两张表的 $n$ 不同 → 补回去的指数不同 → **两表的 $C$ 之间不存在统一的换算系数**。

> 结论句（贴在每个 $C$ 旁边）：**「$C$ 的完整量纲 = 长度 × $K$ 量纲的 $-n$ 次方；本章缺后半截，只可同条件比较，不可跨表代算。」**

### I.3 排序窗口：为什么「只看一列会把名次排反」（可复算示例）

速率式 $da/dN=C(\Delta K)^n$ 里，$C$ 定起点高低、$n$ 定随幅值增长的快慢。两种料谁快，取决于 $\Delta K$ 落在哪个窗口：把两条曲线令相等，交点位置是

$$\Delta K^{*}=\left(\frac{C_2}{C_1}\right)^{1/(n_1-n_2)}$$

用表 7-2 的五组表值两两配对算这个交点（十对），结果跨度极大：

| 配对的两种料 | 交点 $\Delta K^{*}$（按表值算） |
|---|---|
| AC-16 对 SMA | 约 $6.8\times10^{-4}$ |
| SA 对 AC-8 | 约 $1.4\times10^{-2}$ |
| SA 对 SMA | 约 $0.43$ |
| AC-8 对 SMA | 约 $3.3$ |
| SA 对 AC-16 | 约 $9.5$ |
| SA 对 MAC | 约 $18$ |
| AC-16 对 MAC | 约 $37$ |
| AC-8 对 MAC | 约 $3.4\times10^{2}$ |
| AC-8 对 AC-16 | 约 $3.3\times10^{4}$ |
| MAC 对 SMA | 约 $5.3\times10^{6}$ |

**读法（三条，缺一不可）**：

1. **交点跨了约十个数量级**——同一张表、同样的五个数，名次可以在任何窗口里翻。所以「谁更抗裂」这个问句，不指定窗口就没有答案。
2. **这些交点数值不能当可用的 $\Delta K$ 用**：$C$ 缺了 $(\mathrm{MPa}\cdot\mathrm{m}^{1/2})^{-n}$，交点也跟着带错量纲；上表的数只能证明「排序会翻」，不能证明「某料的门槛在这」。
3. **正确做法**：在同一份报告的同一 $\Delta K$ 窗口内做相对比较，并把这个窗口写进结论；本章没有原始 da/dN–$\Delta K$ 点，所以**排序只能给相对快慢，不能给倍数、不能跨报告**。

表 7-2 的 $C$ 自身跨 2.73 个数量级、$n$ 跨 1.52；表 7-1 的 $n$ 跨 1.26–8.70。这两组跨度都不支持「$C$ 小就是抗裂好」这种单列读法。

### I.4 「8 Hz 相当 60 km/h」这句话本身不牢

表 7-2 的四个条件里，频率这一项是这样落到实处的：正文把 8 Hz 说成相当于 60 km/h。两条口径一碰就露：

| 口径 | 由 8 Hz 反推的通过时间 | 与 7-43 的对照 |
|---|---|---|
| 表 7-2（正文） | 0.125 s | 与 7-43 在 60 km/h 给的 0.108 s 差约一成半（约 9.3 Hz） |
| 7-43（$T=12L/V$） | 0.108 s（60 km/h） | 系数 12 无出处，见卡 5 |

> **处置**：引用表 7-2 时，频率这一项要写「8 Hz（作者换算为 60 km/h，与 7-43 的 9.3 Hz 差一成半）」，不得只写「8 Hz 等于 60 km/h」。这不是文字洁癖：换一个车速，$C$、$n$ 的适用区间就跟着动。

### I.5 指数与作者自陈区间的冲突

| 项 | 数 | 出处 |
|---|---|---|
| 作者自陈的高周区间 | 4–8 | p138（正文） |
| 作者自陈的低周 | 约 2 | p138 |
| 表 7-1 的 $n$ 跨度 | 1.26–8.70 | 表 7-1（p139） |
| 越界的那一格 | 5 ℃／10 Hz 的 $n=8.70$，越出高周上限 | 表 7-1 |

> 两处必有一处口径不同：要么表里那一格不是高周，要么自陈的 4–8 不是普适界限。**引用时两说并列，不许替作者选一个。**

### I.6 一张 $C$、$n$ 表的审查清单

1. 表头有没有 $(\mathrm{MPa}\cdot\mathrm{m}^{1/2})^{-n}$？没有 → 标「量纲残缺，仅可同条件比较」。
2. 六项锁定齐几项？缺的逐项写出来（I.1）。
3. 温度、频率、料名三样是否同格在场？表 7-1 的 25 ℃ 行缺频率 → 该组不可用（`b06`）。
4. $n$ 落在 1.26–8.70 的哪一档？与 4–8 这句自陈是否冲突？
5. 要排序吗？先问窗口；答不出窗口就只能说「同条件相对快慢」。
6. 有没有混用 $\Delta K$ 与 $K$？（7-1 用前者、7-2 的被积项用后者，同段两套口径，`b02`）
7. 有没有交代应力比 $R$？（全章零次，$C$、$n$ 对 $R$ 极敏感，`ce-a09`）

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章 0 条原始 da/dN–$\Delta K$ 曲线、0 个跨条件对照试验；下面四段给「一张表 ＋ 一个诉求」，输出「能不能用／缺哪一项／停在哪一步」，**不出任何数值**。

**演练一（审查：一张只有 mm/cycle 的表）**
输入：一张四列的表，列头是料名、温度、$C$（mm/cycle）、$n$；对方要算某段路的扩展速率。
→ 判：量纲第一问就不过（缺 K 量纲的 $-n$ 次方那一截）；六项锁定缺试验方式、尺寸、支承。
→ 输出：**不可代算**——只可同条件比较；要写速率，$C$ 的量纲必须由使用者补全并声明。
→ 不输出：任何速率值。

**演练二（排序：五组数排先后）**
输入：「这五种料，帮我排个抗裂先后。」
→ 判：$C$ 与 $n$ 此消彼长，不指定 $\Delta K$ 窗口时名次会翻（I.3）；本章没有原始点，窗口定不下来。
→ 输出：**只能给「同条件、同窗口内的相对快慢」**，并必须把窗口写进结论；不得给倍数。
→ 不输出：排名表里的任何数值或百分比。

**演练三（两条口径打架：频率那一格）**
输入：「表里说某个频率相当于某个车速，我按这个车速再算周期，对不上。」
→ 判：表 7-2 的换算与 7-43 的系数两条口径对不上，差得不是零头（I.4）。
→ 输出：**两条并列写**，并注明后者系数无出处；不得替作者选一条。
→ 不输出：一个「正确的」对应频率。

**演练四（停：要把表值搬到另一个温度）**
输入：「夏天路面温度高得多，这张表能不能直接搬过去用？」
→ 判：六项锁定里温度是最硬的一项；作者在给出某组数值的同一页就否掉了高温段（`ce-a02`）；正文无任何温度函数。
→ 输出：**停**——本章不覆盖温度修正；要么重标定，要么另找来源。
→ 不输出：任何温度修正系数。

**预期输出表**：`诉求｜量纲过否｜六项齐几项｜窗口定得出否｜能不能代算｜停在哪一步｜依据页`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 一张 $C$、$n$ 表（或单组值） | 表 | 必需 | 缺 → 无判据可用 |
| 六项锁定（料种／加载条件／试验方式／初始状况／尺寸／支承） | 六元组 | 必需 | 缺项逐条列出，不得默认 |
| $C$ 的量纲串 | 文本 | 必需 | 缺 → 判「量纲残缺，仅同条件比较」 |
| 要办的事（代算／排序／跨报告比对） | 枚举 | 必需 | 缺 → 先问 |
| 若排序：$\Delta K$ 窗口 | 区间 | 条件必需 | 缺 → 只能给「同窗口相对」，且须标注 |
| 应力比 $R$ | 数值或「未给」 | 条件必需 | 未给 → 结论里必须带「本章未交代 $R$」 |
| 温度与频率是否同格在场 | 布尔 | 条件必需 | 缺一格 → 该行不可用 |

**步骤**

1. **量纲第一问**：$C$ 后面有没有 $(\mathrm{MPa}\cdot\mathrm{m}^{1/2})^{-n}$？没有就先把「仅同条件比较」写上去。
2. **六项打勾**：I.1 表逐行，缺几项写几项。
3. **查空行**：25 ℃ 那一行的频率格是否为空？（表 7-1）空 → 该组剔除。
4. **查指数**：$n$ 落在哪一档？与 4–8 的自陈是否冲突？（I.5）
5. **定诉求**：代算 → 进停判点 1；排序 → 问窗口，答不出进停判点 3；跨报告比对 → 直接判不可。
6. **写结论句**：只许「同条件、同窗口内的相对快慢」，外加量纲残缺那一句。
7. **报缺**：温度、$R$、尺寸、支承，逐项注明本章不覆盖。

**停判点**

1. 要速率数值或要代 7-1 → 停（$C$ 量纲不全，代了也是数值对、量纲错）。
2. 要跨表比大小或跨报告换算 → 停（$n$ 不同，无统一换算系数）。
3. 要一个不指定窗口的排序 → 停（交点跨约十个数量级，名次会翻）。
4. 要把表值搬到另一个温度或另一个频率 → 停（本章无温度函数，高温段被作者自己否掉）。
5. 要应力比 $R$ 的影响 → 停（全章零次）。
6. 要疲劳次数或寿命 → 停（转卡 1：无 $K(a)$、无 $N_f$）。

**输出契约**——字段固定：

`表来源｜量纲过否｜六项齐几项｜$n$ 档位｜窗口｜可否代算｜可否排序｜本章不覆盖｜依据页`

表下固定三行：
- **公式状态**：7-1 待核（缺量纲、无 $R$）；7-5 待核（log 未加括号、$n$ 在等号两侧）；7-4a／7-4b 不可用。
- **数值状态**：转录值，未见原图；表 7-1 六行十列双栏、表 7-2 三列五行。
- **依据页**：p138–140。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把 $C$ 的 mm/cycle 当完整单位。** 缺 $(\mathrm{MPa}\cdot\mathrm{m}^{1/2})^{-n}$；$n$ 跨七档，错多少取决于碰巧用哪个 $n$（`b01`、`g06`）。这是本章最容易被抄错的一处。
2. **拿两张表的 $C$ 直接比大小。** 两表的温度、频率、试件形式都不同，$C$ 差几个数量级属正常；混排后名次由条件决定，不由材料决定（`b07`、`ce-a03`）。
3. **只看一列排序。** $C$ 与 $n$ 此消彼长，不指定 $\Delta K$ 窗口时名次会反转（`f06`、I.3）。
4. **引用时删掉作者的否决句。** 某组著名数值的同一页写着高温下材料已非完全弹性、该结论代表不了断裂特性（`ce-a02`）。
5. **把 25 ℃ 那一行当有效样本。** 频率格空着，该组无法归因到条件（`b06`、`c03`）。
6. **把 $n=8.70$ 那一格当高周值。** 它越出了作者自陈的 4–8（`g07`、I.5）。
7. **默认任何幅值都会推进裂缝。** 门槛 $\Delta K$、$R$、波形与间歇全章零次（`ce-a09`）。
8. **混用 $\Delta K$ 与 $K$。** 7-1 用幅值、7-2 的被积项用绝对量，同段两套口径（`b02`、`g09`）。
9. **拿 7-5 反解 $n$。** log 的自变量没加括号，$n$ 还在等号两侧；表里的 $n$ 是独立给出的，不由该式解（`b05`、`g08`）。
10. **把「8 Hz 相当 60 km/h」当规范值。** 与 7-43 的 9.3 Hz 差一成半，两条口径都不是规范值（`p14`、`g28`、I.4）。

**H2 — 用前必须声明**
