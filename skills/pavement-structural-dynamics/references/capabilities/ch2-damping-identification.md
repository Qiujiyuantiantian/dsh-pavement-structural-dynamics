## R — 原文论点（转述，非摘录）

作者先按成因把阻尼分作三类：介质黏性、材料变形时的内耗、接触面之间的干摩擦；随即把能写成线性形式的那个限定在黏性一类，并加了一条前提——速度不高时该阻力才与速度的一次方近似成正比。随后他引入两级换算量：一级是阻力系数除以两倍质量，另一级是前者与固有角频率之比，后者同时等于 c 除以 2√(mk) 这个式子。按后一级量对 1 的大小关系，他划出三档：小于 1 时特征根成共轭复数，解为带指数衰减包络的正弦，包络使峰值按等比数列递减；等于 1 时两根合为一个，解里出现线性因子乘指数，物体单调趋回平衡；大于 1 时两根是不相等的实数，同样不再往复。他另外明确表态：衰减波形并不满足关于周期振动的定义，所谓衰减周期只是相邻两个同向极值之间的间隔；随后给出两条从实测波形回到阻尼比的路径——相邻峰值之比取自然对数得对数减缩，该量与阻尼比相差一个 2π 量级；或由有阻尼周期与无阻尼周期之比反解。同一页他还并列了两句话：阻尼让周期变长，以及一般可以把有阻尼周期当成无阻尼周期——两句之间没有交代小到什么程度。

（见 p27–p29，§2.2.1.2）

## I — 判据骨架

### I.1 三个入口，三条链，一个输出

| 入口 | 手上有什么 | 走的链 | 输出 |
|---|---|---|---|
| 参数入口 | m、k、c 三个量 | 先算 $c_{cr}=2\sqrt{mk}$〔公式待核〕，再拿 c 与它比大小 | 档位（欠／临界／过） |
| 波形入口 | 一条自由衰减的**同向极值**序列 | 相邻峰比 → 取自然对数得 $\Lambda$〔公式待核〕 → $\zeta\approx\Lambda/(2\pi)$〔公式待核〕 | ζ 的量级 |
| 周期入口 | 有阻尼周期 $T_d$ 与无阻尼周期 $T$（或对应频率） | 由 $T_d=T/\sqrt{1-\zeta^2}$〔公式待核〕反解 | ζ 的量级 |

**两条反算通道不独立**：波形入口用峰比，周期入口用周期比，同一份数据只走一条；两条都走要交代为何两结果不等（本章没有给出取舍规则）。

### I.2 档位判据表（判据只有一条：ζ 与 1 比）

| 档 | 判据 | 解的形状（形式） | 还能不能谈周期与共振 |
|---|---|---|---|
| 欠阻尼 | $\zeta<1$，即 $c<2\sqrt{mk}$〔公式待核〕 | 衰减正弦 $x=Ae^{-\eta t}\sin(\omega_d t+\theta)$〔公式待核〕 | 能，但只能叫「衰减周期」 |
| 临界 | $\zeta=1$，即 $c=2\sqrt{mk}$〔公式待核〕 | $x=e^{-\eta t}(C_1+C_2t)$〔公式待核〕 | **不能** |
| 过阻尼 | $\zeta>1$，即 $c>2\sqrt{mk}$〔公式待核〕 | 两个不等实根拼成的指数组合〔公式待核〕 | **不能** |

判档的**唯一输入**是 ζ（或等价的 c 与 2√(mk) 的比较），与初始条件无关；但 ζ 本身依赖 m、k，换支承或换边界就换一套值。

### I.3 换算链上有两个近似，必须标出来

1. **对数减缩与阻尼比之间还差一个根号因子**。严格关系是 $\Lambda=2\pi\zeta/\sqrt{1-\zeta^2}$〔公式待核〕，只在 ζ 很小的时候才可以说「差 2π 倍」。本章正文把这句近似写成了结论（对应矛盾 C11），**入卡必须写成近似并给适用方向（小 ζ）**。
2. **$T_d\approx T$〔公式待核〕 是工程近似，不是结论**。本章把「阻尼使周期变长」与「一般可认为两者相等」并列，中间没有门槛（矛盾 C8）。因此本卡的输出必须写清走的是「严格档」（用根号因子）还是「近似档」（直接取等），不许含混。

### I.4 机理是前置条件，不是补充说明

线性阻力 $F_d=cv$〔公式待核〕只在**黏性机理 + 速度不大**时才成立。干摩擦（库仑型，幅值恒定）与材料内耗（滞回型，随频率与应变幅变化）都不能用一个常数 c 概括。换句话说：**先判机理，再谈 c 与 ζ**；机理判错，后面整条换算链的输出都没有物理意义。

### I.5 本章拿不到的东西（写卡时先声明）

- ζ 的**经验区间**：0 处。任何「沥青路面 ζ 取 0.0X」都不来自本章。
- **放大系数、相位差、共振峰值、半功率带宽、瞬态衰减时间**：0 处，因为 2.2.1.4 整节缺位。
- 由 ζ 反推**每循环耗能**的等效阻尼折算：0 处。

## A1 — 演练（合成场景，无书中数字）

【合成演练，非书中案例】本章无阻尼算例，下列五条为**否决式/选式**演练：给字段 → 出「走哪条链／停在哪一步」，**0 个数值结果**。

**演练一（参数入口，正常路径）**
输入：m、k、c 齐全，且已知阻力来自介质黏性、速度在「不大」的范围内。
1. 先判机理 → 通过，可用线性 c。
2. 算两倍根号下质量乘刚度作门槛（符号式见 I 段），与 c 比较 → 判档。
3. 输出档位。若判为欠阻尼，再说明后续凡用到「周期」处一律称衰减周期。
4. 不输出：ζ 的数值、放大倍数。

**演练二（波形入口，关键否决：峰比不能直接当 ζ）**
输入：一条自由衰减波形上相邻两个同向峰的高度，其余字段为空。
1. 判「这两个数是不是同向极值」→ 不是同向则先重取。
2. 取比值 → 取自然对数 → 得对数减缩 → 才可谈 ζ。
3. 输出：**「直接拿峰比当 ζ 是错的，中间少两步」**；并标注该链落在近似档。
4. 不输出：具体 ζ 值（本卡不给数值）。

**演练三（否决：机理不是黏性）**
输入：阻力来自接触面干摩擦，报告仍给出一个 c 并据此报 ζ。
→ 输出「**出局**：干摩擦是库仑型，幅值不随速度线性变化，用常数 c 反算的 ζ 没有物理意义」；建议改按每循环耗能折算（本章未给折算步骤，须外部补）。

**演练四（否决：把衰减波当周期振动）**
输入：一条带衰减包络的波形，要求做频谱分析、找共振峰、按整数个周期外推相位。
→ 输出「**出局**：衰减波形不是周期振动，衰减周期只是同向极值的间隔」；外推与频谱分辨率都不成立。

**演练五（停：非欠阻尼还要周期与共振）**
输入：c 已越过临界值（判档见前一段），仍要求给周期、给共振点。
→ 输出「**停**：临界与过阻尼两档运动不再往复，周期与共振这两个概念在这两档没有定义」；若坚持要，须先改系统参数（本章不给改法）。

**预期输出表**：`入口｜机理判定｜档位｜走的链（严格/近似）｜能谈什么｜不推出的项`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入判定）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 路径标识（参数／波形／周期） | 枚举 | 必需 | 缺 → 停，无法选链 |
| m、k（或由几何与材料折出的等效值） | 数值 | 参数入口必需 | 缺 → 只能走波形入口，且无法给档位的绝对边界 |
| c | 数值 | 参数入口必需 | 缺 → 改由波形或周期入口反算 |
| 同向峰高序列（≥2 个） | 数列 | 波形入口必需 | 缺 → 停；异向极值需先换算再取 |
| $T_d$ 与 $T$（或 $f_d$ 与 $f$） | 数值对 | 周期入口必需 | 缺 → 停 |
| 耗能机理（黏性／干摩擦／内耗／混合） | 枚举 | 必需 | 缺 → 停：机理不明时 c 无意义（ce07） |
| 速度量级是否「不大」 | 布尔 | 条件必需 | 缺 → 结论降级为「仅定性」 |
| 坐标原点是否取在静平衡处 | 布尔 | 条件必需 | 缺 → 静位移可能被吞掉，须先复核（ce08） |
| 记录方式（同向极值／过零点／包络拟合） | 枚举 | 建议 | 缺 → 只能给量级，不给比较 |

**步骤**

1. **先判机理**：黏性 → 可用线性 c；干摩擦或内耗 → 出局或改折算（ce07）。完成标准：能写出「耗能机理是什么」。
2. **选链**：参数／波形／周期三者取其一，写清选它的理由。
3. **判档**（参数入口）：算 $2\sqrt{mk}$ 作门槛〔公式待核〕，与 c 比；等价地判 ζ 与 1 的关系〔公式待核〕。
4. **反算 ζ**（波形入口）：相邻峰比 → 取自然对数 → 除以 2π，得近似 ζ〔公式待核〕；若 ζ 不可忽略，改用带根号因子的严格式〔公式待核〕。
5. **反算 ζ**（周期入口）：由 $T_d/T$ 的比值反解〔公式待核〕，并标严格／近似。
6. **校一致性**：两条通道都走过时，比较两结果；不一致就报「数据或机理有问题」，不取平均。
7. **写「不推出的项」**：ζ 是否落在某经验区间（本章无）、共振放大几倍（本章无）。

**停判点**

1. 机理不是黏性，却要求用 c 描述 → 停（ce07）。
2. 系统已判为临界或过阻尼，仍要求周期、频率、共振 → 停（ce11）。
3. 把衰减波形当周期信号做频谱、做相位外推 → 停（ce09）。
4. **问共振放大几倍 → 本章答不了，去 ch4/ch7 找。**（放大系数、峰值、半功率带宽在本章 0 处）
5. 要求给 ζ 的经验取值区间 → 停（本章 0 处，须外部文献）。
6. 只有一条波形、未标是否同向极值 → 停，先重取。

**输出契约**——表格字段固定：

`入口｜机理判定｜档位（欠／临界／过）｜走的链（严格／近似）｜ζ 的量级或区间｜能谈的项｜不推出的项｜依据页`

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把干摩擦或材料内耗写成 c 乘速度**：只有一个机理能写成线性 c（ce07）。出现「接触面摩擦」「沥青内耗」而仍报一个 c，直接判误用。
2. **拿衰减波形当周期振动**：做频谱、算频率分辨率、按整数个周期外推相位，全部不成立（ce09）。报告里写「周期」又同时画衰减包络，是同一个错。
3. **在 ζ ≥ 1 的档位谈周期与共振**：这两档特征根为实根，运动单调（ce11）。「临界阻尼下调继续算 T_d」属典型误用。
4. **无条件写 $T_d=T$〔公式待核〕**：本章把这条近似与「周期变长」并列却无门槛（矛盾 C8，`ch2p17`/`cb08`）。要用须先给 ζ，并说明近似误差可忽略的依据。
5. **把峰比直接当 ζ**：中间少了对数与 2π 两步；且严格式还带 1/√(1−ζ²)（矛盾 C11，`cb11`）。
6. **要求本卡给 ζ 的经验区间**：本章 0 处。沥青类材料的 ζ 取值必须回 ch3 或外部文献。

**H2 — 用前必须声明**

1. **耗能机理**（黏性／干摩擦／内耗／混合）：不声明，c 与 ζ 都无意义。
2. **速度量级**：线性 c 的前提是「速度不大」，本章未量化，须自己交代适用范围。
3. **坐标原点**：取静平衡处才允许不计重力；换原点后静位移不再是常数偏移（`ce08`）。
4. **近似档还是严格档**：换算链上两处近似（对数减缩的根号因子、有阻尼周期取等〔公式待核〕），输出必须注明走的是哪一档。
5. **公式状态**：本卡所有式子 `〔公式待核〕`；`(2-41)` 与 `(2-42)` 的符号口径在同一页就不一致（矛盾 C3，`cb03`），引用时以写进运动方程的那一版为准。
6. **字母口径**：衰减指数在同一页出现两个字母（矛盾 C4，`cb04`），本章从未声明二者相等；引用时统一到一个，并写明「原文另用一字母」。
