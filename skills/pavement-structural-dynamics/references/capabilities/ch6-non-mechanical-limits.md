# ch6-non-mechanical-limits — 雷达、超声、激光各能到什么程度

> 卡类型：能力天花板（三种非力学手段，落点是「不能给值」）｜主要取材：§6.5.1–§6.5.3（p133–p135）｜挂靠 verified：`p17`、`p18`｜边界素材：`B28`、`f13`、`f14`、`f15`、`g01`、`g03`、`g11`、`g12`、`g13`、`g41`、`g42`
>
> **卡头必读**
>
> 1. **三节的落点都是「给不出值」，不是「怎么测」。** 雷达只到界面位置（缺波速与标定）、超声只到排序（缺测强曲线）、激光只到位移（缺检测结果与真值的对齐）。凡把这三样写成能量化的手段，就是替本章没有的内容背书。
> 2. **这一节的三种手段里，两种与力学无关。** 雷达量的是电磁波走时，激光量的是光学量；它们被并进来，是因为工程上一起用，不是因为它们能算模量。
> 3. **6-53 与 6-3 是同一个式子换了字母，而它的单位还差 $\sqrt{1000}\approx31.6$（本章硬约束 7）。** 标注写 E 用 MPa、ρ 用 g/cm³；按这两个单位直接代，结果要再乘约 31.6 才回到 m/s。
> 4. **全章唯一一处「标定」属单台设备。** 那是激光那台的光电流—位移线，不是检测结果与真值的对齐；设备标定、传感器标定、与钻芯或开挖的对照，三项皆无（`g42`）。
>
> **importance**：medium（理由见 `_ch6_report.md` §2.8）
>
> **公式**：只引 6-53〔公式待核〕，且必须连单位那句一起引；6-3 与 6-53 同形，不并引。
>
> **数值**：本卡出现的数只有单位差 31.6 与一组代值示例（属换算纪律，在 I 段与 B 段）；A1 **0 个数值结果**。
>
> **页码**：PDF 页序 p133–p135；印刷页 = PDF − 9。

## R — 原文论点（转述，非摘录）

作者补三种手段，各给一段原理。雷达那一节说：特高频电磁波往下发，遇到介电性质变化的界面就反射，按三个界面分成小、中、大三种循环来读回波，就能判断路面内几个界面的位置；另外列了四个技术方向，又说射频在吉赫以上。超声那一节说：频率超过两万赫兹的弹性波，靠吸收、反射、波速三件事；波速与强度、密实度、模量、泊松比相关，并给了一条纵波速的式子——那条式子和前面纵波速那一块完全同形，只换了字母，而单位标注写的是兆帕与克每立方厘米。激光那一节说三条原理：衍射条纹数、光电转换后的电流变化、光的飞行时间差，分别用于纹理、弯沉与平整度；其中光电那一段给了一条光电流与位移之间的关系线。三节都没有精度、没有标定、没有一条实测剖面，也没有一个算例。

（见 p133–135，§6.5.1–§6.5.3）

## I — 判据骨架

### I.1 三手段的能力天花板

| 手段 | 输入（现场能拿到的） | 判据 | 输出 | 天花板卡在哪 |
|---|---|---|---|---|
| 雷达 | 回波走时、三个界面的回波序列 | 界面位置（走时突变处） | 界面在哪 | 换厚度要该层电磁波速与标定，两者皆无 → **只到界面** |
| 超声 | 走时 → 波速；吸收与反射的强弱 | 波速高低 | 排序 | 波速换强度要测强曲线，全章无 → **只到排序** |
| 激光 | 条纹数、光电流、光时差 | 位移或纹理的相对变化 | 相对量 | 与真值的对齐无 → **只到位移** |

### I.2 雷达：界面位置不等于层厚（`p17`）

1. **缺波速**：走时换厚度必须知道该层电磁波速，并做标定；本章两个都没有。
2. **缺精度与实测**：全节无误差指标、无一条实测剖面，只有三个界面的读法（`f13`）。
3. **频带两句不自洽**：一处写 100–1000 MHz，一处说射频在吉赫以上（`g11`）；读的人无法判断哪个是工作频段。
4. **后果**：雷达给的是「界面在哪」，不是「层有多厚」；而卡 5 的入场券（各层厚度）正挂在这上面。

### I.3 超声：只到排序，且单位差 31.6（`B28`）

| 步 | 动作 | 本章状态 |
|---|---|---|
| 1 | 量走时，得波速 | 式子有（6-53），与 6-3 同形异字母 |
| 2 | 波速 → 强度／密实度 | 要测强曲线，**全章无** |
| 3 | 排序 | 只能比同批、同条件的两点谁高谁低 |

**单位纪律（本章硬约束 7）**：6-53 标注 E 用 MPa、ρ 用 g/cm³。按这两个单位直接代，数值是 111.8 量级；换算成 m/s 还要乘 $\sqrt{1000}\approx31.6$，才回到三千五百上下。**两条路选一条：要么全部换成 Pa 与 kg/m³ 再代，要么在结果上乘 31.6。** 不写这一句，量级差三十倍。

**反解核对（记录在案）**：按标注单位直接代得 $\sqrt{E/\rho}$ 在 111.8 量级；原文同一材料报出的量级在 3500 上下。两数相除 $3536/111.8=31.63$，与 $\sqrt{1000}=31.62$ 吻合到小数点后两位。**这说明差的是单位制（MPa 与 Pa 差 $10^6$、g/cm³ 与 kg/m³ 差 $10^3$，开方后 $10^{1.5}$），不是公式错**——所以 6-53 与 6-3 同形是可信的，要改的只是代入前先统一单位。

> 另一个坑：超声那节的「波速法」与 6.1 那套同名不同法——一个量走时，一个量相位差（`g03`、`g12`）。

### I.4 激光：三条原理，只有一条带标定线（`p18`）

| 原理 | 量什么 | 用途 | 缺什么 |
|---|---|---|---|
| 衍射条纹 | 条纹数 | 纹理 | 与纹理深度的换算无 |
| 光电转换 | 光电流变化 | 弯沉 | 只有一条单台传感器的电流—位移线 |
| 光时差 | 时间差 | 平整度 | 与高程的标定无 |

> 全章唯一出现「标定」二字的地方就在这里，而它是**一台设备的内部关系线**，不是检测结果与真值的对齐（`g42`）。所以它不能给别的手段、别的设备背书。

### I.5 三节共同的缺口

| 缺口 | 三节各自的表现 |
|---|---|
| 精度 | 一个数都没有；全章唯一精度是相位计 1°（`g41`） |
| 标定 | 设备、传感器、钻芯对照三项皆无（`g42`） |
| 实测 | 无剖面、无曲线、无算例（`f13`、`f14`、`f15`） |
| 频率口径 | 六处频段互相越界（`g43`、`A03`） |

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】三节 0 条实测、0 个算例、0 个精度指标；下面四段给「一份成果 ＋ 一个诉求」，输出「能给值／只能排序／只能给位置／停」，**不出任何数值**。

**演练一（雷达：给的是界面还是厚度）**
输入：一份雷达成果，写着某层「厚度多少厘米」，正文只给了回波序列。
→ 判：走时换厚度缺该层电磁波速与标定；本节无精度、无实测剖面（I.2）。
→ 输出：**只到界面位置**——厚度不可得，成果里的厚度数没有依据。
→ 不输出：一个「大概多厚」。

**演练二（超声：能不能给强度）**
输入：一组超声走时读数，诉求是「估这段基层的强度」。
→ 判：波速换强度要测强曲线，全章无（I.3）。
→ 输出：**只能排序**——同批同条件的两点比高低，不能给强度值。
→ 不输出：强度换算值、经验系数。

**演练三（激光：这条标定线能通用吗）**
输入：「激光那台设备有光电流与位移的标定线，能不能拿它给别的手段定值？」
→ 判：那是单台传感器的内部关系线，不是检测结果与真值的对齐（I.4、`g42`）。
→ 输出：**不能**——标定不可移植；别的手段仍是相对量。
→ 不输出：任何换算系数。

**演练四（停：要 6-53 的代值结果）**
输入：「按超声那条式子把波速算出来。」
→ 判：式子与 6-3 同形，但单位标注是 MPa 与 g/cm³；单位不统一，量级会差出三十倍上下（I.3）。
→ 输出：**先停**——要么统一到 Pa 与 kg/m³，要么声明结果已乘那个换算系数；否则不给数。
→ 不输出：一个不声明单位的波速。

**预期输出表**：`手段｜成果声称什么｜本章能给什么（位置／排序／相对量）｜停在哪一步｜依据页`。

## A2 — 触发场景（用户口吻）

1. 「雷达说基层十八厘米，这个数能直接用吗？」
2. 「超声测出来的波速，能不能换算成强度或者模量？」
3. 「那台激光设备有标定线，是不是就算标定过了？」
4. 「雷达那一节一会儿说一百到一千兆赫，一会儿说吉赫以上，到底哪个？」
5. 「超声那条式子代进去数小得离谱，是不是单位错了？」
6. 「这三种手段里，哪一种能给设计用的绝对值？」

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 手段（雷达／超声／激光） | 枚举 | 必需 | 缺 → 先问 |
| 成果声称的产出（厚度／强度／位移／界面） | 文本 | 必需 | 缺 → 判不了越界 |
| 原始量（走时／波速／电流／条纹数） | 数值 | 必需 | 缺 → 无法回溯 |
| 该层电磁波速与标定（雷达专用） | 数值 ＋ 文本 | 条件必需 | 缺 → 厚度不可得 |
| 测强曲线（超声专用） | 曲线 | 条件必需 | 缺 → 只能排序 |
| 单位制（Pa 与 kg/m³，或 MPa 与 g/cm³） | 枚举 | 必需 | 混合单位 → 先统一再算 |
| 是否与钻芯或开挖对照 | 布尔 | 条件必需 | 无 → 只可相对量 |

**步骤**

1. **认手段**：三节口径不同，先定是哪一种（注意「波速法」同名不同法）。
2. **认产出**：成果声称的是位置、厚度、强度还是位移——越界的先标出来。
3. **查缺件**：雷达查波速与标定；超声查测强曲线；激光查与真值的对齐。
4. **统单位**：凡用 6-53，先统一到 Pa 与 kg/m³，或声明已乘 31.6。
5. **定颗粒度**：只到位置／只到排序／只到相对量，三选一，不许升级。
6. **写不做的项**：精度、标定、厚度、强度值、跨设备通用。
7. **出判决**：能给什么 ＋ 给不了什么 ＋ 依据页。

**停判点**

1. 要雷达给厚度 → 停（缺波速与标定）。
2. 要超声给强度值 → 停（缺测强曲线）。
3. 要激光给绝对位移 → 停（只有单台设备的内部关系线）。
4. 用 6-53 却不声明单位 → 停（差 31.6 倍）。
5. 要三者的精度比较 → 停（全章 0 个精度指标，「精度高」是形容词）。
6. 要跨设备沿用标定 → 停（标定不可移植）。

**输出契约**——字段固定：

`手段｜成果声称｜本章能给（位置／排序／相对量）｜缺件清单｜单位声明｜本章不覆盖｜依据页`

表下固定三行：
- **公式状态**：6-53〔公式待核〕，与 6-3 同形，不并引。
- **数值状态**：本章 0 个精度指标；唯一带数的是 31.6 这个单位差。
- **依据页**：p133–p135。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把雷达的界面当层厚。** 走时换厚度缺该层电磁波速与标定（`p17`、`f13`）；厚度这一环一空，卡 5 的入场券就悬空。
2. **拿雷达的频带当已定。** 一处 100–1000 MHz、一处吉赫以上，两句不自洽（`g11`）；引频带必须两处都写，或干脆不引。
3. **用超声波速换强度。** 缺测强曲线；三项可用信息里只有「扩散」那条能出量，而它与 6-3 同形（`f14`、`g12`），仍要标定。
4. **按 6-53 标注的单位直接代。** E 用 MPa、ρ 用 g/cm³ 时结果要乘 $\sqrt{1000}\approx31.6$（`B28`）；或统一到 Pa 与 kg/m³。这条不写，量级差三十倍。
5. **以为激光那一条标定线能通用。** 它是单台传感器的光电流—位移关系，不是结果与真值的对齐（`g42`、`g13`）；设备标定、传感器标定、钻芯对照三项全章皆无（`A17`）。
6. **拿「精度高」当依据。** 全章唯一具体精度是相位计 1°；其余是形容词（`g41`）。
7. **把三种手段写成同一类。** 雷达量电磁波、激光量光学量，只有超声与结构动力学同族；章首只承诺三种手段，6.5 又加三种且没有回头补（`g01`）。
8. **按名字认「波速法」。** 6.1 那套量相位差，6.5.2 那套量走时，同名不同法（`g03`、`g12`）。

**H2 — 用前必须声明**

1. 是哪一种手段、用的哪一节口径。
2. 成果的颗粒度：位置／排序／相对量，三选一。
3. 缺件：电磁波速与标定、测强曲线、与真值的对齐——逐项写明缺哪一项。
4. 单位制与换算；凡用 6-53 必须带 31.6 那句或改用 SI。
5. 本章不覆盖的：精度、标定、厚度、强度值、跨设备通用。

**本章缺口对本卡的影响**

| 缺口 | 对本卡 |
|---|---|
| 精度（0） | 无法给误差，也无法比较三手段 |
| 标定（三项全缺） | 三者都只能作相对量 |
| 实测剖面（0） | 雷达的「三个界面」读法无实例 |
| 测强曲线（0） | 超声停在排序 |
| 单位统一（否） | 6-53 必须自带换算纪律 |

**不要用本卡做的事**：给层厚、给强度值、给绝对位移、给精度、给跨设备标定、把三种手段并列成同一种能力。

**已知硬伤（备查）**：雷达频带两句不自洽、无精度无标定无实测（p133–134）；超声三条信息只有一条出量、6-53 与 6-3 同形异字母且单位差 31.6（p134–135）；激光三条原理量程与分辨率全无、唯一标定属单台设备（p135）。
