## R — 原文论点（转述，非摘录）

作者先给这件事一个用途：敲出一根梁的频率之后，得有个独立算出来的数放在旁边，才知道「测到的是不是这根梁、这一阶」。办法沿用前面一章的能量法：把长梁当成只有等效重量、自身质量不计的梁，于是有两种支承各自的周期式。他把手边能拿到的三个量代进去——截面与长度、材料密度、以及一个从弯曲试验那边取来的模量值。四个数就这样算出来了：两个温度、两种支承各一个。接着他把两个支承的理论频率相除，得一个比值，再把这套结果与实测并排放，指出实测的简支频率比悬臂高、而两条式子相除也给出同样的趋势，于是认为这套取阻尼的路子走得通；同一段还写了两支承频率之间的一个固定倍数。理论值整体比实测低一截，作者把它归到支承简化和推导误差，没有再往下查。表格只排了两个温度，而方案里说的是四个；那个被代入的模量来自哪种试验、什么加载快慢，正文也没有交代。

（见 p46–47，§3.1.2.1 与表 3-1）

> **出处**：p47（能量法简化、两条周期式与两条频率式、四个理论频率、两个支承的比值、与实测的对照）＋ p47（表 3-1 两行）。

## I — 判据骨架

### I.1 三个输入与一个输出

| 输入 | 本章给的 | 缺失后果 |
|---|---|---|
| 几何（截面、长度） | 方截面 50 毫米见方、长 600 毫米 | 长度错，频率按平方反比错 |
| 密度 | 2.56 g/cm³ | 密度错，频率按平方根错 |
| 一个试取的模量 | −5℃ 取 6000 MPa、10℃ 取 3000 MPa（取自弯曲试验的弯拉劲度） | 模量的来源试验与加载快慢未交代，比较不闭合 |

**输出**：一张「理论—实测」对照表 + 一个判断（夹具做出的是不是简支与悬臂）。

### I.2 四个数与那个比值（逐格带条件）

> 全部为**转录值，未见原图**〔待核原图〕。**四个频率与下表全部数值，都是按 0.6366 与 3.516 算的，不是印出的 0.632 与 3.567**；照印出的系数代值会得 97.1 与 34.9，与表值差 0.7%~1.4%。

| 温度 | 支承 | 理论基频 (Hz) | 实测基频 (Hz) | 实测/理论 |
|---|---|---|---|---|
| −5℃ | 简支 | 96.4 | 103.3（实测表首行标 5℃，疑为 −5℃） | 实测偏高 |
| −5℃ | 悬臂 | 34.4 | 36.8 | 实测偏高 |
| 10℃ | 简支 | 68.2 | 75.6 | 实测偏高 |
| 10℃ | 悬臂 | 24.3 | 28.7 | 实测偏高 |

**两个比值**：两条频率式相除，得 2.79（按 0.6366 与 3.516 复算；正文另写 2.77，按印出系数复算为 2.787——三个数并存，引用须指明取哪一个，`g07`）。实测逐行：2.81 / 2.63 / 2.49。

### I.3 判据：比值同带才算夹具做对

1. 理论比值 2.79 只在**首行**（最低温那一行）与实测对上；温度上去，实测比值掉到 2.63、2.49。
2. 因此判据要写成「**低温行的实测比值应在 2.79 附近；随温度升高会下滑**」，不能写成「实测比值应恒为 2.8」。
3. 比值对模量取值不敏感——这是它比绝对值硬的地方：模量取错一成，单个频率错约半成，而比值几乎不动。
4. 反过来，**绝对值对得上不能证明夹具做对**，比值对得上也不能证明模量取对；两者回答的是两个不同问题。

### I.4 为什么这套对照不能闭环（必须写明）

代入的模量来自弯拉试验（准静态的一路），算出来的是动力响应的频率，再与实测频率比——用一套试验的量去预测另一套响应，这个比较本身不闭合（`ce-A10`）。本章的实测反算比所取模量高 13% 与 21%，作者笼统归因于「支承简化与理论公式的系统误差」。所以本卡的定位是：**搭一个量级对照与一个比值判据**，不是「验证理论」。

### I.5 本章拿不到的东西（先声明）

- 另两个温度的模量取值：0（表只有两行）。
- 简支实际跨距、悬臂自由长度：0。
- 模量来源试验的温度与加载快慢：0。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】表 3-1 的四个数是转录值、且与印出的系数不同源，不作演练答案；下列四段输出「走哪条式、比值是否同带、要不要补几何」，**不给任何算出数**。

**演练一（对照，正常路径）**
输入：方截面长梁的截面与长度、材料密度、一个从别处取来的模量；两种支承各算一遍。
→ 判：走两条周期式再取倒数得频率〔公式待核〕；系数必须用与表值同源的那一组（见 I 段登记表）。
→ 输出：一张两支承对照表 + 一个比值 + 「实测比值是否落在同一带」的判断。
→ 不输出：任何频率数值、任何模量结论。

**演练二（否决：用印出的系数代值）**
输入：照本章印出的那组系数代值，要与表 3-1 对答案。
→ 判：这一组系数与表值不同源，代进去必然对不上（本章自己拿它对答案就差了不到两个百分点）。
→ 输出：**出局**——改用与表值同源的那一组，并在引用处注明「表按这一组算，与印出的系数不符」。

**演练三（否决：一个梁长算两种支承）**
输入：简支与悬臂都用梁的总长代入。
→ 判：简支要两端余量、悬臂要夹持段，实际跨径不可能都等于总长；基频与长度平方成反比，长度差一成频率差两成。
→ 输出：**停**——先补实际跨距与自由长度；补不出则理论值只能当量级。

**演练四（停：拿理论值当验证）**
输入：要求用「理论值与实测值接近」来宣布夹具与公式都没问题。
→ 判：代入的模量来自另一套试验，闭环不闭合；实测反算系统性高于所取模量，本章只归因于「系统误差」而未查。
→ 输出：**停**——理论值只能当量级对照；判夹具只用比值，且只判低温行。

**预期输出表**：`支承｜用的系数组（与表值同源的那一组）｜几何是否分列｜比值是否同带｜能判什么｜停在哪一步`。

## A2 — 触发场景（用户口吻）

1. 「敲出来一个频率，我怎么知道它对应的是这根梁的这一阶？」
2. 「理论算出来和实测差一截，是公式错了还是我测错了？」
3. 「简支和悬臂的理论频率比该是多少，实测多少才算夹具做对了？」
4. 「表里四个频率和书上的式子对不上，是我算错了还是书错了？」
5. 「我用准静态模量去算动力频率，这样比合理吗？」

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不算）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 截面与长度 | 数值对 | 必需 | 缺 → 停：频率与长度平方成反比 |
| 材料密度 | 数值 | 必需 | 缺 → 停：频率与密度平方根成反比 |
| 一个试取的模量（含来源试验与条件） | 数值＋文本 | 必需 | 缺 → 停；来源不明则结论只能到量级 |
| 支承类型（简支／悬臂） | 枚举 | 必需 | 缺 → 停：两式的系数不同 |
| 简支跨距 / 悬臂自由长度 | 数值 | 必需 | 缺 → 理论值只能当量级，且须声明用的是总长 |
| 系数组 | 枚举 | 必需 | 缺 → 默认 0.6366 与 3.516，并注明与印出系数不符 |
| 实测频率（含温度与支承） | 数值对 | 判比值时必需 | 缺 → 只算理论，不做对照 |

**步骤**

1. **列几何**：截面、总长、以及简支跨距与悬臂自由长度（两个不同的数）。
2. **定系数**：用 0.6366 与 3.516 这一组，并在输出里写一句「与印出的 0.632 与 3.567 不符，用印出的会得另一组值」。
3. **算两支承频率**：两条周期式取倒数〔公式待核〕。
4. **算比值**：理论比值与实测逐行比值并排。
5. **判夹具**：只看低温行是否落在理论比值附近；温度上去比值会下滑，属正常。
6. **标闭环**：写明代入的模量来自哪套试验、什么温度与加载快慢；交代不了就写「此处不闭合」。
7. **写「不推出的项」**：模量取值的对错、理论值的修正、另两个温度。

**停判点**

1. 要求用印出的 0.632 与 3.567 对表值 → 停（不同源）。
2. 要求用一个梁长算两种支承 → 停（`ce-B20`）。
3. 要求用理论—实测接近来证明夹具或公式正确 → 停（闭环不闭合，`ce-A10`）。
4. 要求把实测比值恒当 2.8 → 停（只在首行成立）。
5. 要求补另两个温度的理论值 → 停（本章没有那两个温度的模量）。

**输出契约**——字段固定：

`支承｜系数组｜几何（总长/跨距/自由长度）｜理论基频｜实测基频｜比值（理论/实测逐行）｜夹具判断｜闭环声明｜不推出的项｜依据页`

表下固定三行：
- **公式状态**：`〔公式待核〕`；两条周期式共用一个式号。
- **数值状态**：转录值；四个频率按 0.6366 与 3.516 算，与印出的系数不同源。
- **依据页**：p46–47。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **照印出的 0.632 与 3.567 去对表值**：表不是用这组系数算的（`ce-B17`）。这四个数（96.4 / 68.2 / 34.4 / 24.3）与那个比值（2.79）必须按 0.6366 与 3.516 复现；照印出的代值会得 97.1 与 34.9，差 0.7%~1.4%。
2. **用一个梁长同时算简支与悬臂**：本章就是这么干的（`ce-B20`），但实际几何不可能两处都留全长；长度差一成、频率差两成。
3. **拿「理论值与实测接近」宣布夹具或公式没问题**：代入的模量来自另一套试验，闭环不闭合（`ce-A10`）；实测反算比所取模量高 13% 与 21%，本章只归因于系统误差。
4. **写「简支约为悬臂的 2.8 倍」当通例**：实测比值随温度从 2.81 掉到 2.49；理论比值 2.79（按 0.6366/3.516）、2.77（正文）、2.787（按印出系数）三个数并存（`g07`）。
5. **要求补另两个温度的理论值**：表只有两行，方案说的是四个；缺的两个温度没有模量取值。
6. **把 40℃ 写成主曲线参考温度**：本卡不涉及主曲线，但同一句里若提到参考温度，只有 20℃ 能自洽。

**H2 — 用前必须声明**

1. **系数组**：「0.6366 与 3.516，与本书印出的 0.632 与 3.567 不同源」这句必须随数走。
2. **几何分列**：总长、简支跨距、悬臂自由长度，三个数里后两个本章未给。
3. **模量来源**：来自哪套试验、什么温度、什么加载快慢。
4. **闭环状态**：不闭合就写「不闭合」，不许写「已验证」。
5. **比值的适用范围**：只判低温行，且比值随温度下滑。
6. **公式状态**：`〔公式待核〕`；两条周期式共用一个式号，取式时须说明取哪一条。

**本章三条覆盖缺口（对本卡的影响）**

**不要用本卡做的事**：验证理论公式、修正理论值、判模量取值、把比值当不变量、用印出的系数复现表值。

**已知硬伤（不影响判据的，列此备查）**：两条周期式共用一个式号；(3-7)(3-8) 的系数与表值不同源；正文与式子的比值三个数并存；实测反算模量比表取模量高 13% 与 21% 而未查。
