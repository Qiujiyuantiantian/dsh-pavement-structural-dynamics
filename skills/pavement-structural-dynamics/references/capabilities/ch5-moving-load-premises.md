## R — 原文论点（转述，非摘录）

把车轮写进解析解，作者分两步。先写荷载：一个矩形均布压力，沿行进方向与横向各用一对跃阶函数把边线卡住，中心按速度乘时间往前挪；式子里的压强幅值与两个半宽都只是符号。再定边界：横向两条对边简支，行进方向的两端要求位移与应力都衰减到零。后者不是设边界时写的，是解出来之后补的条件；由它反推，板在行进方向必须是无限长。求解走三步：先沿板宽按半波正弦展开，再换到随荷载平移的坐标做傅里叶变换，最后用留数定理把变换积回去。作者没有声明板有限，也没有在设边界时把无限长写进题设。

（见 p101–105，§5.2.1）

## I — 判据骨架

### I.1 三个前提（写代码前逐条核）

| # | 前提 | 原文依据 | 不成立时 | 本章是否明说 |
|---|---|---|---|---|
| 1 | 行进方向无限长（两端位移与应力衰减到零） | p102 边界段；p103 才点出无限长 | 闭式解出局，退到有限元那两路 | 半明说：解完才补 |
| 2 | 横向两侧简支（两条对边挠度与弯矩为零） | 边界式只给了一条边，另一条靠级数形式反推 | 边界不全，解不成立 | 沉默：另一条边全章没有 |
| 3 | 单块矩形均布、中心匀速平移 | 荷载式 | 轮组、双轮、非均布、变速 → 荷载函数须重写 | 明说形状，未说适用范围 |

### I.2 荷载函数怎么写（形式可编码）

1. 横向：一对跃阶相减，框出一条宽度带。
2. 行进方向：再一对跃阶相减，框出长度。
3. 中心：整体按速度乘时间前移（换到移动坐标后，时间只出现在坐标平移里）。
4. 幅值：框内等于接地压强，框外为零。
5. **必须先统一**：横向两条边原文一边写 $y_0$、一边写 $y_c$，而 $y_c$ 全章无定义，$y_0$ 也无定义；取一个，并在代码注释里声明（`B11`）。
6. **不能当设计轮载标准值**：本章给的是「压强 × 矩形」的数学形式，不是荷载规范里的标准值（`g21`）。

### I.3 断点清单（走到哪一步为止）

| 位置 | 状态 | 后果 |
|---|---|---|
| 5-27 | 系数是纯数，缺荷载强度；下游三处却从 $8q_0$ 起 | 荷载强度在链中途消失（`B13`） |
| 5-28 | 两个跃阶项写得完全相同，相减恒零 | 那条积分得不到末行（`B14` 同页） |
| 5-26a 与 5-28 | 变换核一负一正，同一块内部还打架 | 回变换取镜像，波形前后颠倒（`B14`） |

| 5-33 与 5-34 | 系数定义行不可读、两个系数无定义 | 闭式解在最后一步断链（`B26`、`g25`） |

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章 0 个算例、0 个车速、0 个响应值；下面四段给「一块板 + 一个诉求」，输出「能不能走这一路／停在哪一步」，**不出任何数值**。

**演练一（正常路径：判几何）**
输入：一块板条，行进方向两端可按衰减处理，横向两条对边简支，荷载是一块矩形均布、中心匀速前移。
→ 判：三个前提逐条过——无限长对得上、两侧简支对得上、单块匀速对得上。
→ 输出：可以走解析路线；荷载函数按统一符号写成形式；闭式解只当路线图。
→ 不输出：任何挠度、弯矩或应力值。

**演练二（否决：有限板）**
输入：「我这块板四个边都有，想用这套闭式解」。
→ 判：两端衰减这一条只在无限长上成立；有限板的边界式本章没有。
→ 输出：**出局**——退到有限元那两路（见卡 4），或另找解法。
→ 不输出：把有限板「近似当无限长」的结论。

**演练三（否决：有横缝或自由端）**
输入：板在行进方向有横缝，或端部是自由边。
→ 判：解域里没有第二块板，也没有自由端；横缝与自由边都不在模型里。
→ 输出：**出局**——本章只能当背景（卡 5 有词层证据）。
→ 不输出：任何传荷或端部效应的判断。

**演练四（停：要闭式解的可代值形式）**
输入：「把闭式解抄进程序」。
→ 判：系数定义行不可读；分母两处相反；四阶导印错。
→ 输出：**停**——只能交付荷载函数与路线图；要数值走有限元那两路。
→ 不输出：任何系数值或曲线。

**预期输出表**：`三个前提各过否｜能不能走｜停在第几步｜缺什么｜依据页`。

**步骤**

1. **先问几何**：你的板是不是无限长条带？不是就停。
2. **再问接缝**：有没有横缝、自由端？有就停。
3. **核横向边界**：两条对边是否都简支；只给一条边不算。
4. **核荷载**：形状、块数、中心是否匀速；不是单块矩形就重写函数。
5. **统一符号**：横向两条边取一个；四个 $a$ 下标归一；级数指标取一个起头（`B11`）。
6. **写函数**：按 I.2 五步写成可编码形式，幅值与速度留符号。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **你的板是不是无限长条带？** 不是就别引这一路的闭式解：两端位移与应力衰减到零这一条只对无限长成立，作者设边界时并没有写（`A06`）。
2. **有没有接缝？** 有就别把本章当刚性路面分析：接缝与传荷在本章各 0 次，解域里也没有第二块板（`p12`，卡 5）。
3. **照 5-23 抄边界**：只给了一条边，另一条边全章没有；而 $x=0$ 的简支是有限矩形板解法的残留，与无限长互斥。只留横向两条边加两端归零（`B12`）。
4. **照 5-31 编程**：它的分母写成 $(k^2-\alpha^2)^2$，与 5-30 的 $(k^2+\alpha^2)^2$ 相反；板算子作用在「指数 × 半波正弦」上只能得加号那版，所以 5-30 对、5-31 坏——这一步不依赖原图（`B04`）。
5. **把 5-33、5-34 当成品**：两个关键系数的定义行不可读，其中一个全章无定义；闭式解在最后一步断链（`B26`、`g25`）。
6. **按 5-22 直接编码**：同一式里两个横向符号并用；还有四个 $a$ 下标与四套级数起头（`B11`）。不先统一，宽度会自己变。
7. **把 5-27 的系数当完整**：缺荷载强度，系数成了纯数，而下游三处都从带荷载强度的形式起（`B13`）。
8. **变换核混用**：正变换一个符号，回变换那一块第一行又反过来、第二行起再回去；全链只能一个核（`B14`、`g24`）。
9. **把借来的解法名当依据**：那个名字对应的是双向级数的有限矩形板解法，本章只沿一个方向展开、另一个方向走变换，不能按人名去查对照式（`g23`）。
10. **把本章荷载当设计轮载标准值**：它是「压强 × 矩形」的数学形式，不是规范值（`g21`）。

**H2 — 用前必须声明**

1. 板的几何：无限长还是有限；有没有接缝、自由端。
2. 横向边界两条都成立。
3. 荷载是单块矩形均布、中心匀速。
4. 符号已统一（横向两条边、四个下标、级数起头）。
5. 闭式解只到路线图，不能代值。
6. 数值状态：本章 0 个车速、轮压、响应值。
