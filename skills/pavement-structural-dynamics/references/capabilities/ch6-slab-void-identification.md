# ch6-slab-void-identification — 板底脱空：三法里只有一条带门槛

> 卡类型：判据（有／没有的判定 ＋ 两条判定不了的红线）｜主要取材：§6.4.3.3（p132–p133）｜挂靠 verified：`f12`｜边界素材：`B27`、`g24`、`B30`、`B17`、`c04`
>
> **卡头必读**
>
> 1. **三法只交「有没有」，交不出「多大」。** 法一带数是定性的，法二只有一个门槛，法三缺两张诺谟图与两个量的定义；所以本卡的输出是一个是非判断，不是一个尺寸。
> 2. **唯一的数值门槛有三个条件，缺一不可。** 三级荷载、板角、NCHRP 来源，三样同时在场，零点零五毫米才成立；换到板中就换了一套判法。
> 3. **法三的判据量纲是长度，而单位全章没给。** 模量除以地基反应模量得长度，「小于一」是一米还是一毫米差一千倍（`B27`）；这条带不上单位就不进卡，本章确实带不上。
> 4. **两种方法互校在本章失败，且失败得没有方向。** 表 6-6 里一号试样力阻抗法高出一段，二号试样相速法的上限反而更高，大小关系随试样反转；作者把这个结果摆在表里，一句没跟进（`B17`、`c04`）。所以「谁对」这类问题在本卡上无解。
>
> **importance**：high（理由见 `_ch6_report.md` §2.2）
>
> **公式**：本节无带号式子；0.05 mm 是判据数，不是算出来的。
>
> **数值**：本卡只有两个判据数（0.05 mm 与 E₀/K₁ 的阈值 1），都在 I 段与 B 段，不在 A1；A1 **0 个数值结果**。
>
> **页码**：PDF 页序 p132–p133；印刷页 = PDF − 9。

## R — 原文论点（转述，非摘录）

作者先给一个立场：面板与基础局部不接触是普遍现象，他引了两处国外调查做背景。然后给三条识别路径。第一条看盆形——均匀支承时，离荷载越远读数越小；若某处远处读数反超近处，盆就出现异常信号，可判「可能脱空」；他还补了一句比较：板角与接缝边缘比板中最容易出现，所以板角读数与板中读数之比明显超过理论值，也可判板角脱空。第二条做三级荷载下的板角荷载—弯沉图，无脱空时曲线在原点附近与弯沉轴相交，交点离原点的距离有一个人为给的门槛，越往外脱空越重；这条他注明出自美国一个合作研究计划，并说目前认为比较理想。第三条要先用地基反应模量、接缝传荷系数、面板厚度去查两张诺谟图，算出两个量之比，若小于一即判板角脱空，再查图估尺寸。三条路径的能力并不对等：前两条判有无，第三条声称能估尺寸，但图没给、两个量的定义与单位也没给。

（见 p132–133，§6.4.3.3）

## I — 判据骨架

### I.1 三法对照

| 法 | 输入 | 判据 | 输出 | 颗粒度 |
|---|---|---|---|---|
| 一 · 盆形异常 | 沿测梁的一列读数（板中、板角、缝边三处位置的盆） | ①远处读数反超近处；或②板角与板中读数之比明显超过理论值 | 可能有／可能无 | 定性，无门槛 |
| 二 · 三级荷载截距 | 板角处、三级荷载下的荷载—弯沉图 | 曲线与弯沉轴的交点距原点不超过 0.05 mm → 无脱空 | 有／无 | **唯一带数** |
| 三 · 刚度比＋诺谟图 | 地基反应模量、接缝传荷系数、板厚、板角读数 | E₀/K₁ 小于 1 → 板角脱空 | 有无 ＋ 尺寸 | 声称能估尺寸，实际不可执行 |

### I.2 0.05 mm 的三个条件（缺一即失效）

1. **三级荷载**：只打一级、或只打两级，画不出那条交截线。
2. **板角**：原文的这条判法写在板角处；板中的同一读数不能套这个门槛。
3. **NCHRP 来源**：这个门槛是别人建立的、作者转述并背书「比较理想」；脱离来源，它在本章就没有第二个支撑。

> 三条同时在场时，它仍是**一个门槛、一个来源**，不是本卡的通用容差。

### I.3 三法各自断在哪一步

| 法 | 断点 | 后果 |
|---|---|---|
| 一 | 「明显超过理论值」没有理论值的数，也没有「明显」的判据 | 只能判「疑似」，不能判「有」 |
| 二 | 只给门槛，不给「越往外多少算多严重」的刻度 | 能判有无，判不了程度 |
| 三 | 两张诺谟图未给、E₀ 与 K₁ 无定义无单位、相除得长度（`B27`） | 判据带不上单位；尺寸估不出（`g24`） |

### I.4 与「互校」的关系：本章自己给了反例

表 6-6 把两种方法测同一批基层材料的结果摆在一起（本章硬约束 4）：一号试样力阻抗法比相速法高出三到四成；标「充分压实」的那一组，相速法上限反超约一成半。两法若可互校，比值应当稳定，实际随试样换方向；表的编号列只填了两格，试件数量列有四个值，行与行已不再对应（`B17`）。

> 动作：这张表在本卡只承担一句话——**同批材料两法差三到四成且方向不定，不能互校**。任何具体模量都不引，更不能由它反推修正系数。

### I.5 图上读出来的数，一律要带一句

本章八张图没有任何图片元素、两张连图注都没有、三张共用一个文件名（`B30`）。本节没有从图上读出的数，但凡下游把盆形与图 6-20、6-21 的示意对上号，就必须注明「图无坐标数值，只能照图意」。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本节 0 条实测盆、0 张诺谟图；下面四段给「一组读数 ＋ 一个诉求」，输出「有／无／判不了／停」，**不出任何数值**。

**演练一（判无脱空，走法二）**
输入：板角处做了三级荷载，画出荷载—弯沉线，交点落在原点近旁；同时盆形沿距离单调递减。
→ 判：法二的三个条件齐（三级荷载、板角、来源在），交点未越过门槛；法一的盆形也不异常。
→ 输出：**判无脱空**，并写明门槛与来源。
→ 不输出：任何尺寸、任何「基层强度够」的判断。

**演练二（判有脱空，走法一）**
输入：板角与板中的两处盆，板角那处读数沿距离先降后升，远处反超近处。
→ 判：法一的第一款命中（远处反超近处），这一款不需要门槛。
→ 输出：**判有脱空**，性质为「盆形异常」。
→ 不输出：「脱空多大」，也不把板角与板中之比当第二个证据（理论值本章没有）。

**演练三（停：要尺寸）**
输入：「脱空范围有多大，能不能给个数？」
→ 判：法三缺两张诺谟图、缺 E₀ 与 K₁ 的定义与单位；比例判据的量纲是长度，阈值随单位走（`B27`、`g24`）。
→ 输出：**停**——只能判有无，尺寸在本章拿不到。
→ 不输出：任何面积、深度、半径。

**演练四（停：两法谁对）**
输入：「相速法与力阻抗法给出的模量差这么多，信哪一个？」
→ 判：表 6-6 的比值随试样反转，行与行不对应（`B17`、`c04`）；本章无重复性、无钻芯对照。
→ 输出：**停**——两法不能互校；「谁对」在本章无解。
→ 不输出：修正系数、平均值、或「取保守值」。

**预期输出表**：`诉求｜走哪一法｜三个条件齐否｜有／无／判不了｜停在哪一步｜依据页`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 测点位置（板中／板角／缝边） | 枚举 | 必需 | 缺 → 先问；法二只认板角 |
| 荷载级数 | 整数 | 必需 | 少于三级 → 法二不可用 |
| 沿测梁的读数序列（含距离） | 序列 | 必需 | 缺距离 → 法一不可用 |
| 是否同一板、同一时段 | 布尔 | 必需 | 否 → 两处读数不可比 |
| 接缝传荷系数、板厚 | 数值 | 条件必需 | 仅在走法三时必需；缺 → 法三直接停 |
| 地基反应模量的定义与单位 | 文本 | 条件必需 | 缺 → 法三停（`B27`） |

**步骤**

1. **定位置**：板中、板角、缝边分开记；不同位置的读数不进同一张表。
2. **先过法一**：看盆形是否单调；出现远处反超近处即记「异常」。板角与板中之比只作旁证，因为理论值本章没有。
3. **再过法二**：核三级荷载与板角两个条件；齐则画线读截距，对 0.05 mm 门槛；不齐则此法作废，不许降级使用。
4. **法三要么全要么不做**：诺谟图、E₀ 与 K₁ 的定义与单位，四件缺一即整法作废（`B27`、`g24`）。
5. **收口**：输出「有／无／判不了」，并写明走的是哪一法、哪几个条件在场。
6. **写不做的项**：尺寸、位置、程度、谁对——逐项写明本章不覆盖。

**停判点**

1. 要脱空尺寸或位置 → 停（两张诺谟图未给，`g24`）。
2. 要 E₀/K₁ 的判定 → 停（量纲是长度，单位未给，`B27`）。
3. 只有一级或两级荷载却要用法二 → 停（三级荷载是前提）。
4. 拿板中读数套法二门槛 → 停（该判法写在板角）。
5. 要两法互校或修正系数 → 停（`B17`、`c04`）。
6. 要「越往外多少算多严重」的刻度 → 停（本章只给方向）。

**输出契约**——字段固定：

`位置｜走哪一法｜条件齐否｜判据（含门槛与来源）｜有／无／判不了｜本章不覆盖｜依据页`

- **公式状态**：本节无带号式子。
- **数值状态**：只有 0.05 mm 一个门槛，且三条件齐才成立。
- **依据页**：p132–p133。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把法一的「可能」读成「有」。** 法一只给现象与方向，没有门槛、没有理论值；能判「疑似」，判不了「确定」。
2. **用法二却缺三级荷载或换了位置。** 0.05 mm 与「三级荷载 ＋ 板角 ＋ NCHRP 来源」是绑在一起的一组；拆开用就是把别人在特定条件下的结论搬到别处。
3. **用法三判「有没有」以外的任何东西。** 两张诺谟图未给、E₀ 与 K₁ 无定义无单位，相除得长度，阈值 1 随单位走一千倍（`B27`、`g24`）；尺寸、位置、程度三样都拿不到。
4. **拿表 6-6 当两法的对照结论。** 比值随试样反转，行与行不对应（`B17`、`c04`）；它只能证明「互校失败」，不能证明任何一方对。
5. **以为盆形异常只有一个原因。** 作者把脱空当解释，但同一段也承认板中比板角不易脱空；层间接触、基层压缩都会改盆形，本章没有把它们拆开的判据。
6. **从图上读数。** 本章八张图无图片元素、两张无图注、三张共用一个文件名（`B30`）；凡涉及图形的结论只能照图意，不能声称读出了坐标。
7. **把本卡的「无脱空」当承载力合格。** 本卡只判界面接不接触，与结构强度是两件事（卡 3）。

**H2 — 用前必须声明**

1. 测点位置与荷载级数；法二的两个前提要逐条点名。
2. 走的是哪一法；三法不交叉加权。
3. 0.05 mm 的来源（NCHRP）与它的适用位置（板角）。
4. 本章不覆盖的：尺寸、位置、程度、两法互校、图上的定量读数。
5. 若报告引了 E₀/K₁，说明它的单位（本章给不出，等于不能引）。

**本章缺口对本卡的影响**

| 缺口 | 对本卡 |
|---|---|
| 诺谟图（0） | 法三只剩「小于一」这一句，尺寸不可得 |
| E₀、K₁ 定义与单位（0） | 法三的判据带不上单位，等于不可核 |
| 「明显超过理论值」的理论值（0） | 法一永远停在「疑似」 |
| 重复性与钻芯对照（0） | 「谁对」无解 |
| 图形元素（8 张缺） | 任何读图结论只能照图意 |

**不要用本卡做的事**：估脱空尺寸、给脱空位置、给严重程度刻度、做法三的判定、做两法互校、由盆形反推模量。

**已知硬伤（备查）**：法一的「理论值」与「明显」无判据（p132）；法三两张诺谟图未给、E₀ 与 K₁ 无定义（p133）；E₀/K₁ 的量纲是长度、阈值随单位变（p133）；表 6-6 行与行不对应、大小关系随试样反转（p127）。
