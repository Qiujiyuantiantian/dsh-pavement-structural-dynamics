> **卡头必读**

> 1. **这三个数都是「带一句话的观察」，不是「带条件的结论」**：一句上限、两个百分数、一个倍数，三处都缺条件，本章也没有给任何门槛。

## R — 原文论点（转述，非摘录）

三个数分散在三处。第一处在讲主压时：作者先给一条经验式的上限，说试件的应变量不要越过某个很小的值；为了让这条守住，他按温度分别配了四档主压，温度越高配得越低，最高一档与最低一档相差三十倍。作者没有做「同一个温度换两级主压、看模量是否一致」这种线性格校核，也没有说明这四档是怎么定出来的——只说为了把应变压住。第二处在讲围压时：他把结论压在一个频率上，报出两个温度下无围压与最高围压之间的差值，一个不到一成，一个超过三成；紧接着一句，把这处差异连同试验误差一起放过，说可以不记。第三处在讲频率时：他说高温下高频相对最低频的涨幅是「三到六倍」，没说是哪一级围压，也没说是哪条曲线，更没有区分「涨到三到六倍」还是「涨了三到六倍」。三处的共同点是：数给了，条件没给，门槛也没有。

（见 p54、p57–59）

> **出处**：p54（应变上限与四档主压）＋ p57（频率效应的倍数）＋ p59（围压的两个百分数与「可忽略」）。

## I — 判据骨架

### I.1 三个数各自的「引用三件套」

| 数 | 它是什么 | 必须同时写出的条件 | 一旦缺了 |
|---|---|---|---|
| 125 微应变 | 作者声称的应变上限，用于反推主压 | 温度档、对应主压、以及「这是声称还是已验证」的标注 | 会被当成已校核的线性区 |
| 8% 与 31% | 无围压对最高围压的模量差 | 频率（只有一个）、两个温度、围压对（0 与 200 kPa）、单一材料 | 会被推广成「围压影响不超过某个百分数」 |
| 3~6 倍 | 高温下高频相对最低频的涨幅 | 温度、频率对、哪一级围压、哪条曲线、增至还是增了 | 会变成一个凭空多出来的设计系数 |

### I.2 为什么这三处都不能外推（机制，不是谨慎）

- **应变上限**：模量随应变幅上升而下降，于是「超限」这件事会自我掩盖——超限后测到的模量偏低，按偏低的模量反推应变又显得没超限。所以上限不能自证。
- **围压**：围压的作用随偏应力水平与温度升高而放大，低频（长时间加载）时更明显；只在高频（最短加载）处比较，恰好落在它最弱的一端。拿最弱的一端判「可以忽略」，方向就错了。
- **频率倍数**：模量—频率曲线的斜率高温端最陡、低温端趋平，倍数是曲线两端之差；围压既改变整体高度也改变斜率，所以同一个倍数换一级围压就不通用。

### I.3 本章自己还有一处方向问题（必须带进 B 段）

围压那一节的数据里，**无围压的模量反而高于加了最高围压的模量**，方向与「围压使材料变劲」相反。作者没有讨论、也没有回查曲线是否接反，直接用「可忽略」封口（`ce-B23`）。因此这组数据在本章内部连方向都不可靠——它能支撑的最强结论只有「差异存在且量级不小」，支撑不了「可以忽略」。

### I.4 本章拿不到的东西（先声明）

- 误差门槛（差异大到多少算不能忽略）：0。
- 线性校核（同一温度两级主压对比）：0。
- 围压随频率的系统曲线：0。
- 四个温度集的三套写法：方案、图注、正文各一套，未统一（`ce-B13`）。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章这三个数都不作演练答案；下列四段给「报告里的一句话」，输出「能不能引 / 缺哪几件 / 停在哪」，**不给任何算出数**。

**演练一（引数审查，正常路径）**
输入：一份报告写「本材料在高频下的模量比低频高数倍」，并给出温度、频率对、围压、曲线编号。
→ 判：条件五件齐（温度、频率对、围压、曲线、增至/增了）。
→ 输出：「可引，但只能作为该条件截面下的观察」+ 条件清单。
→ 不输出：把倍数当设计系数。

**演练二（否决：把围压的差值推广）**
输入：报告写「围压对模量的影响不超过一成，可以忽略」。
→ 判：本章的两个百分数只在一个频率、两个温度、一个围压对下成立；且其中一个已超过三成；方向还与「围压使材料变劲」相反。
→ 输出：**出局**——不能推广；只能写「在某个频率、某两个温度下，无围压与最高围压之间差多少，其余未统计」。

**演练三（否决：把上限当已验证）**
输入：报告写「应变控制在某个上限以内，故处于线性区」。
→ 判：判「是否超限」需要先有模量，而模量正是待测量；本章没有做两级主压的线性格校核。
→ 输出：**停**——改写为「作者声称的上限」，并补一句「线性区未校核」。

**演练四（停：要求给误差门槛）**
输入：要求给出「差异大于多少就不能算可忽略」。
→ 判：本章零门槛；作者的处理是把它并进「试验误差」，而误差本身也没有给数。
→ 输出：**停**——门槛须外部规范或自定，并写明来源。

**预期输出表**：`引的是哪个数｜条件几件齐｜能不能引｜缺哪几件｜停在哪一步`。

## A2 — 触发场景（用户口吻）

1. 「报告说围压可以忽略，这个结论我能不能直接引用？」
2. 「应变控制在多少以内才算在线性区，书上给的这个数可靠吗？」
3. 「高温下高频比低频高好几倍，这个倍数能当设计系数用吗？」

5. 「我要在报告里写『围压影响小于多少』，该引哪句话？」

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判可引）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 要引的是哪个数 | 枚举 | 必需 | 缺 → 停：三个数条件不同 |
| 该数的条件（温度、频率、围压、曲线） | 四元组 | 必需 | 缺 → 判「条件不全，只能作观察」 |
| 「增至」还是「增了」 | 枚举 | 倍数类必需 | 缺 → 停：两种读法差一个基准 |
| 上限的性质（声称／已验证） | 枚举 | 上限类必需 | 缺 → 按「声称」处理并标注 |
| 误差门槛来源 | 文本 | 条件必需 | 缺 → 只能给差异，不能给「可忽略」 |
| 数据方向是否与机理一致 | 布尔 | 围压类必需 | 缺 → 须自行核对；本章方向相反 |

**步骤**

1. **认数**：先确认引的是哪一个，三个数的条件互不通用。
2. **点条件**：按 I.1 表逐件勾；缺件即降级为「该截面下的观察」。
3. **查方向**：围压那组要核「加围压是变硬还是变软」；本章是变软，与机理相反。
4. **查上限性质**：应变上限只是声称，须注明「线性区未校核」。
5. **裁决措辞**：允许写「在某频率、某温度、某围压对下差多少」；不允许写「围压影响不超过某百分数」「可忽略」。
6. **写「不推出的项」**：误差门槛、线性区、其他频率下的倍数。

**停判点**

1. 要求把围压差值推广成上限 → 停。
2. 要求把应变上限当已验证线性区 → 停（`ce-A05`）。
3. 要求把倍数当设计系数 → 停（`ce-A07`）。
4. 要求给「可忽略」的门槛 → 停（0）。
5. 要求把这几个数搬到别的温度集上 → 停（温度集本章有三套写法，`ce-B13`）。

**输出契约**——字段固定：

`引的数｜条件（温度/频率/围压/曲线）｜增至还是增了｜上限性质｜方向核对｜能不能引｜不推出的项｜依据页`

- **数值状态**：全部为转录值，未见原图；均为单截面观察。
- **依据页**：p54、p57–59。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **写「围压影响不超过某个百分数」或「围压可忽略」**：两个百分数只在一个频率、两个温度、一个围压对下成立；其中一个已超过三成；方向还与机理相反（`ce-A06`、`ce-B23`）。
2. **把 125 微应变当成已验证的线性区**：上限只是作者声称，且判「是否超限」需要先有模量，构成循环依赖（`ce-A05`）。
3. **把「3~6 倍」当设计系数搬走**：缺围压、缺曲线身份、缺「增至／增了」三件（`ce-A07`）；脱离条件它就是一个凭空多出来的数。
4. **说「本章认为高温下围压不可省」**：这是对原文结论的反向重读，不是作者原话（`p10`）。作者的原话是「可以忽略」；我们能说的是「这个结论不可外推」，不是「作者说了反面」。
5. **把四档主压的配法当标准做法**：本章没有给配法依据，也没做线性校核；照抄等于把未校核的假设固化。
6. **跨温度集搬数**：方案、图注、正文三处温度集不同（`ce-B13`）；搬之前先确定取哪一处。

**H2 — 用前必须声明**

1. **是哪一个数**，以及它的三件套（见 I.1）。
2. **上限的性质**：声称，不是已验证。
3. **差异的方向**：加围压是变硬还是变软（本章与机理相反）。
4. **误差门槛的来源**：本章 0，自定须标注。
5. **单截面性质**：所有百分数与倍数都只在一个截面上成立。
6. **数值状态**：转录值，未见原图。

**本章三条覆盖缺口（对本卡的影响）**

| 缺口 | 对本卡 |
|---|---|
| 误差门槛（0） | 本卡只能判「不可外推」，判不了「多大算可忽略」 |
| 线性校核（0） | 本卡只能把上限标为「声称」，标不了「有效」 |
| 围压随频率的系统曲线（0） | 本卡只能给单点差值，给不出趋势 |

**不要用本卡做的事**：给误差门槛、给线性区、把百分数或倍数当设计系数、把「高温围压不可省」当作者原话。

**已知硬伤（不影响判据的，列此备查）**：围压差值的方向与机理相反且未讨论；「若忽略试验误差」这句话本身没有误差数；四个温度集三套写法；图 3-20/3-21 的子图温度与正文冲突。
