## R — 原文论点（转述，非摘录）

三条求解衰减的路子被逐一拿出场，又被逐一打死。半功率带宽那一条，作者先许它一个成立条件——阻尼足够小；紧接着在同句里承认，正因为阻尼小，那两个特征点挨得太近，间距量不准。能用的门槛与测得准的门槛方向相反，他没有再往下接。共振那条要求试件真的走进速度共振：外力与位移之间差四分之一周期的相位，外力恰好被耗散项顶住；作者说混合料很难进到那个状态，设备也有门槛。剩下的一条从位移记录本身出发，式子与试验都省事，于是被选中。选中之后他补了一个模型前提：敲一下只让某一阶振型起来，梁按 Euler–Bernoulli 处理，于是传感器处的位移可以写成一个带阻尼的单自由度衰减解。换算链随之给到：两个峰高相除取自然对数，得对数减缩；再由该量与 2π、与 1−ζ² 的关系解出阻尼比。链条上有两处没缝好——同页一处按隔一个周期取峰（首峰比第三峰），另一处又写成首峰比首峰（比值恒等于 1）；整个间隔口径全章没有一个统一说法。

（见 p44–45，§3.1.1.1；换算链见 p45 的式块；表与小结见 p48–49）

> **出处**：p44–45（三类测法、淘汰理由、单阶假设、衰减解、对数减缩与换算式）＋ p48（表 3-2 八行）＋ p48–49（表后三条小结）。

## I — 判据骨架

### I.1 选法：三支里只有一支在本材料上站得住

| 路子 | 它要的前提 | 在本材料上怎么就废了 | 本章给的数据 |
|---|---|---|---|
| 半功率带宽 | 阻尼小 → 两特征点分得开 | 阻尼小 ⇒ 两点间距本来就窄，间距精度上不去；两条约束互相收紧，可用窗口趋近空 | 0 个（只有定性一句） |
| 速度共振 | 试件进得去共振，靠相位差四分之一周期、外力由耗散项平衡 | 混合料难到这个状态，且对设备有要求 | 0 个 |
| 自由衰减 | 只激起一阶振型，响应按单自由度衰减 | 这个前提本章**也没有判据**，但它是对本材料唯一还能做的 | 表 3-2 八行 |

**选法的判据只有一条**：先用「做得到做不到」淘汰，再对留下来的那一支撑要一个原始量（一条位移衰减波形）。**不要**把三支并列成「三种可选方法」——半功率带宽那一条的成立条件与精度条件是同一句话的两半。

### I.2 换算链：四步，两个岔口

| 步 | 手上有什么 | 做什么 | 输出 |
|---|---|---|---|
| 1 | 一条位移衰减记录 | 定同向极值（必须同向，异向先换算） | 峰高序列 |
| 2 | 相邻两峰，或隔一周期两峰（岔口 A） | 相除、取自然对数 | 对数减缩 Λ |
| 3 | Λ | 由 ζ=Λ/√((2π)²+Λ²) 解〔公式待核〕 | 阻尼比 ζ |
| 4 | Λ 与 T_d（=1/f） | 反推 η=Λ/T_d，再 c=2mη〔公式待核〕 | 有量纲的阻尼系数 |

**岔口 A（取峰间隔）**：本章同时存在「隔一个周期」与「相邻两峰」两种取法，两者差一个因子 2，全章未声明哪种为准。**用前必须声明取的是哪一种**，同一批数据不许混用。

**岔口 B（近似档位）**：ζ 与 Λ 之间严格带一个 1/√(1−ζ²) 的因子〔公式待核〕。本章实测 ζ 最大到 0.2786，已不能算「小」；走精确式还是小量近似，必须写明。

### I.3 读表反查：η 列名的三步核对（全卡最要紧的一步）

拿到一张「阻尼系数」列，按三步判它到底是什么：

1. **看量纲**：真正由 c/2m 来的系数带 1/s；对数减缩无量纲。列头标 1/s 而全列是纯小数 → 疑。
2. **看内部一致性**：该列若无量纲，逐行验 ζ=Λ/√((2π)²+Λ²)。全部命中 → 这一列就是 Λ。
3. **看反读的后果**：若硬按 c/2m 当 η 用、算 ζ=η/ω，得到的值比表值**小 7~103 倍**（低温端近百倍，高温端只有 7 倍）。量级差摆在这里，说明列名错，不是数据错。

> 本章实测（表 3-2，p48，七行非空）：按第 2 步复算，**七行里六行与表内 ζ 列吻合到四位小数**，只有 30℃ 悬臂那一行对不上（表值 0.1855，按同列 1.1201 复算得 0.1755，差 5.4%）。这 5.4% 不改变「列名错」的结论，但那一格不能当复算校验点。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章无阻尼算例可当答案样本（表 3-2 是转录值，不得当演练答案），下列四段全是**淘汰式 / 否决式**演练：给字段，出「走哪支 / 停在哪步 / 能不能进链」，不给任何一个算出数。

**演练一（选法，正常路径）**
输入：目标材料为沥青混合料；设备只有小锤、加速度计与采集器；没有激振器，也没有扫频台。
→ 判：共振那一支进不去（要可控频率扫描与共振状态）；半功率带宽那一支缺带宽与分辨率信息，不成立；只剩自由衰减。
→ 输出：走自由衰减 + 必须采到的原始量（一条同向极值可辨的位移衰减记录）。
→ 不输出：ζ 的大小。

**演练二（否决：报告称用半功率带宽，却不给带宽）**
输入：报告写「阻尼比由半功率点法测得」，只给一个 ζ，无扫频步长、无带宽、无两点位置。
→ 判：成立条件（阻尼小）与精度条件（两点间距够宽）都无法核对，两点位置可能由噪声决定。
→ 输出：**出局**——要么补扫频步长与半功率带宽，要么改声明走自由衰减。

**演练三（否决：把峰比直接当阻尼比）**
输入：一条衰减波形的两个相邻峰高，要求「直接给出阻尼比」。
→ 判：中间少了取对数（得 Λ）与 Λ→ζ 两步；严格式还带一个根号因子。
→ 输出：**停**——先取对数再换算，并声明岔口 A（相邻两峰／隔一周期）与岔口 B（精确／小量）。
→ 不输出：任何数值。

**演练四（停：要同时拿模量与阻尼）**
输入：一份「既要 |E*|(f) 又要 ζ(f)」的模型输入请求。
→ 判：本章阻尼只落在梁的基频那一串档位上，模量扫的是另一套更低的扫频档位；两套频率轴没有交集（`ce-B22`、`p04`）。
→ 输出：**停**——给不出配对的 |E*| 与 ζ；只能分别交付「模量曲线」与「单频阻尼值」，并在报告里写明两轴不相交。

**预期输出表**：`走的哪支｜原始量是否齐｜岔口 A/B 声明｜三条件是否齐｜能给的输出｜停在哪一步`。

**步骤**

1. **选法**：按 I.1 表先淘汰两支撑不住的，写下淘汰理由（不是「不常用」，是「前提做不到 / 精度上不去」）。
2. **验单阶**：看包络是否单一指数、峰比是否随序号漂移、有无拍频。异常 → 停，先带通只留基频再取峰。
3. **取峰并声明间隔口径**（岔口 A）：相邻两峰或隔一周期两峰，只选一，写进输出。
4. **取对数得 Λ**，声明精确/近似（岔口 B）。
5. **换算 ζ**：ζ=Λ/√((2π)²+Λ²)〔公式待核〕；ζ 不小（本章实测最大到 0.2786）时复核是否该走带根号因子的严格式〔公式待核〕。
6. **反查列名**（输入是一张表时）：量纲 → 内部一致性 → 反读后果三步走（I.3）；判为「列名错」则改名 Λ，并在引用处加注。
7. **登记三条件**：温度、支承、该行频率与 ζ 同格写入；空格一律标「未取」，不许填 0。
8. **写「不推出的项」**：阻尼—频率关系、ζ 的设计取值、与模量的配对。

3. 报告只给 ζ、不给温度/支承/频率 → 停，先补三条件。
4. 把半功率带宽列为「可选测法」而不并列「ζ 越小越量不准」 → 停（`ce-A01`）。
5. 要求本章给 ζ 的设计取值范围 → 停（0 处；只有七行实测值）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把表 3-2 第二列当「阻尼系数」用**：列名与数值不符，数值是无量纲的 Λ（`ce-B01`）。照列名套 ζ=η/ω，得到的值比表值小 7~103 倍（低温端近百倍，高温端 7 倍）——不是「差一点」，是差一个到两个量级。
2. **温度标签照抄**：同一组试验有四套温度写法（方案 −20/10/30/50；理论表只有 −5/10；实测表首行写 5；图注写 −5）。首行最可能是漏了负号；方案里的 −20℃ 全章没有数据，不许列入已测温度（`ce-B02`）。
3. **写「简支基频约为悬臂的 2.8 倍」**：这个倍数只在 5℃ 那一行成立；逐行是 2.81 → 2.63 → 2.49，随温度单调下滑（`ce-B03`）。要写就写「随温度从 2.8 降到 2.5」，不许当通例。
4. **拿单频阻尼去配扫频模量**：阻尼落在 7.3–103.3 Hz 那一串基频上，模量扫的是 0.1–25 Hz，两轴不相交（`ce-B22`、`p04`）。凡要「同时取」，先停。
5. **用表 3-2 的温差去做温度效应结论**：这张表里温度与频率完全共线（每个温度只配一个基频），「温度升则阻尼增」与「频率降则阻尼增」在同一批数据上等价，拆不开（`ce-B24`）。要拆，得补第二档频率。
6. **要求本章给 ζ 的设计取值区间**：0 处。只有七行实测值。

**H2 — 用前必须声明**

1. **三条件**：温度、支承、该行频率。三个都写，缺一不引。
2. **列名**：「原表列名 η，数值为 Λ」这句注必须跟着数列一起走。
3. **间隔口径**：相邻两峰还是隔一周期，差一个因子 2（本章两处并存）。
4. **近似档位**：ζ 到 0.2786 时小量近似已无依据，须说明走的是严格式。
5. **单阶检验**：本章没有判据，须自己声明「已看包络为单一指数 / 未检验」。
6. **温度轴参考点**：本章温度轴能自洽的参考温度只有 20℃（`c06` 的三个移位因子 4.52 / −3.26 / −5.28 落在 20℃）；40℃ 不得作为参考温度写出。
7. **公式状态**：本卡所有式子 `〔公式待核〕`；(3-2) 的指数项符号与「振幅递减」相反、(3-3) 括号内写成首峰比首峰（恒等于 1）；换算链以 ζ=Λ/√((2π)²+Λ²) 这一式为准，另两式只作定位。
