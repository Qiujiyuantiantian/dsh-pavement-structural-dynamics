## R — 原文论点（转述，非摘录）

作者在 6.2 开场就把这条路的目的写明：共振法只对弹性体系管用，沥青、黏性土这类材料不行，所以另起一条路——测结构对简谐力的反抗，用共振与反共振极值的位置读模量，用极值之间的落差读阻尼。他先给复模量的最小一套式子（应力、应变、模量、模量取模、阻尼系数、另一种写法），再定义归一化力阻抗，然后按弯曲、纵向、扭转三种受力分别给式。极值判读那一段说：极小对应一端固定一端自由，极大对应一端固定一端简支；后来在弯曲那两式里，极值的归属又写成与另一种边界对应。现场那一节给一张实测表：圆板压在路基上，扫频读力与加速度之比，由极值频率反解剪切波速与剪切模量，再取两个来源的平均作修正值，并与相速法比。设备那一节只有一段话，没有清单。最后到激光那一节，全章唯一一次出现「标定」，是一台传感器的光电流与位移之间的关系线。

（见 p118–p126、p135，§6.2、§6.3.1.2、§6.5.3）

## I — 判据骨架

### I.1 入口：两问选路（先问材料）

| 材料 | 共振法 | 力阻抗法 | 依据 |
|---|---|---|---|
| 混凝土、陶瓷一类弹性体系 | 可用 | 也可用 | p118 |
| 沥青、黏性土一类黏弹材料 | **出局** | 只此一条 | p118（`A08`） |
| 复合、层状、含接触面 | 本章无判据 | 本章无判据 | —— |

> 「出局」不是精度差，是选错工具。共振法读的是弹性体系的固有频率，黏弹材料没有那个东西。

### I.2 中间：力阻抗能读的三样，以及它们各自的断点

| 读什么 | 怎么读 | 断点 |
|---|---|---|
| 两个极值的位置 | $|Z'|$ 曲线的极小与极大对应哪一阶、哪一种边界 | 两种边界的特征括号撞车（`B10`、`B11`）；极值归属前后两处不一致（`g09`） |
| 一个极值差（dB） | 极小与极大之间的落差 → 阻尼 | 表 6-3 两处数值异类、一处列名错、续表表头粘连（`B12`）；整表不进数 |
| 绝对模量 | 由极值频率与几何反解 | 入口式指数丢失（`B09`）；惯性半径幂次差两级（`B13`）；系数 16 与两种读法都不符（`p07`） |

> 三段里只有「极值差随阻尼增大而收窄」这个趋势能留下；其余全部停在「位置能认、数不能算」。

### I.3 出口：三项标定，一项都没有（`A17`）

| 项 | 本章有没有 | 证据 |
|---|---|---|
| 设备标定 | 无 | 6.2.4 只有一段话，无清单、无型号 |
| 传感器标定 | 无 | 力那一列的单位是 V（电压），换算系数未给（表 6-5） |
| 与钻芯或开挖的对照 | 无 | 全章 0 处 |
| 唯一一处「标定」 | 有，但是单台设备 | 激光那台的光电流—位移线（p135） |

> 判据：三项里只要一项都没有，绝对模量就只能作相对量、只可同批横比。**「精度高」这类形容词不许进结论**（`g41`）。

### I.4 表 6-5 的两处错行（硬约束 3，随数带走）

| 位置 | 表里印的 | 按 6-43 应得 | 处置 |
|---|---|---|---|
| 50 Hz 行 | 133.5 m/s | 111.4 m/s | **整行不用**。同表其余十行按 6-43 复算差不超过 0.5%，坏的是首行不是式子 |
| 500 Hz 行 | $c_2$ 与 G 印着 174.5 | 该行应得 177.7；174.5 是 750 Hz 行的值 | **只用 70–180 Hz 那十行**；750 Hz 行整行空着，不作补 |

> 另外三件事使整表不能当绝对量：力列单位是 V、标定系数未给；密度全表未给（G 只能由 G 与修正后的 $c_2$ 反解出隐含密度）；续表把列名整套换掉（$P_c\to P_n$、$|Z'|\to Z'$、$\Omega_{max}\to\Omega_{cmin}$、$c_1\to c_2$、$c_{2corr}\to c_{2,1}$）。

### I.5 符号层：引之前先认字母，不认名字

| 名字 | 字母 | 陷阱 |
|---|---|---|
| 剪切波速 | $c_2$／$c_1$／$c_t$／$c_0$ | 同一量四个字母；柔性路面那页还把剪切波速写成 $c_0$（`g20`） |
| 纵波速 | $c_1$／$c_0$／$v$ | 一维介质与无限介质不分（`g21`） |
| 归一化力阻抗 | $Z'$ 与后半章的 $Z^*$ | 是不是同一个量，全章没有一句交代（`g07`） |
| 阻尼 | $\eta_E$／$\eta_r$／$\eta_n$／$\eta_G$／$\eta$ | 一个损耗因子五种下标，无一处说明是否同值（`g30`） |
| 复模量符号 | $(1+i\eta)$ 与 $(1-i\eta)$ | 同章两种约定，取实部还是取模取决于用哪版（`g39`） |

> 规则：按式子认字母，不按名字认；跨节引用必须写明「此处的 $c_2$ 就是那一节的哪个量」。

### I.6 与共振法的分界只看材料，不看名字

力阻抗法与第 3 章的共振法在读数机构上同源（都是极值），分界只写「能不能测黏弹」（`g06`）。按名字区分两法不可靠：同一个「波速法」在本章还指相速法，一个量相位差、一个量走时（`g03`，卡 8）。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章 0 条力阻抗实测曲线（只有一条图，无坐标数值）、0 个算例；下面四段给「一种材料 ＋ 一个诉求」，输出「走哪条路／能不能给绝对值／停在哪一步」，**不出任何数值**。

**演练一（选路：黏弹材料）**
输入：被测对象是沥青混合料或黏性土，诉求是拿模量与阻尼。
→ 判：入口这一问命中黏弹 → 共振法出局，只留力阻抗法（`A08`）。
→ 输出：**走力阻抗法**；输出颗粒度限定为「相对量 ＋ 趋势」。
→ 不输出：绝对模量、绝对阻尼。

**演练二（选路：弹性材料）**
输入：被测对象是混凝土或陶瓷，诉求同上。
→ 判：可走共振法，也可走力阻抗法；两条都可，差别在设备。
→ 输出：**两条皆可**，并写明走哪条、依据哪一节的假定。
→ 不输出：「两条给同一个数」这类判断（本章无互校数据）。

**演练三（出口：要绝对值）**
输入：「这套设备测出来的剪切模量，能不能直接写进设计文件？」
→ 判：三项标定一项没有；力通道以电压计；表 6-5 两处错行、密度未给（I.3、I.4）。
→ 输出：**不能**——只可作相对量、只可同批横比；「精度高」是形容词不是依据（`g41`）。
→ 不输出：任何修正系数、任何「误差不大」。

**演练四（停：要一段可执行流程）**
输入：「从扫频到出模量，给我一套能照着做的步骤。」
→ 判：入口式指数丢失、特征括号撞车、惯性半径幂次差两级、表 6-3 不可进数（I.2）。
→ 输出：**停**——只能给「极值位置怎么认、极值差怎么读趋势」，给不了从极值到绝对值的流程。
→ 不输出：一套「先读极小再读极大再代式子」的流程。

**预期输出表**：`材料｜走哪条路｜能读到哪一层｜能不能给绝对值｜停在哪一步｜依据页`。

**步骤**

1. **先判材料**：黏弹即排除共振法；这一条不需要阈值。
2. **再认字母**：把 $c_2$／$c_0$／$Z'$／$\eta$ 在本节的所指逐一写明（I.5）。
3. **读极值**：只认位置与落差，不认绝对值；极值归属存疑的，两处都标（`g09`）。

6. **写不做的项**：绝对模量、绝对阻尼、流程化的反解、跨设备比较。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **拿共振法测沥青或黏性土。** 共振法只对弹性体系成立；黏弹材料该走力阻抗法，这是选路问题，不是精度问题（`A08`）。
2. **报绝对模量却不提标定。** 设备标定、传感器标定、与钻芯或开挖的对照，三项一项没有；力那一列还是电压读数（`A17`）。凡绝对量一律降格为相对量，只可同批横比。
3. **把「精度高」当结论。** 全章唯一具体的精度数是相位计 1°；其余「精度高」都是形容词（`g41`）。
4. **用 6-23 复现应力—应变关系。** 指数整段丢失，按印出的式子应力是常数，复模量那一串定义接不上（`B09`、`p05`）；要用就改用文字定义「应力按简谐变化、应变落后一个相位角」。
5. **把 6-31 与 6-34 并引。** 一个是悬臂、一个是两端自由，却共用同一个特征括号 $1+\cosh\cdot\cos$；两种边界的特征方程不可能同式，至多一处对（`B10`、`p06`、`f06`）。
6. **照 6-42 的 $r^2$ 算弯曲模量。** 由 6-33 反解时分母是 $r$ 的四次；差两级幂而量纲都能凑成 Pa，只能靠互引发现（`B13`）。
7. **把表 6-3 的数当代入表。** 两处数值异类、一处列名重名、续表表头粘连；只能留一句「极值差随阻尼增大而收窄」（`B12`）。
8. **用表 6-5 的 50 Hz 行，或 500 Hz 行的 $c_2$ 与 G。** 前者按 6-43 应得 111.4 而列 133.5（其余十行差不超过 0.5%，所以坏的是首行）；后者的 174.5 实属 750 Hz 行，500 Hz 应得 177.7、750 Hz 行整行空着（`B15`、`B16`、`f07`、`c03`、`p08`）。
9. **引 6-43 却不提 a=0.126 m 的出处。** 圆板半径此前一律写作 a，到 6-43 直接代入这个数，此前无说明；0.791 这个系数就建立在它上面（`B14`）。
10. **按名字认量。** 同一剪切波速四个字母、$Z'$ 与 $Z^*$ 未交代是否同量、阻尼五种下标、$(1\pm i\eta)$ 两种约定；按名字检索必错（I.5、`g07`、`g20`、`g30`、`g39`）。

**H2 — 用前必须声明**

1. 材料类别，以及「为什么可以／不可以走共振法」。
2. 走的是哪条路；力阻抗法用到的是位置、落差还是趋势。
3. 力的单位（N 还是 V）与标定状态；三项标定逐项写明。
4. 表 6-5 用了哪十行、避开了哪两处；表 6-3 一个数都没进。
5. 每个字母在本节的所指（$c_2$／$c_0$／$Z'$／$\eta$）。
6. 本章不覆盖的：绝对模量、绝对阻尼、可执行的反解流程、跨设备比较。
