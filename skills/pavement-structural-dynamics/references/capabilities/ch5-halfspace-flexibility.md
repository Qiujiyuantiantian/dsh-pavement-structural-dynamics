## R — 原文论点（转述，非摘录）

半空间这一路的目标是把地基刚度也写成一个矩阵，好与板的刚度相加。作者的搭法是：每个板节点下接一根假想的杆，杆力就是该点的地基反力；每个矩形单元把自身面积的四分之一摊给相邻的四根杆，于是一个节点从周围四个单元收反力。分摊的积分域取一个多边形——单元形心与各边中点连起来。柔度矩阵的意思反过来：在某点加单位力，看各点沉多少；对角元在本点多边形上积分，非对角元按两点距离的负一次方近似。把这个阵求逆，就得到地基刚度，与板刚度相加后解一次线性方程组。作者另加一条：地基反力不随表面的转角变化，求逆之后把转动那几个自由度补零。

（见 p108–110，§5.2.3–§5.2.3.2）

## I — 判据骨架

### I.1 链条六步

| 步 | 做什么 | 判据 | 输出 |
|---|---|---|---|
| 1 | 划节点网格 | 每节点接一根链杆 | 节点与杆一一对应 |
| 2 | 摊派面积 | 每个矩形单元把自己的四分之一面积给相邻四根杆 | 每根杆分到的反力域 |
| 3 | 定积分域 | 以本点为中心，连形心与各边中点成多边形 | 多边形面积 |
| 4 | 建柔度阵 | 对角元在本点多边形上积分；非对角元取两点距离的负一次方 | 柔度矩阵 |
| 5 | 求逆 | 柔度阵求逆得当量地基刚度 | 地基刚度矩阵 |
| 6 | 相加求解 | 与板刚度相加，解一次线性方程组 | 位移与反力 |

### I.2 每一步的判据

- **链杆**：一根杆对一个节点，杆力即反力；不允许一个节点挂两根、也不允许杆跨节点。
- **面积摊派**：四分之一是离散约定，不是实测比例；只对规则矩形网格成立。
- **对角元**：取本点多边形上的积分，被积式带一个距离的倒数（点载沉陷的形式）。
- **非对角元**：两点距离的负一次方，是近似，不是精确影响系数。
- **求逆**：柔度阵必须可逆；求逆前不要先把对角元换成面积（见 B-2）。
- **相加**：地基刚度与板刚度同一位移体系，才能直接相加。

### I.3 角隅与自由边（`A10`）

作者明写：反力与表面倾角无关，所以求逆后再给转动自由度补零。含义是——地基只对竖向位移有反应，板的转角不引起地基反力。板角与自由边附近倾角最大，这条假定在那里最吃亏。作者只给做法，没给失效区间。

### I.4 本章明确拿不到的东西

- 网格多细才够：0。
- 收敛性说明：0。
- 角隅修正系数：0。
- 与实测反力的对照：0 个算例。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章 0 个算例、0 个网格尺寸、0 个反力值；下面四段给「一套建模方案 + 一个诉求」，输出「链条齐不齐／停在哪个假定上」，**不出任何数值**。

**演练一（正常路径：核链条）**
输入：一份半空间地基刚度的建模方案，写明了节点网格、每节点一杆、四分之一面积摊派、多边形积分、求逆后与板刚度相加。
→ 判：六步逐条对得上；对角元是否取本点多边形积分，是这一步的关键。
→ 输出：链条完整；可继续；须声明网格依赖与角隅解耦。
→ 不输出：任何刚度值或反力值。

**演练二（否决：拿面积当对角元）**
输入：方案里写「对角元按那个多边形面积的式子取」。
→ 判：那个式算的是面积，不是柔度；两块被积式只差一个距离因子。
→ 输出：**出局**——按面积取到的对角元会让地基刚度整体尺度错，而且错的倍数是几何量，不是常数。
→ 不输出：任何修正倍数。

**演练三（停：板角附近）**
输入：「用这套模型算板角附近的反力」。
→ 判：反力与倾角解耦、转动自由度补零；板角附近倾角最大。
→ 输出：**停**——角隅区结果不可信；用前必须声明解耦，结论不能进板角评价。
→ 不输出：任何「角隅偏大／偏小」的判断。

**演练四（停：要精度或网格建议）**
输入：「网格划多细才够，误差多少」。
→ 判：四分之一面积摊派是构造性假定，作者没给收敛性说明，也没给网格密度要求。
→ 输出：**停**——只能说「结果依赖网格、只对规则矩形网成立」；精度须自证。
→ 不输出：任何单元尺寸或误差百分比。

**预期输出表**：`六步各齐否｜对角元取对否｜角隅要不要声明｜网格依赖｜停在哪步`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 节点网格（规则矩形？） | 结构 | 必需 | 畸变单元 → 四分之一摊派不成立，停 |
| 每节点是否一杆 | 布尔 | 必需 | 否 → 链条第 1 步不成立 |
| 土体模量与泊松比 | 标量对 | 必需 | 缺 → 柔度阵建不了（本章也不给取值） |
| 对角元取的是哪一块 | 枚举 | 必需 | 取到面积块 → 停（B-2） |
| 是否要角隅、自由边结果 | 布尔 | 必需 | 为真 → 必须声明解耦，结论降级 |
| 网格密度与收敛依据 | 文本 | 条件必需 | 缺 → 只能声明「依赖网格」，不能报精度 |

**步骤**

1. **查网格**：是否规则矩形；畸变单元先停。
2. **查链杆**：一节点一杆，杆力即反力。
3. **查摊派**：四分之一面积给相邻四杆，节点从周围四单元收。
4. **查积分域**：本点多边形（形心与边中点相连）。
5. **认块**：对角元取带距离倒数的那一块，不取只带面积的那一块。
6. **求逆**：柔度阵求逆得地基刚度；不要把面积混进来。
7. **相加**：与板刚度同一位移体系，解一次线性方程组。
8. **声明**：网格依赖、角隅解耦、无非对角精确性。

**停判点**

1. 取面积当对角元 → 停（`B16`）。
2. 板角、自由边要结论 → 停或降级（`A10`）。
3. 要网格密度或误差 → 停（0）。
4. 要模量、泊松比取值 → 停（0，`p13`）。
5. 要应变矩阵、弹性矩阵 → 停（本章无定义，转卡 2）。

**输出契约**——字段固定：

`网格｜链杆｜摊派｜对角元取块｜求逆｜角隅声明｜网格依赖｜依据页`

表下固定三行：
- **公式状态**：5-56 至 5-64 全部〔公式待核〕；对角元所在块无号。
- **数值状态**：本章 0 个模量／网格尺寸／反力值。
- **依据页**：p108–p110。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **用粗网格或畸变单元仍按四分之一面积摊派**：这是构造性假定，作者没给收敛性说明，也没说网格多细才够；结果依赖网格，且只对规则矩形网成立（`A13`）。
2. **照正文那句「对角元由某个式算」取数**：那个式算的是多边形面积，真正的对角元是紧邻上方那个无号块；两块被积式只差一个距离因子，互换即错（`B16`、`g36`）。认块不认号。
3. **把链式等号两侧都照抄**：节点位移列阵与面分布量不能直接相乘，维度对不上；只取插值一次的那一侧（`B22`）。
4. **用组装式里的应变矩阵与弹性矩阵**：两个符号全章只此一见或同名不同物；剪切修正因子到这一节就消失，而厚板与薄板的差别恰在这一点（`B23`，卡 2 的 B-1）。
5. **在角隅、自由边附近用这套**：反力与倾角解耦，那里倾角最大；作者只给做法、未给失效区间（`A10`）。
6. **把这一节的标题当内容**：标题写厚板，正文却用矩形单元离散薄板，两者不能同时成立（`g35`）。
7. **把非对角元当精确影响系数**：两点距离的负一次方是点载沉陷形式的近似，作者未说误差；报结果时必须写明这是近似。
8. **双参数那档的反算**：见卡 1 的 B-4——5-45 把一个参数摆错位，纯量纲可判死，与本节不是同一条链，别混。

**H2 — 用前必须声明**

1. 网格形状与密度；四分之一摊派只对规则矩形网成立。
2. 对角元取的是哪一块（带距离倒数的那块，不是面积块）。
3. 反力与倾角解耦；角隅与自由边结果降级。
4. 非对角元是近似。
5. 数值状态：本章 0 个模量、网格尺寸、反力值。
6. 与卡 2 的边界：应变矩阵、弹性矩阵不在本卡。
