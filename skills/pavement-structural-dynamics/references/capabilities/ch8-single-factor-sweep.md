# ch8-single-factor-sweep — 单因素扫描：一个因素、两个指标，差一个量级

> 卡类型：方法卡（怎么扫、怎么读、门槛在哪）｜主要取材：§8.2.2.4 的 5)6)7)（p173–177）、§8.3.2.4 的 5)（p190–191）、§8.3.2.5 后两个无号小节（p192–193）、表 8-2～8-9（p174–177）｜挂靠 verified：`f07`、`p10`、`p19`、`c04`｜边界素材：`c05`、`c12`、`c13`、`p20`、`ce-b18`、`p28`、`g16`、`ce-b13`
>
> **卡头必读（四句，顺序不许换）**
>
> 1. **一次只动一个因素，两个指标分报。** 本章所有敏感性段落都是这个形状：改车速、改阻尼、改模量、改厚度，每一轮只动一个，位移与应力各报各的。**把两个指标合成一个「综合影响」就废了这张卡。**
> 2. **判据是相对差，不是绝对值。** $(\text{最大}-\text{最小})/\text{最大}$。作者用的门槛是定性的：2% 与 3.5% 判不显著，15% 与 19% 判显著。**这是他的口径，不是统计检验，卡里必须原样标成「定性门槛」。**
> 3. **两个指标差一个量级。** 位移对车速与阻尼都钝（2–3.5%），应力对同一批因素敏（15–20%）。**同一组算例，报位移会得出「没什么影响」，报应力会得出「影响明显」。两个都对，说的是不同的事。**
> 4. **三处口径陷阱，一步踩一个。** 模量在本章有三个基准（680／700／600 MPa），敏感性曲线的起点不可比；两档平整度只有「较好／较差」四个字、没有 IRI；表 8-6 的 ζ=0.15 那格 0.517 破坏整行单调。
>
> **本章硬约束 5 的旁注**：本卡的四组数全部来自移动恒载（车速 60 km/h、单轮、ζ=0.1），引用时荷载口径照卡 1 的 I.4 写。
>
> **importance**：high（理由见 `_ch8_report.md` §二）
>
> **公式**：本卡的判据不依赖任何带号式子；8-2～8-8 那一组只作定位，均不可代。
>
> **数值**：本卡的四组数可复算（每个百分比都写算式）。A1 **0 个数值结果**。
>
> **页码**：PDF p173–p177、p190–p193；印刷页 = PDF − 9。

## R — 原文论点（转述，非摘录）

8.2.2.4 的后半段是一条一条扫的：先把车速从低速推到高速，报出位移与铺装表面横向拉应力随车速的变化；再把阻尼比从很小扫到很大，同样报两个指标；然后做一次静力与动力的对照。作者对每一条都给了结论句，用的词是「影响不明显」「影响较明显」这一类，并把百分比写进正文——位移那一侧是百分之二到三点五，应力那一侧是百分之十五到二十。

8.3.2.5 之后还有两个没有编号的小节，变量换成铺装模量与厚度，指标只剩表面横向拉应力一个。模量那一条从低模量推到高模量，应力先是涨得快、后来涨得慢；厚度那一条从四厘米改到六厘米，应力降了一成半。作者还顺手加了一句刹车：模量提高会让裂尖驱动力变大，但这不等于更容易开裂。

整章没有一次重复性试验、没有一条误差带；所谓「明显」与「不明显」全部由这两个百分比的分界来判。作者自己也承认，某些档位的平整度只有定性描述，没有对应的 IRI 值。（p173–177、p190–193）

## I — 判据骨架

### I.1 判据（三条同时成立）

$$\text{相对差}=\frac{\text{最大值}-\text{最小值}}{\text{最大值}}$$

1. **一次只动一个因素**；动两个就不许把差值记在其中一个名下。
2. **两个指标分报**，不合并、不加权。
3. **门槛是定性的**：约 2%–3.5% 判不显著，约 15%–20% 判显著（作者口径，不是统计检验）。

### I.2 四组数：同一批算例，两种读法

| 因素 | 位移 | 应力量级 | 条件 |
|---|---|---|---|
| 车速 40→120 km/h | 0.628→0.615 mm，**−2.1%** | 0.133→0.113 MPa，**−15.0%** | 移动恒载、ζ=0.1、60 km/h 为基准档 |
| 阻尼比 0.01→0.2 | 0.637→0.615 mm，**−3.5%** | 0.140→0.113 MPa，**−19.3%**（原文按 −20% 记） | 移动恒载、60 km/h |
| 模量 500→1500→4000 MPa | — | 0.085→0.201→0.359 MPa，**+136.5%**、**+78.6%**（原文 135%） | 80 km/h、55 mm、平整度「较好」 |
| 厚度 40→60 mm | — | 0.26→0.22 MPa，**−15.4%** | 80 km/h、模量 700 MPa、平整度「较好」 |

**复算明细（每一步都能自己验）**：

| 算式 | 结果 | 原文怎么写 |
|---|---|---|
| $(0.628-0.615)/0.628$ | 2.07% | 「约 2%」 |
| $(0.133-0.113)/0.133$ | 15.04% | 「约 15%」 |
| $0.113/0.133$ | 84.96% | 「85%」 |
| $(0.128-0.109)/0.128$ | 14.84% | 「约 15%」（C 节点那一列） |
| $(0.637-0.615)/0.637$ | 3.45% | 「约 3.5%」 |
| $(0.140-0.113)/0.140$ | 19.29% | 「约 20%」 |
| $0.113/0.140$ | 80.71% | 「80%」 |
| $(0.201-0.085)/0.085$ | 136.47% | 「135%」 |
| $(0.359-0.201)/0.201$ | 78.61% | 未写 |
| $(0.26-0.22)/0.26$ | 15.38% | 「约 15%」 |

> **两张表合看，本卡的结论就一句话**：**位移钝、应力敏，差一个量级。** 同一批算例，报位移得「不显著」，报应力得「显著」——**这不是矛盾，是两个指标各说各的。**

### I.3 模量那一条为什么不能横比（`p19`、`ce-a06`）

方向是清楚的：模量升，铺装表面横向拉应力升，且增幅收窄（+136% 之后只有 +79%）。

**但有三个不能做**：

| 不能做 | 为什么 |
|---|---|
| 把 500–4000 那条曲线与 8.2 的基准接起来 | 敏感性用 680／700／600 之外的第四个起点；基准不同，曲线不可拼接 |
| 跨「较好／较差」两档比绝对值 | 两档只有定性描述，**没有 IRI 值**，曲线上的点无法定位 |
| 把「应力大」读成「更易裂」 | 模量升还让裂尖驱动力变大，但无门槛值、无 Paris 参数，判不了（`p28`） |

### I.4 三处口径陷阱（踩一个就错）

| # | 陷阱 | 表现 | 处置 |
|---|---|---|---|
| 1 | 平整度档位无 IRI | 「较好／较差」四个字，函数曲线无法定位 | 只在同一档之内比；跨档不比 |
| 2 | 模量三基准 | 680（8.2）／700（厚度）／600（8.4），互不换算 | 每条曲线标自己的基准；不拼接、不外推 |
| 3 | 表 8-6 的坏格 | ζ=0.15 那格 0.517，前后是 0.625 与 0.613，同条件表 8-7 是 0.618 | **该列整列不引**；阻尼敏感性只走表 8-7（位移）与表 8-9（应力） |

### I.5 一条读数纪律

本章 8.2 与 8.3 共用一个有限元模型（表 8-1）。**`cases.md` 的 c02–c13 十二条是同一模型的十二次读数，不是十二个独立证据**——本卡引到的 c04（车速扫描）、c05（阻尼扫描）、c12（模量）、c13（厚度）四条全在这十二次里。**凡引用，必须同时写出这句话。** 这意味着一件事：**四条敏感性曲线反映的是同一个模型对四个旋钮的响应，不是四组互相独立的实验。**

### I.6 复算清单（拿它验别人）

1. 一次动了几个因素？动了两个 → 差值不可归因。
2. 两个指标都报了吗？只报位移 → 结论必然是「不显著」；只报应力 → 必然是「显著」。
3. 百分比是相对差还是绝对差？$(\text{max}-\text{min})/\text{max}$ 才对。
4. 模量基准是哪一档？是不是与基准工况混用？
5. 平整度档位有 IRI 吗？没有 → 跨档比绝对值不成立。
6. 阻尼敏感性引的是表 8-6 还是 8-7／8-9？前者含坏格。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】下面四段给「一份资料 ＋ 一个诉求」，输出「该怎么扫／能不能归因／停在哪」，**不出任何数值**。

**演练一（要一次扫两个因素）**
输入：「我想同时改车速和阻尼比，看哪个影响大。」
→ 判：I.1 第 1 条——一次只动一个；两个一起动，差值分不开。
→ 输出：**改设计**——先固定一个、扫另一个，各扫一遍再比两条曲线的量级。
→ 不输出：任何「哪个更敏感」的结论。

**演练二（只报了位移，结论是「没什么影响」）**
输入：「我扫了车速，位移几乎不变，所以车速可以不管，对吧？」
→ 判：I.1 第 2 条与 I.2 的两张表——位移钝、应力敏。
→ 输出：**不成立**——须把应力也报出来；同一批算例应力那一侧是显著档。
→ 不输出：任何「所以可以忽略」的判断。

**演练三（把两档平整度的曲线接起来）**
输入：「模量曲线我从低档一路连到高档，画了一条完整曲线。」
→ 判：I.3 与 I.4 第 1、2 行——两档无 IRI、模量基准还换了档。
→ 输出：**断开**——每条曲线只在自己的档位内成立；跨档只许说方向，不许连线。
→ 不输出：任何跨档的读数。

**演练四（要用阻尼表做结论）**
输入：「我拿阻尼比那张表做的结论，位移先减后增再减，物理上说得通吗？」
→ 判：I.4 第 3 行——那一格破坏了整行单调，同条件另一张表的值不一样。
→ 输出：**换表**——阻尼敏感性只走另外两张表；坏格整列不引。
→ 不输出：任何「那格大概该是多少」的替代值。

**预期输出表**：`诉求｜动了几个因素｜两个指标齐不齐｜判据（相对差）｜门槛（显著／不显著）｜口径查过没有｜停在哪一步｜依据页`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 要扫的因素（车速／阻尼／模量／厚度，单个） | 枚举 | 必需 | 多个 → 逐个扫，先不判 |
| 输出要哪几个指标 | 枚举（位移／应力／两者） | 必需 | 只给一个 → 提醒「两个指标差一个量级」 |
| 每个因素的档位 | 数列 | 必需 | 缺 → 用本章档位并标「本章值」 |
| 模量基准 | 数 | 条件必需 | 缺 → 标「基准不明，不可横比」 |
| 平整度档位有无 IRI | 布尔 | 条件必需 | 无 → 跨档比绝对值判不成立 |
| 引到的案例编号 | 列表 | 条件必需 | 落在 c02–c13 → 加 I.5 那一句 |

**步骤**

1. **定型**：I.1 三条判据逐条对——一次一个因素、两个指标分报、相对差。
2. **算差**：套 I.2 的算式，保留两位。
3. **读量级**：落在 2%–3.5% → 不显著；落在 15%–20% → 显著；**两个指标分别落档**。
4. **查口径**：I.4 三处陷阱逐条打勾。
5. **接结论**：模量那条只给方向与增幅收窄，不给「易裂」判断（`p28`）。
6. **定措辞**：只许写「位移 −X%、应力 −Y%，两者不在同一量级」；不许写「综合影响」。

**停判点**（命中任一条即停，不再往后走）

1. 要一次扫两个以上因素并归因 → 停（分不开）。
2. 要一个「综合影响系数」或把两指标加权 → 停（本章没有这种量）。
3. 要用表 8-6 的 ζ=0.15 列 → 停（坏格，整列不引）。
4. 要跨平整度档比绝对值 → 停（无 IRI）。
5. 要跨模量基准拼曲线 → 停（680／700／600 互不换算）。
6. 要把「模量升、应力升」读成「更易开裂」→ 停（无门槛、无 Paris，`p28`）。

**输出契约**——字段固定：

`诉求类型｜因素（单个）｜指标（位移／应力）｜相对差｜显著与否（定性门槛）｜口径检查｜停判点｜依据页`

表下固定三行：
- **公式状态**：本卡判据不依赖带号式子；8-2～8-8 均不可代。
- **数值状态**：四组数可复算；两档平整度无 IRI；表 8-6 的 ζ=0.15 列坏。
- **依据页**：p173–177（车速与阻尼）、p190–193（模量与厚度）。

**反解核对（记录在案）**：卡里「两个指标差一个量级」的说法可当场核。作者判不显著的门槛是
$2\%$ 与 $3.5\%$、判显著的是 $15\%$ 与 $19\%$；同门槛相除得 $15/2=7.5$、$19/3.5=5.4$，
即位移与应力的敏感度差 **5.4–7.5 倍**，严格说不到「一个量级（10 倍）」。写成「差五到七倍」
比「差一个量级」更准，读者据此可以判断同一组算例报哪个指标会得出相反结论。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **一次动两个因素。** 差值不可归因（I.1 第 1 条）。
2. **只报一个指标。** 位移钝、应力敏，只报一个必然得出片面结论（I.2）。
3. **把「不显著」当成「没有影响」。** 2%–3.5% 是作者给位移定的门槛；换指标就换档。
4. **跨平整度档比绝对值。** 两档只有定性词、无 IRI（`ce-b18`、`g16`）。
5. **跨模量基准拼曲线。** 680／700／600 三个基准互不换算（`ce-a06`）。
6. **用表 8-6 的 ζ=0.15 列。** 0.517 破坏单调，同条件表 8-7 是 0.618（`ce-b13`、`c05`）。
7. **把「应力大」读成「更易裂」。** 本章无门槛值、无 Paris 参数（`p28`、`c17`）。
8. **把四条曲线当四组独立实验。** c04、c05、c12、c13 是同一模型的十二次读数之四（I.5）。

**H2 — 用前必须声明**

1. 一次只动一个因素，两个指标分报。
2. 门槛是定性口径（2%–3.5% 与 15%–20%），不是统计检验。
3. 每组数的荷载档（移动恒载）、车速、ζ、模量基准、平整度档位。
4. 两档平整度无 IRI；模量三基准互不换算。
5. 表 8-6 的 ζ=0.15 列不引。
6. 结论措辞只到「方向 ＋ 量级 ＋ 落哪个档」。

**本章缺口对本卡的影响**

| 缺口 | 对本卡 |
|---|---|
| 门槛无量化定义（`f07`） | 只能原样称「定性门槛」 |
| 两档平整度无 IRI（`ce-b18`） | 跨档比绝对值不成立 |
| 模量三基准（`ce-a06`） | 曲线不可拼接、不可外推 |
| 表 8-6 坏格（`ce-b13`） | 阻尼敏感性只能走另两张表 |
| 随机动载档不单调（`c10`） | 车速那一条只对移动恒载成立；随机动载档峰值在 60 km/h，不是同一条曲线 |

**不要用本卡做的事**：给综合影响系数、跨档连线、跨基准外推、用坏格、把应力变化读成开裂风险、把四条曲线当独立验证、用「不显著」替用户做设计取舍。

**已知硬伤（备查）**：表 8-6 的 ζ=0.15 格 0.517；表 8-8 与表 8-9 的 C 节点列与全层列不是同一个量；p192 有「0.035 增大到 0.201」的残句（0.035 应为 0.085，135% 只能由 0.085 得）；厚度那条的两个档位平整度也是定性词；`c12` 与 `c13` 的曲线点无法定位到具体 IRI。
