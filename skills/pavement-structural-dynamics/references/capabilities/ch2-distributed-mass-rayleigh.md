## R — 原文论点（转述，非摘录）

作者的瑞利法是一条「先假定形状、再用能量等式换频率」的绕路：不写运动方程，只要一条满足边界的挠曲形状。

**弹簧这一例**：设弹簧上各截面的位移与其到固定端的距离成正比，于是势能跟无质量弹簧一样，只需把动能重算一遍；把每个微元的动能沿全长积分，得弹簧的总动能；与重物动能相加写成能量等式，再跟无质量弹簧的等式对照，结论是——只要给重物质量补上弹簧质量的一个固定分数，周期就估出来了〔公式待核〕。作者还补了一句：即使弹簧质量与重物质量同量级，这个结论的精度也够用。

**简支梁这一例**：假定振动时梁的挠曲线与跨中受一个集中荷载时的静挠曲线同形，把梁的动能沿半跨积分后加倍，得到一个折算系数；于是「带自重的梁 + 跨中质量」等价于「无质量梁 + 一个放大后的质量」。作者接着走极端——把跨中质量取为零，给出这时的近似周期系数与精确解系数，并说误差落在一个百分点以内。悬臂梁同一套办法，折算到自由端，得另一个系数，误差约一个半百分点。

**形状函数这一层**：作者随后换了两次形状。一次取正弦形（对无质量简支梁这是真实振型），代进弯曲应变能积分，得出来的频率就是精确解；一次取均布自重下的挠曲线（四次多项式），分别积分出最大动能与最大势能，令两者相等，得到的频率与精确解前三位有效数字相同。最后由这两个积分给出一般商式：频率平方等于重力作功的积分除以动能里那条平方的积分〔公式待核〕；密度沿长度变化时积分内的密度要留着，均匀时可约掉。

**方向性结论**：梁本来是无穷多自由度；指定一条挠曲形状，等于给系统添了约束。加约束只可能抬高刚度，所以估出来的频率只会偏高，不会偏低。

（见 p39–p43，§2.3.2）

### I.3 判据：结果只许偏高

- 算出值**高于**精确解 → 正常，这是上界性质。
- 算出值**低于**精确解 → 不是「运气好」，而是形状函数违反边界条件、积分算错、或把质量算漏了（ce24）。
- 两条形状给出两个值 → 取**较小**的那个更接近真值（离上界更近），不能取平均。

### I.4 折算系数的意义要点：它是「按形状积分出来的」，不是凑的

每个系数都来自「把微元动能沿构件长度积分，再除以端部速度的平方」。所以：

- 系数依赖**形状假设**，换形状就换系数；
- 系数依赖**边界条件**，简支与悬臂不能互换；
- 系数只对**均质等截面**成立，截面变化或多层体系要重积分。

### I.5 本章不给的三样（写卡即声明）

1. **「自重相对集中质量小到什么程度才可以压成单自由度」的阈值**：0 处，只有「相比很小」与量级算例。
2. **二阶及以上频率**：0 处；瑞利法在本章只给一阶。
3. **有耗散系统的处理**：0 处（`ce21`）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **对有耗散的系统用「势能最大 ＝ 动能最大」这条等式**：它的前提是无耗散；有阻尼器或材料内耗时两能量不再同时取极值（ce21）。
2. **把瑞利法只会偏高当成可能偏低**：加形状假定等于加约束，加约束只抬高刚度，所以估计值只可能高于真值（ce24）。算出来偏低，说明形状、边界或积分有一处错，不是「更精确」。
3. **不声明弹簧质量已略去就用能量法**：能量法里弹簧动能被丢掉是一个前提，不是默认（ce22）。
4. **梁的分布质量为主时仍用静挠曲线**：静挠曲线形状只在集中质量为主时够准；分布质量为主时形状该另选（ce23）。本章对「相比很小」只有定性说法，没有量化界。
5. **拿本章的折算系数去套多层体系或变截面梁**：系数是按均质等截面、特定边界积分出来的。
6. **照抄本章 p39 的周期式**：该式与同页频率式、p26 周期式三者互斥（矛盾 C1），只能以「二π 除以角频率」为准。

**H2 — 用前必须声明**

1. **边界类型**：简支与悬臂的系数不能互换；本章只给这两类梁。
2. **形状函数是什么、为什么选它**：瑞利法的全部精度都在这条假定上。
3. **集中质量与分布质量的相对大小**：决定静挠曲线这个假定还站不站得住（`ce23`，本章无阈值）。
4. **弹簧质量是否已略去**（`ce22`）。
5. **公式状态与数字状态**：式子 `〔公式待核〕`；全部系数、误差 **转录值，未见原图**，逐个带标。
6. **本章另一处已知损坏**：能量守恒式 `(2-116)` 里应变能一项带负号、且丢了等号（`cb14`），对它求导得不到运动方程；`(2-148)` 的动能式角频率只到一次方（`cb40`）；`(2-141)` 精确解的根号里少了长度的幂次（`cb17`）。凡用这些式子，先按量纲复算。
