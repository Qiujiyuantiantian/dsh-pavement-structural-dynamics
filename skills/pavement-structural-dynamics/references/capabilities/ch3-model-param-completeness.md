## R — 原文论点（转述，非摘录）

这一章把「进动力模型要什么」散在三处：阻尼那套在 3.1，模量与相位角在 3.2 与 3.3，主曲线在 3.3 收尾，另有一条弯拉的路子放在 3.4。作者在讲复合模量时顺口点了四样东西的名字——储能那一半、耗能那一半、两者合成的模量、以及错开的角度——并在一句并列里把杨氏模量、剪切模量与泊松比摆在一起，此后泊松比就再没出现过。主曲线那一段给了做法：假定两个经验常数，由实测的横移量反推材料自己的基准温度，再把几条温度曲线挪到同一个参考温度上叠成一条；形状用一条 S 形的四参数式子描述。至于这四个参数取什么数、叠出来的曲线横轴纵轴怎么标，都没有。3.4 又换了一条加载路径，量弯拉方向的劲度，另配一个相位角，并声称这一路与静力结果走向一致；两条路径之间的换算，全章没有一句。

（见 p48–65；四件的名字在 p50–52，主曲线在 p59–62，弯拉在 p62–65）

> **出处**：p48（表 3-2 的阻尼）＋ p50–52（复合模量、相位角、泊松比那一次并列）＋ p59–62（主曲线、移位因子、S 形四参数）＋ p62–65（弯拉劲度）。

## I — 判据骨架

### I.1 四件与本章的交付状态

| # | 件 | 进模型时它管什么 | 本章给了什么 | 状态 |
|---|---|---|---|---|
| 1 | 模量随温度与频率 | 决定刚度矩阵随工况怎么变 | 曲线（4 温度 × 9 频率 × 3 围压），**无一个绝对值**、无结果表 | 半（有趋势无表值） |
| 2 | 同条件下的相位角 φ | 决定耗能项与滞后，决定了黏性成分 | 同一批试验的曲线，另有一节方向性讨论 | 半（有趋势，方向两节未调和） |
| 3 | 泊松比 | 三维本构里把 E 与 G、K 连起来的那一格 | 词 1 次、符号 0 次、数值 0 次 | **缺** |
| 4 | 阻尼随频率 ζ(f) | 决定阻尼矩阵随频率怎么变 | 只有基频一个点（7.3–103.3 Hz 那一串） | **缺（无频率维）** |

**判定**：四件齐 → 可进；缺 1 或 2 → 只能进一维简化模型；缺 3 → 三维本构立不起来；缺 4 → 阻尼只能取一个与频率无关的常数，而这恰好是作者自己在 3.2 反对的做法。

### I.2 「四件缺三件」怎么读

本章真正算得上齐备的只有相位角一项（同一批工况、同条件测得），其余三件各有一处硬缺口：模量没有绝对值落地、泊松比无值、阻尼没有频率维。**这不是「数据少」，是「三件都断在不同的地方」**：一件断在「没落地成表」、一件断在「根本没测」、一件断在「只测了一个点」。所以对「缺哪几件」的回答必须分开写，不能笼统说「参数不全」。

### I.3 两套频率轴不相交（第 4 件为什么补不上）

模量扫的是 0.1 Hz 到 25 Hz 那一串档位；阻尼只在梁的基频上取，落在 7.3 Hz 到 103.3 Hz 那一串。两套轴**没有一个共同频点**。因此：即使把第 1 件补齐（模量有表值），第 4 件仍然补不上——ζ 与 |E*| 无法配对成同频点的一对。这是本章方法论层面最要紧的断口，不是笔误。

### I.4 弯拉那一路填不进 |E*| 的位置

3.4 量的是小梁在四点弯曲下的弯拉劲度，另配相位角。它与 3.3 的轴向 |E*| 在应力状态（均匀受压 vs 纯弯段的应变梯度）、试件体积、应变梯度三处都不同。本章既没有换算关系，连四点弯曲的应力与应变式都没有给，只有一张结果表（`ce-A09`）。**判据**：两条线的数据各自引用、各自标条件，谁都不许填对方的位置。

### I.5 本章拿不到的东西（先声明）

- 泊松比数值：0。三维本构缺的那一格，本章不补。
- ζ 随频率：0。只有一个频率点。
- 低温端实测锚点：0。试验温度窗只到 4℃（另一路弯拉最低到 −10℃ 附近），而冬季开裂正落在这端（`ce-A11`）。
- 主曲线的四个形状参数：0。作者的主曲线无法复现（`ce-B21`）。
- 动静比值：0。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章没有「一套齐备参数进模型」的算例，下列四段给字段、出「能不能进 / 缺哪几件」，**不给任何算出数**。

**演练一（完备性检查，正常路径）**
输入：一份参数集，四件逐项列明来源与条件（模量随温频、同条件相位角、泊松比、阻尼随频率）。
→ 判：四件齐 → 可进；再核「四件的试验条件是否同一批材料、同一温区」。
→ 输出：一张四件登记表 + 「可进」结论 + 三处须声明的条件（参考温度、频率轴范围、围压口径）。
→ 不输出：任何参数值。

**演练二（否决：只有模量曲线就要进三维模型）**
输入：一份只有 |E*| 曲线的资料，要求直接进三维有限元。
→ 判：缺泊松比（本章这个词出现过一次、符号零次、数值零个），三维本构立不起来；缺阻尼频率维，阻尼只能取常数。
→ 输出：**停**——列出缺的两件，并说明「缺泊松比」不是「本章没提」，是提了没给值。

**演练三（否决：拿弯拉劲度顶轴向模量）**
输入：一份四点弯曲的弯拉劲度结果，要填进 |E*| 那一栏。
→ 判：应力状态、试件体积、应变梯度三处都不同，本章不给换算（`ce-A09`）。
→ 输出：**出局**——两条线各自引用。

**演练四（停：按本章 S 形函数写拟合代码）**
输入：要求照本章的 S 形四参数式子写一段拟合主曲线的代码。
→ 判：指数项里形状参数出现两次、另一个形状参数不出现、缩减频率不出现；同一个字母还同时是曲线宽度、移位因子与一个语义不可用的「变量」；四个参数一个数没有。
→ 输出：**停**——符号必须自定、式体必须重写；本章一个都对不上（缺口，见 B 段第一条）。

**预期输出表**：`四件（模量/相位角/泊松比/阻尼频率维）｜各件状态｜能不能进模型｜缺哪几件｜须声明项`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判完备）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 模量 | 数值或曲线 | 必需 | 缺 → 停：第 1 件无 |
| 模量的温度与频率标签 | 列表 | 必需 | 缺 → 该件按「不可用」记，不按「有」记 |
| 相位角 | 数值或曲线 | 必需 | 缺 → 第 2 件无，黏性成分判不了 |
| 相位角是否同条件 | 布尔 | 必需 | 缺 → 该件按「半」记 |
| 泊松比 | 数值 | 必需 | 缺 → 三维本构不可用；本章亦无值 |
| 阻尼（含频率标签） | 数值或曲线 | 必需 | 缺频率维 → 第 4 件按「缺」记 |
| 加载路径（轴向／弯拉） | 枚举 | 必需 | 缺 → 停：两条路径不可互换 |
| 参考温度 | 数值 | 条件必需 | 缺 → 主曲线类数据不可用；只许填 20℃ 这一组能自洽的 |
| 围压口径 | 枚举 | 建议 | 缺 → 只当单轴量 |

**步骤**

1. **列四件**：逐件写「有／半／缺」，并写清断在哪（没落地成表 / 根本没测 / 只测了一个点）。
2. **核条件同源**：四件是否同一批材料、同一温区、同一加载路径；不同源则逐件标来源。
3. **查第 4 件的频率维**：若只有基频一个点，直接判「缺频率维」，不许用模量的扫频轴去补。
4. **查弯拉与轴向是否混用**：混用即停（`ce-A09`）。
5. **查主曲线可用性**：有没有四个形状参数？没有 → 只能自拟，不许声称「用作者的主曲线」。
6. **写参考温度**：只能写 20℃（本章唯一自洽的那一组）。
7. **写「不推出的项」**：动静比值、泊松比取值、低温端外推的可信度。

**停判点**

1. 缺泊松比还要进三维模型 → 停。
2. 只有基频阻尼还要 ζ(f) → 停（两轴不相交）。
3. 拿弯拉劲度顶 |E*| → 停（`ce-A09`）。
4. 按本章 S 形函数写代码 → 停（符号与式体都对不上）。
5. 要求以本章为据主张动态优先 → 停（动静比值 0）。
6. 把主曲线往 0℃ 以下外推当实测 → 停（无锚点，`ce-A11`）。

**输出契约**——字段固定：

`四件状态（有/半/缺＋断在哪）｜条件是否同源｜参考温度｜加载路径｜能不能进模型｜缺哪几件｜不推出的项｜依据页`

表下固定三行：
- **公式状态**：`〔公式待核〕`；S 形函数不可直接实现。
- **数值状态**：本章无 |E*| 绝对值；三个移位因子为转录值（可复算）。
- **依据页**：p48、p50–52、p59–65。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **只有模量一条曲线就要进三维模型**：第 3 件（泊松比）本章词 1、符号 0、数 0；第 4 件（阻尼频率维）只有基频一个点。
2. **拿弯拉劲度填轴向 |E*| 的位置**：`ce-A09`，两个量在应力状态、试件体积、应变梯度上三处不同，本章不给换算。
3. **用主曲线往 0℃ 以下外推并当实测**：试验温度窗只到 4℃，低温端没有实测锚点，而冬季开裂就在这一端（`ce-A11`）。凡外推必须标「外推，无锚点」。
4. **按本章的 S 形函数直接写拟合代码**：指数项里形状参数出现两次、另一个不出现、缩减频率不出现；同一个字母兼作曲线宽度、移位因子与一个语义不可用的「变量」；四参数无值。式体要重写、符号要自定，本章一个都对不上。
5. **写「主曲线可以直接读数」**：图 3-22 无坐标刻度、无拟合参数，读不出任何 (T, f) → |E*| 的点（`ce-B21`）。
6. **以本章为据主张「动态参数优先于静力参数」**：`ce-B19`，动静比值全章 0 个。
7. **把 40℃ 写成主曲线参考温度**：能自洽的只有 20℃ 那一组（4.52 / −3.26 / −5.28），40℃ 那一步被作者无声丢弃。

**H2 — 用前必须声明**

1. **四件的状态**：有／半／缺，逐件写，并写断在哪。
2. **泊松比口径**：「词 1 次 / 符号 0 次 / 数值 0 次」，不许写成「未提」。
3. **参考温度**：只写 20℃。
4. **加载路径**：轴向还是弯拉，二者不互换。
5. **阻尼的频率维**：有没有；没有就明写「阻尼只能取与频率无关的常数，且这与本章 3.2 的立场相反」。
6. **公式状态**：主曲线相关式子 `〔公式待核〕`，S 形函数不可直接实现。

**本章三条覆盖缺口（对本卡的影响）**

| 缺口 | 对本卡 |
|---|---|
| 泊松比（0 值） | 本卡只能判「三维不可用」，补不了那一格 |
| 主曲线四参数（0 值） | 本卡只能判「不可复现」，给不出可执行的拟合参数 |
| 低温端无锚点（温度窗 4–60℃） | 本卡的「外推可信度」一项只能标红，不能量化 |

**不要用本卡做的事**：给泊松比、给主曲线参数、给动静比值、把两条加载路径的数互换、按本章式体写拟合代码。

**已知硬伤（不影响判据的，列此备查）**：S 形函数四个参数全无；移位因子常数一处说应逐料拟合、一处直接套普适值（两种口径并列）；同一个记号在一个小节里既指参考温度又指基准温度。
