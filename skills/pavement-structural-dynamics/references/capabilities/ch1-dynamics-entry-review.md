## R — 原文论点（转述，非摘录）

作者的立论是一条链：静力法把车当成停在那里不动的荷载，而真实路面受的是移动车轮一遍遍压；路表的平整程度、车辆跑得快慢、车辆本身的参数这三样都会改变实际施加的荷载，荷载一变，结构里的应力与应变跟着变，而静力这条路对上面每一环都无能为力。据此他推出应当转向动力学。转到动力以后，他把缺口放在两处：一是材料的动、静参数怎么取——他摆了四种仪器的对比试验，结论是动、静模量之间有一定关联，但数据的重复性很差，拿来定设计参数问题很大；二是阻尼——动力有限元要建刚度、质量与阻尼三类矩阵，阻尼偏复杂，一般拆成结构的那一份与材料的那一份，而路面动力研究里多数人直接把阻尼忽略，计入的也多是假设值。收束那一节他把卡点全部归到数学：无限域与半空间在运动点源下的弹性动力学解很难；带边界的有限尺寸构件（梁、板、层状体）会让传播中的弹性波多次反射与折射，不同边界与入射情形下还会发生波形转换。归因之后他只给两条出路——梁板一类初等理论，或者数值方法。此后全章不再给任何判据。

（见 p10 导语、p11 §1.1 末段、p16 §1.6）

## I — 判据骨架

### I.1 正向链条：三步，缺一步就证不成

| 步 | 要成立的事 | 判据（怎么算成立） | 缺了会怎样 |
|---|---|---|---|
| 1 | 三个荷载来源都进了模型 | 路表平整、行车快慢、车辆参数，三样在模型里都有位置（不是只在文字里提过） | 只把静载换个名字叫「动载」，链条没闭合 |
| 2 | 荷载的变动继续传下去 | 荷载的变化确实进到内力与变形里（有传递路径，不是停在轮压那一层） | 有动载、没有响应，等于只做了荷载谱 |
| 3 | 结论落在「静力描述不了」这一层 | 说的是描述能力的边界，不是「动力更准」这种泛断言 | 变成「新方法比旧方法好」，那是评价不是判据 |

> 反用：拿这三步去审一份把荷载按车停住取值的论证——**三源不全、或荷载变动没传到内力变形，都可以判「这只是静力的改写」**。

### I.2 反向门槛：四项条件 ＋ 一个空档（`ce-A01`）

| 项 | 内容 |
|---|---|
| 四项条件 | 有速度、有不平整、车辆参数有差异、荷载是反复的。四项都不显著时，才谈得上退回静力 |
| 本章给的 | 四项条件本身（p10 导语把它们点出来了） |
| **本章没给的** | **反向门槛的数值界**：速度低到什么程度、平整度好到什么程度仍可用静力。作者没给，也没打算给 |
| 因此本卡的输出只有 | 「能不能退回静力」＋「缺的是四项里的哪一项」＋「门槛本章未给」 |

> 这一格是本卡最容易被替作者填的地方。凡出现「按本章，速度低于某值就可以用静力」这类句子，一律判越界。

### I.3 参数与阻尼的入场审查（`f06`，含 `f05` 的空档）

| 审查项 | 通过的样子 | 本章的实情 |
|---|---|---|
| 三类矩阵齐不齐 | 刚度、质量、阻尼三个都在，且各自说明了来源 | 只说了「必须建」，一个都没给形式（本章无式） |
| 阻尼有没有分两块报 | 结构那一份与材料那一份分开，各自说明取值依据 | 说了要分，但没给任何一块的取值 |
| 取值是实测还是假定 | 每一处都写清 | 明说「多数忽略、计入的也多为假设值」——这是作者自陈的普遍缺陷，不是他能补的 |
| 参数能不能当设计值 | 有重复性、有比对、有离散度 | 四台仪器的对比**零数据**：频率、应力水平、试件尺寸全无，「再现性差」没有离散度指标，也没有「差到什么程度就不能用于设计」的界（`f05`、`p02`） |

> 判法：**「有输入」不等于「有这三个矩阵的名字」，而是三样都在、都写了来源、都写了是实测还是假定。** 三样里缺「实测／假定」这一栏，动力解就只能当趋势看。

### I.4 三类数学困难 → 两条出路（`f13`，收束在此为止）

| 卡在哪 | 作者的原话位置 | 出路 |
|---|---|---|
| 无限域与半空间在运动点源下的弹性动力学解 | 1.6 前半 | ①简化成梁板一类初等理论；②直接上数值 |
| 有边界结构的弹性波多次反射与折射 | 1.6 中段 | 同上 |
| 不同边界与入射情形下的波形转换 | 1.6 中段 | 同上 |

> **这一步之后本章不再给判据。** 出路只有两条，两条的名字都点到为止：初等理论只列了梁板各家的名字，数值只说了有限元与边界元。**哪条出路更好、误差多大、什么时候必须上数值——全章没有。** 因此本卡的归因只到「属于哪一类困难」，不到「该选哪条路」。

### I.5 时间起点：两种读法只能并列（`ce-B12`）

同一句先称路面结构动力模型的研究起于上一世纪七十年代，紧接着举的证据却是那一年的机场道面动力相互作用研究。上一世纪七十年代既没有汽车也没有路面动力学；若原文是这一世纪七十年代，则与那条证据对得上。**这是全章唯一的时间起点**，两种读法只能并列标「原文如此，未核」——不许挑一个信，也不许径改成另一个世纪。

### I.6 立论证据的两处塌陷（引这一句前必须知道）

| 柱子 | 塌在哪 | 后果 |
|---|---|---|
| 部级一份研究总报告要求把设计参数由静改到动 | 角标印成 0 号，而清单从 1 号起，没有 0 号 | 全书为什么要写的依据，无法追溯（`ce-B04`） |
| 某一年的试验里速度升高、内应力增四成 | 整句无角标；清单里也找不到那一年的那条试验 | 无出处，且条件缺失（`ce-B04`） |

> 附带一条更细的：作者用两组互斥的速度效应数推出「同一课题可能得到互相矛盾的结论」，再由此推出「必须先做材料参数研究」。但这两组数的条件一项没交代，**速度快的那一组增量反而更小**，严格说不是矛盾，是不可比（`ce-B13`）。引这个论证时，只能说「方向存在分歧」，不能说「数值互相矛盾」。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章 0 个算例、0 条实测、0 个复算；下面四段给「一份论证或一份分析 ＋ 一个诉求」，输出「该不该转／缺哪项／卡在哪类／停在哪一步」，**不出任何数值**。

**演练一（入场：该不该转动力）**
输入：一份设计办法，荷载按车停住取值，理由写「本段路行车速度不高、路表也还平整」。
→ 判：走反向门槛（I.2）——先看四项条件是否都不显著，再看作者有没有给「不显著」的界。
→ 输出：**条件方向对，门槛缺失**——能判「这是有理由的静力取值」，但不能判「按本章就可以用静力」，因为数值界本章未给。
→ 不输出：一个速度界限，或一个平整度界限。

**演练二（参数：这份动力分析算不算有输入）**
输入：一份路面动力有限元分析，写了网格、写了材料模量，阻尼写「取经验值」。
→ 判：三栏审查（I.3）——三类矩阵齐不齐、阻尼有没有分两块、取值是实测还是假定。第三栏落在「假定」。
→ 输出：**三栏缺一栏**——可以出趋势，不能当设计输入；并写明缺的是「实测还是假定」这一栏。
→ 不输出：一个阻尼比，或一句「按经验取值即可」。

**演练三（归因：算不动怎么办）**
输入：「这个模型解不出来，或者解出来跟实测差得远，下一步该干什么？」
→ 判：先归到三类数学困难之一（I.4）——是无限域与半空间那一类、边界反射折射那一类，还是波形转换那一类。
→ 输出：**归因到某一类，然后只剩两条出路**（简化成梁板初等理论，或直接数值）；并声明「本章到此为止，不再给判据」。
→ 不输出：误差量级、方法优劣排序、任何「改用某软件即可」的建议。

**演练四（证据：用两组数证明方向）**
输入：「用书里那两组互斥的速度数据，证明车速对动载的影响方向，行不行？」
→ 判：两组条件一项没交代，且速度高的那组增量更小（I.6）——不可比，不是矛盾。
→ 输出：**只能写「方向存在分歧」**；不得给幅度、不得给趋势、不得内插。
→ 不输出：任何「车速越大动载越大」的定量结论。

**预期输出表**：`诉求｜四项条件过几项｜三栏审查结果｜归因类别｜出哪条路｜停在哪一步｜依据页`。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把「静力不够」当放之四海的结论。** 四项条件必须一起带出；四项都不显著时才谈得上退回静力（I.2）。
2. **替作者补退回静力的门槛。** 速度阈值、平整度界限、阻尼比，本章一个都没有；补了就是编（`ce-A01`）。
3. **引带数字的立论句。** 一根柱子指向不存在的 0 号，另一根连角标和清单条目都没有（`ce-B04`）。
4. **把两组互斥数据当「数值矛盾」。** 条件一项没交代，速度高的那组增量反而小；只能说方向有分歧（`ce-B13`）。
5. **把「建了三类矩阵」当「有输入」。** 三栏缺一栏（尤其实测还是假定），动力解只能当趋势（I.3、`f06`）。
6. **拿四台仪器的对比当参数依据。** 那一节零数据：没有频率、没有应力水平、没有试件尺寸、没有离散度；结论只到「有关联、再现性差」（`f05`、`p02`）。
7. **把 1.6 的两条出路当方法推荐。** 只点了名字，没有优劣、没有误差、没有适用界。
8. **改时间起点。** 两种读法并列，不许挑一个信，也不许径改（`ce-B12`）。

**H2 — 用前必须声明**

1. 判的是「该不该转」，不是「转过去算得对不对」。
2. 四项条件逐项写；门槛缺失这一句必须出现。
3. 三栏审查逐栏写；阻尼取值来源必须落「实测／假定／忽略／未写」之一。
4. 归因只到类别，不到方法选择。
5. 立论句不带数字；带数字则必须加「无出处」与「条件缺失」。
6. 本卡不覆盖：门槛数值、阻尼取值、模量比、误差量级、出路比较、时间起点。
