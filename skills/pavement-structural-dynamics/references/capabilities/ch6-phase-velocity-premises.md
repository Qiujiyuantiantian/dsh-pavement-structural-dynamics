## R — 原文论点（转述，非摘录）

作者先给相速的定义：它是频率与波长的乘积，而波长要靠两个位置的相位差来量。量法他给了三条：波长短、测线够长时，沿测线多点读相位，找相位差走满整圈的位置，两处间距即一个波长；测线只够覆盖一个波长以内时，把测线等分，用相位对距离那条线的斜率取平均；要自动化，就固定两个探头的间距去扫频，让相位差走满整圈，那时两探头间距就是一个波长，前提是这个间距得小于最低频率下的波长。他随后提醒：这只在相位差与距离成直线时成立；接触状态不一致会把线掰弯，直达波与界面反射波干涉会让它呈波浪状，频率撞上被测体的固有频率而起驻波时，波长根本量不稳。再往后他声明层状路面的精确解拿不到，于是把模型分四级退让：无界介质、弹性半空间、自由板、板上覆层。写到表面波时他补一条：只有波长短于表层厚度，高频段读到的才是那一层介质的波速；否则读到的是更深的等效值。到多层那一节，他改用弯曲波频散曲线读「等效自由层厚度」，把频段人为划成三段，读出的厚度随划法变；那一段的推算式与步骤另有硬伤。

（见 p112–115、p127–129，§6.1.1、§6.1.2.2、§6.3.2.1）

## I — 判据骨架

### I.1 波长三法：先问波长相对测线有多长

| 情形 | 走哪一法 | 操作 | 前提 | 本章给的精度 |
|---|---|---|---|---|
| 波长短、测线长 | 多点读相位 | 沿测线多点量相位，相位差走满整圈处两点的间距即一个波长 | 相位—距离成直线 | 相位计误差 1°（全章唯一的精度数） |
| 测线只够覆盖一个波长以内 | 等分取斜率 | 把测线等分，用相位对距离的斜率取平均 | 线段仍要接近直线 | 无 |
| 要自动化 | 定距双探头扫频 | 间距固定，扫频到相位差走满整圈，间距即波长 | 间距小于最低频下的波长 | 无 |

> 三法不是同一件事的三种做法，而是三种尺寸条件下的三种做法（`A01`、`g04`）。把它并列成「任选其一」，读到长波长时会失真。

### I.2 两条前提（缺一即不能用这个波长）

| # | 前提 | 判据 | 违反的后果 | 本章有没有处置 |
|---|---|---|---|---|
| 1 | 波长短于被测层厚 | $\lambda<h$ | 读到的是更深层的等效值，点层名即错 | 给了判据（`A04`） |
| 2 | 相位与距离成直线 | 目视相位—距离图 | 波长量不稳，后面所有换算失效 | 只描述现象，**无剔除办法**（`A02`） |

> 第 2 条要写成动作：**先看相位—距离是不是直线，再决定信不信这个波长。** 驻波情形本章未给处置，遇到只能停。

### I.3 频段：本章自报的上限有三个（`A03`、`g43`）

| 出处 | 说法 | 用途 |
|---|---|---|
| p113 | 设备能力写到 25 kHz | 设备标称 |
| p113 | 一条实测曲线用 28 kHz | 单条曲线 |
| p127–128 | 现场实测用 35 kHz | 两组现场数据 |
| p135 | 超声另给 20–100 kHz 一档 | 另一种手段 |
| p133 | 雷达写 100–1000 MHz | 又一种手段 |

> 规则：**写频率范围必须带页**；不许把 35 kHz 说成「本章设备的能力」，也不许拿一处上限去质疑另一处的实测——本章从未统一口径。

### I.4 等效厚度的定性残留（只留一句判据）

多层体系那一路的完整六步不可执行：6-45 括号里有无定义的 $c_5$、6-46 的 φ 恒为负、步骤 ④ 的条件恒真、⑤ 引的是 φ 的定义式（`B20`、`B21`、`f05`、`p10`）。能留下的只有这一句：

> **低频段看到的是更深的等效层，高频段只看得到表层；报等效厚度必须连频段一起报。** 频段一换，读出的厚度就换一个数（本章同一组波速换出 0.063、0.345、0.170 三个厚度，只是划法不同）。

这句是**判据**（别按六步走、别裸报厚度），不是**能力**（怎么走）。想按六步算，本章给不出。

### I.5 覆层剪切波的前置比较（`A06`、`B08`）

板覆在土基上那一族波，只在「上层剪切波速小于下层」时才有实数解；反过来只剩复数解，必须计入土基耗能，而耗能对波速的影响只在低频且 $h/\lambda<0.1$ 时才显出来。

> 动作：先比两层的剪切波速，用文字写（「上层比下层软」），**不要搬下标**——本章的下标有 ↑、∥、⊥ 三套字形，同一介质换过写法（`B08`）。

### I.6 本章明确拿不到的东西

- 穿透深度公式：0。
- 频率—深度的对照表：0。
- 反射波与驻波的处置办法：0（只有现象描述）。
- 三法之间的精度差别：0（唯一精度是相位计 1°）。
- 等效厚度的可执行算法：0（六步坏在 ④⑤ 与两个无定义量上）。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章 0 条实测频散曲线、0 个算例；下面四段给「一条测线 ＋ 一个诉求」，输出「走哪一法／能不能用／停在哪一步」，**不出任何数值**。

**演练一（选法：测线很长）**
输入：一条较长的测线，波长短、能沿测线连续布点，仪器能读相位。
→ 判：波长相对测线短 → 走多点读相位那一法。
→ 输出：一个波长 ＋ 第二条前提的检查结论（相位—距离是否成直线）。
→ 不输出：任何深度、任何模量。

**演练二（选法：测线只够一个波长）**
输入：场地限制，测线长度只能覆盖一个波长以内。
→ 判：多点法布不出整圈 → 改等分取斜率。
→ 输出：一个平均值 ＋ 声明「本法的精度本章未给」。
→ 不输出：把这个平均值当该层的确定波速。

**演练三（不合格：相位—距离不是直线）**
输入：相位随距离的点散成波浪状，或频率正好压在被测体的固有频率上。
→ 判：第二条前提被违反（`A02`）；本章没有剔除办法。
→ 输出：**这个波长不能用**——换测点或换频段重测，或直接停。
→ 不输出：一个「修正后」的波长。

**演练四（停：问能看多深、要厚度）**
输入：「这个波长能看到多深的层？」／「按频散曲线把等效厚度算出来。」
→ 判：穿透深度公式与频率—深度表全章没有；等效厚度的六步坏在 ④⑤ 与无定义量上（I.4）。
→ 输出：**停**——只能给「波长属于该层／只能报等效值」这个二分，加一句「低频看深、高频看浅」。
→ 不输出：深度数值、等效厚度数值。

**预期输出表**：`诉求｜走哪一法｜两条前提过否｜输出是一个波长还是一个二分｜停在哪一步｜依据页`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 测线长度与测点布置 | 数值 ＋ 序列 | 必需 | 缺 → 选不了法 |
| 相位—距离序列 | 序列 | 必需 | 缺 → 前提 2 不可判 |
| 扫频范围 | 区间 | 必需 | 缺 → 无法核「高频段」 |
| 被测层厚度（或假定值） | 数值 | 必需 | 缺 → 只能报等效值 |
| 两层的剪切波速（覆层情形） | 一对数值 | 条件必需 | 缺 → 覆层那族不可用 |
| 探头间距 | 数值 | 条件必需 | 走扫频法时必需，且要小于最低频波长 |

**步骤**

1. **量一量**：波长相对测线有多长 → 三法里选一条（I.1）。
2. **看直线**：相位对距离的点是否成一条线；不成就判「波长不可用」。
3. **核层厚**：波长短于该层厚，才允许点层名。
4. **报频率**：把所用频段连页码一起写（I.3）。
5. **判覆层**：若涉及覆层，先比两层剪切波速，用文字写，不用下标。
6. **收口**：输出一个波长，或「只能报等效值」这个二分。
7. **写不做的项**：深度、等效厚度、精度差别——逐项注明本章不覆盖。

**停判点**

1. 要穿透深度 → 停（公式与表皆无）。
2. 要等效厚度 → 停（六步不可执行，只留定性）。
3. 相位—距离不成直线 → 停（无处置办法）。
4. 要三法之间的精度比较 → 停（只有相位计 1° 一个数）。
5. 覆层层比下卧层硬却要读频散曲线 → 停（无实数解）。
6. 要一个统一的频率上限 → 停（三套上限并存）。

**输出契约**——字段固定：

`测线条件｜走哪一法｜相位—距离成直线否｜波长与层厚关系｜频段（带页）｜输出是波长还是二分｜本章不覆盖｜依据页`

表下固定三行：
- **公式状态**：只引 6-1 的关系；6-2、6-15 不引。
- **数值状态**：唯一精度数是相位计 1°；本卡无结果数。
- **依据页**：p112–p115、p127–p129。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把三法并列成「任选其一」。** 三法各有尺寸前提；波长很长时用多点法、或波长只有几厘米时去画等分斜率，读数都会坏（`A01`、`g04`）。
2. **搬 6-2 这条式子。** 印出的形式多一个 $1/k$，按正文自己的条件代进去得 $L/k^2$ 而不是 $L$；同页又说 k 是任意实数，与「相位差走满整圈」直接打架（`B01`）。只写这一句：**相位差走满整圈时，两探头间距就是一个波长。**
3. **相位—距离不直还硬用。** 接触状态、界面反射、驻波三样都会把线掰弯；本章只描述，不给剔除办法（`A02`）。遇到就停，不许「拟合一下」。
4. **波长比层厚还长却点层名。** 那时读到的是更深层的等效值（`A04`、`g18`）。核不了层厚，就只报「等效值」。
5. **把 35 kHz 当本章设备能力。** 三处上限互不相等（25／28／35 kHz），超声与雷达又各有一套（`A03`、`g43`）；写频率必须带页。
6. **按六步算等效厚度。** 6-45 有无定义的 $c_5$、6-46 的 φ 为负、④ 的条件恒真、⑤ 引错号（`B20`、`B21`、`f05`、`p10`）；这一步只能给「低频看深、高频看浅」。
7. **覆层层比下卧层硬还读频散曲线。** 那种情形方程只有复数解，要计土基耗能，而耗能只在低频且 $h/\lambda<0.1$ 时才显（`A06`）。
8. **以为频散曲线只有一支。** 板内相速至少三支，能套到路面的是最下面那支弯曲波；取错分支厚度换一个量级（`A05`）。
9. **裸引任何一个波速式。** 全章波速式分属四级简化（无界介质、半空间、自由板、覆层），跨级套用会丢掉该级的条件（`f04`、`A07`）；卡里每个式子都要标「属哪一级」。

**H2 — 用前必须声明**

1. 走的是三法里的哪一条，以及为什么（波长相对测线多长）。
2. 相位—距离成不成直线；驻波有没有遇到、怎么处置（本章无处置）。
3. 波长与该层厚度的关系；核不了就只报等效值。
4. 频段及其页码。
5. 若涉及覆层：两层剪切波速的大小关系。
6. 本章不覆盖的：穿透深度、频率—深度表、等效厚度算法、三法精度比较。
