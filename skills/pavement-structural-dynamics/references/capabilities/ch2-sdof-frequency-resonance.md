## R — 原文论点（转述，非摘录）

作者从最简单的模型起步：质量块挂在一根线弹性弹簧上，只在竖直方向动。取静平衡处为坐标原点，则偏离后受到的合力与偏离成正比、方向指回原点，这个力叫恢复力；只有恢复力时的振动叫无阻尼自由振动。把方程两端除以质量，引入「刚度除以质量」的平方根作为固有角频率，方程就成了标准形式，其解是简谐函数——幅值与初相角两个常数由初始条件定。周期由二π 除以该角频率给出；频率是周期的倒数；角频率等于二π 乘频率。他最后强调，这个角频率只跟系统自身性质有关、与初始条件无关，故名固有。

**第二条路（能量法）**：对无耗散系统，可以完全不写运动方程——物体停在端点时动能零、势能最大；以最大速度过平衡位置时势能零、动能最大；两者相等就给出一个代数等式，把简谐运动的最大速度换成角频率乘最大位移，即可反解出角频率。作者的措辞是：这条等式在部件较多、参与运动的部位不止一个的系统里尤其方便。

**受迫与共振**：他取简谐激振力（力幅、角频率、初相角三个定值），写出非齐次方程，解分成自由振动项与受迫项。受迫项的振幅是一个分式，分母是固有角频率平方减激振角频率平方；他分三段讨论：频率很小的时候振幅趋近静力作用下的静变形；介于零与固有频率之间时振幅随频率单调上升，接近固有频率时趋于无穷；超过固有频率后振幅取负值，习惯上取绝对值，物理上表示与激振力反向。当两者相等时，那个分式失去意义，特解必须另设形式（幅值乘时间再乘余弦），共振时的振幅随时间线性增长。他随即补一句现实修正：实际系统总有阻尼，共振振幅不可能无限大，但仍会相当大。

（见 p26，§2.2.1.1；p30–p32，§2.2.1.3；p38–p39，§2.3.1）

> **出处**：p26（恢复力、(2-34)~(2-40)、T 与 f 的关系）＋ p30（受迫开场、激振力 (2-61)、方程 (2-62)(2-63)、`2-64` 缺式、通解 (2-65)~(2-70)）＋ p31（振幅讨论 (2-71)、共振曲线、共振特解 (2-72)~(2-74)、错字「阳尼」「越人」）＋ p32（共振幅值 (2-75)、有阻尼时的定性修正）＋ p38–p39（能量法 (2-113)~(2-125)）。

## I — 判据骨架

### I.1 三条求固有角频率的路

| 路 | 输入 | 式子 | 适用 |
|---|---|---|---|
| 直接开方 | $m$、$k$ | $\omega_0=\sqrt{k/m}$〔公式待核〕 | 单自由度、线性弹簧 |
| 能量等式 | 最大势能与最大动能的形式 | $P_{\max}=K_{\max}$〔公式待核〕，反解 | 无耗散；多部件系统更方便 |
| 分布质量折算 | 边界类型、形状函数 | 见 `ch2-distributed-mass-rayleigh` | 梁类构件 |

三条路给出的都是**同一个量**（一阶固有角频率），不是三个不同的频率。

### I.2 周期与频率的换算：只认一条

$$T=\frac{2\pi}{\omega_0}\quad\text{〔公式待核〕},\qquad f=\frac{1}{T}\quad\text{〔公式待核〕},\qquad \omega_0=2\pi f\quad\text{〔公式待核〕}$$

**本章 p39 另给了一个周期式，它与同页频率式、p26 的周期式三者不能同真（矛盾 C1）。本卡一律用「二π 除以角频率」现场复算，不照抄 p39 那一式。**

### I.3 共振校核：判据只有一条

| 情形 | 判据 | 该用什么解 | 不能用什么 |
|---|---|---|---|
| 非共振 | $\omega\neq\omega_0$〔公式待核〕 | 稳态振幅分式〔公式待核〕 | — |
| 共振 | $\omega=\omega_0$〔公式待核〕 | 幅值乘时间的特解〔公式待核〕 | **原振幅分式，此处无意义**（ce13） |
| 静力极限 | $\omega\to 0$ | 静变形 $H/k$〔公式待核〕 | 把静变形写成刚度除以频率平方（本章 `(2-71)` 就是这处错） |

### I.4 「共振」在本章只到定性，给不出倍数

本章能说的：重合即共振；无阻尼时幅值随时间线性增长、理论上没有上限；有阻尼时有限但仍大，因此工程上要避开。
本章**不能说的**：放大几倍、峰值多少、相位差多少、带宽多宽、瞬态多久衰减掉。这五样在 2.2.1.4 整节缺位，本章 0 处。

## A1 — 演练（合成场景，无书中案例）

【合成演练，非书中案例】本章无固有频率算例，下列五条为**判定式**演练：给字段 → 出「走哪条路／能不能用哪个式」，**0 个数值结果**。

**演练一（直接开方，正常路径）**
输入：m、k，系统单自由度、线性、无阻尼。
1. 核前提：恢复力与偏离成正比且反向、无耗散 → 通过。
2. 走开方路 → 得角频率形式〔公式待核〕。
3. 周期用「二π 除以角频率」现场复算。
4. 输出：频率与周期的形式 + 「只对一阶、单自由度」的限定。

**演练二（能量法，正常路径）**
输入：无耗散系统的最大动能与最大势能表达式。
1. 令两式相等〔公式待核〕。
2. 把最大速度换成角频率乘最大位移。
3. 反解角频率 → 与开方路对照（两条路应给同一个量）。

**演练三（关键否决：在共振点直接代振幅式）**
输入：激振角频率等于固有角频率，报告仍用振幅分式算出一个数。
→ 输出「**出局**：该分式在此点没有意义，分母为零；共振必须改用幅值乘时间的特解」（ce13）。

**演练四（否决：负振幅当算错）**
输入：激振频率高于固有频率，算出的振幅为负，报告取绝对值后声称同相。
→ 输出「**出局**：负号携带相位信息，表示与激振力反向；取绝对值可以，但必须同时报反相」（ce12）。

**演练五（停：要放大倍数）**
输入：要求给「共振时放大几倍」「峰值多少」「相位差多少」「半功率带宽多宽」。
→ 输出「**停**：本章没有，须去 ch4/ch7」；本章只能给「无阻尼时无上限、有阻尼时有限但仍大」这一句定性。

**预期输出表**：`走的路｜ω₀ 形式｜T 形式（现场复算）｜是否共振｜该用哪类解｜不推出的项`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入判定）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| $m$、$k$（或等效能） | 数值 | 必需 | 缺 → 停；梁类构件先转 `ch2-distributed-mass-rayleigh` |
| 激振角频率 $\omega$（或频率） | 数值 | 共振校核必需 | 缺 → 只给固有频率，不做校核 |
| 激振力形式 | 枚举（简谐／其它） | 必需 | 非简谐 → 停：本章只认简谐 |
| 是否有阻尼 | 布尔 | 必需 | 有 → 只能给固有频率与定性结论；受迫段 → 停 |
| 恢复力是否线性反向 | 布尔 | 必需 | 否 → 停：简谐结论不成立 |
| 目标阶次 | 整数 | 必需 | 大于一阶 → 停（单自由度只一阶） |
| 坐标原点 | 文本 | 条件必需 | 缺 → 静位移与重力项可能混入 |

**步骤**

1. **核前提**：恢复力线性反向、无耗散、单自由度。
2. **算固有角频率**：走开方路或能量路〔公式待核〕，两条都走时互校。
3. **算周期与频率**：一律用「二π 除以角频率」与「周期取倒数」〔公式待核〕，**不照抄本章 p39 的周期式**。
4. **比频率**：$\omega$ 与 $\omega_0$ 是否重合〔公式待核〕。
5. **分情形**：非共振 → 稳态振幅式；共振 → 幅值乘时间的特解；静力极限 → 静变形。
6. **写定性修正**：实际有阻尼，共振幅值有限但仍大（本章只到这一句）。
7. **写「不推出的项」**：放大倍数、峰值、相位差、带宽、瞬态衰减时间。

**停判点**

1. 在激振频率与固有频率重合处直接代振幅分式 → 停（ce13）。
2. 系统有阻尼却要求受迫振幅或共振峰值 → 停：**有阻尼受迫整节缺位**。
3. 要求放大系数、相位差、半功率带宽、瞬态衰减时间 → 停：本章 0 处。
4. **问共振放大几倍 → 本章答不了，去 ch4/ch7 找。**
5. 激振力不是简谐（移动荷载、随机荷载、冲击） → 停：本章只认简谐。
6. 目标为二阶及以上频率 → 停：单自由度只给一阶。
7. 恢复力非线性（大变形、间隙、干摩擦） → 停：简谐解的前提不成立。

**输出契约**——表格字段固定：

`ω₀ 形式｜T 形式（已复算）｜校核结论（共振／非共振）｜该用的解｜定性修正｜不推出的项｜依据页`

表下固定三行：

- **公式状态**：全部 `〔公式待核〕`；p39 的周期式不采用。
- **不推出的项**：放大倍数、共振峰值、相位差、半功率带宽、瞬态衰减时间。
- **依据页**：p26、p30–p32、p38–p39。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **在激振频率等于固有频率处直接代振幅公式**：该式在此点没有意义，分母为零；共振必须改用幅值随时间的特解（ce13）。程序里在这一点出现溢出或异常大数，正是这个重合的信号，不是数值问题。
2. **把「振幅无穷大」当真实结论**：这个结论只在无阻尼下成立；实际系统有阻尼，幅值有限但仍大（`ce14`）。本章连「有限到多少」都给不出。
3. **把负振幅当算错、或忽略反相**：频率超过固有频率后振幅为负，负号表示与激振力反向；取绝对值可以，相位必须一起报（ce12）。
4. **在临界或过阻尼档谈共振与周期**：这两档运动不再往复，没有周期、没有共振峰（ce11）。
5. **把含瞬态项的响应当长期稳态**：本章的解里自由振动项在无阻尼模型下永不衰减，真实结构则很快衰减掉；本章因缺有阻尼受迫，连衰减时间都给不出（`ce25`）。
6. **无条件写「有阻尼周期等于无阻尼周期」**：本章把这条近似与「阻尼使周期变长」并列却没有门槛（矛盾 C8，`ce10`）。

**H2 — 用前必须声明**

1. **阻尼状态**：本卡的全部定量式子都在无阻尼下成立；有阻尼时只能给固有频率与定性结论。
2. **激振力形式**：只认简谐；移动、随机、冲击一律出界。
3. **坐标原点**：取静平衡处才允许不计重力（`ce08`）。
4. **公式状态与已知符号错**：本卡所有式子 `〔公式待核〕`。另有三处**确切损坏**必须点出：`(2-71)` 把静变形写成「刚度除以固有频率平方」，按量纲该式等于质量而不是静变形（`cb29`）；`(2-74)` 共振解前面少了一个负号，与 `(2-73)` 连读即可判定（`cb30`）；`2-64` 整式缺失，导致 `h` 与固有频率平方的定义式没有来历（`cb19`、`g33`）。凡用受迫段的式子，先补这三处再落笔。
5. **相位字母**：`(2-67)` 把自由振动的初相角写成与激振力初相角同名的字母（`cb31`），引用时须分开。
6. **周期式口径**：本章 p39 的周期式与 p26 的周期式互斥（矛盾 C1），只认「二π 除以角频率」。
