# ch4-dynamic-static-four-metrics — 动/静四指标对照组与它的边界；88% 的口径

> **卡位**：第 8 张 / 共 10｜**重要性**：critical
> **挂靠 verified**：f24、P20、P18
> **B 段随卡**：B65（高危）、B66（中）；术语侧 g09；禁令侧 f25、f26
> **页**：PDF p91–p93，印刷 p82–p84
> **引式纪律**：凡引式一律带〔公式待核〕；4.3 的式子只按节 + 页引。本卡引了算例的数，故六缺必须同列（见 I.4）。
> **一句话**：能动/静成对比较的只有四项，两个拉应力没有对照；那个 88% 是两个深度的位移相除、随截断深度变，既不是按层分解的份额，也不能反推处治效果。

## R — 原文论点（转述，非摘录）

算例给了两套数：移动荷载下的，和同一模型按静力另算的。能把两套摆在一起成对比较的只有四项——路表竖向位移、面层横向压应力、面层水平压应力、面层最大剪应力。作者据此说各层指标都小于静力值。另有两个拉应力（基层底横向、路表水平）没有静力对照，却被那句概括一并收了进去。位移那一段还给出一个比例：土基顶面位移除以路表位移，约得 88%。这个数是两个深度的同刻位移相除，随底面截断深度走；它既不是按层分解出来的份额，也不能反推处治效果。全章只有两个位移值，没有沿径向铺开的一串点，所以它也不是弯沉盆。车速那一段另有方向性表述：升速则弯沉与剪应力降，某一档降幅最大，之后趋稳——但承载这两条结论的两张图在源文件里没有图片。（PDF p91–p93，印刷 p82–p84）

## I — 判据骨架

### I.1 四指标成对相减：一项一对，不许跨项

输入：同一模型的动、静两套值。

判据：四项逐一成对相减——位移比位移、压应力比压应力、剪应力比剪应力。跨项比（拿压应力比位移）没有意义。

输出：四个比值。本阶段由两个转录值算得 −8.7%、−30.9%、−20.0%、−10.8%（依次为最大剪、横向压、水平压、路表位移），原文只写"小于"。

纪律：四个数由转录值算出，不是原文给的；不得推广成"动载比静载小一至三成"这类通则。

### I.2 概括句只能覆盖有对照的项

判据：一句概括性结论，先数它覆盖的指标里有几项同时给了动、静两套数。

本算例的实况：四项有对照；两个拉应力（基层底 22.91 kPa、路表 69.67 kPa）没有。而且它们是拉应力，与压应力比大小本来不是一回事。

输出：一张两栏清单——"有对照／无对照"。无对照项必须单列，并注明"本章未给静力对照"。

### I.3 那个 88% 的口径：三问

1. 分子与分母是不是两个深度的同刻位移？（本章是：土基顶面与路表）
2. 有没有按层分解？（没有）
3. 这个数在什么模型里有定义？（底面全约束、土基厚度由总高减三层得到的那个模型）

三问的答案决定它只能写成一句话：**两个位移相除得 88%，随截断深度变**。

写成"某层贡献占 88%"是换了一个定义；写成"处治某层能减 88%"是又跨一步。两句都不许出现。

输出：一句带模型条件的话 + 一句"不是分解"。本章没有做层间分解，所以谈贡献只能先补一套分解方法，而本章没有。

### I.4 六缺（本卡引了算例的数，必须同列）

1. 时间步；
2. Newmark 的两个积分参数；
3. 网格尺寸；
4. 荷载起始坐标；
5. 前两阶频率的数值；
6. 阻尼比的口径。

六项本章都没给。判据：任何出现七个数之一（0.66、0.58、0.38、0.44、0.21、22.91、69.67）的段落，都要在同一段里带这六项；带不了，就把数删掉。

### I.5 这条结论的适用面（四条，全中才成立）

1. 那一种结构（四层复合式基层）；
2. 那一个车速；
3. 那一种荷载图形（矩形轮迹 + 水平力）；
4. 那四条假定（常模量、界面不滑不脱、底面钉死、线弹性小变形）。

四条里任何一条换了，四个比值都要重算。

### I.6 车速那一段只能当作者口述

升速则弯沉与剪应力降、某一档降幅最大、之后趋稳——这三句只有文字，承载它的两张图在源文件里没有图片。判据：凡"由图可见"的口气，一律改写成"作者口述，图形不可复核"；也不得把"约为其它区间的三倍"写成可计算的说法。

## A1 — 演练（合成场景，零数值结果）

**【合成演练，非书中案例】**

场景：一份报告写"移动荷载下各指标均小于静载，降幅一至三成，故可用静载代替"。

走哪支：

① 先数它覆盖的指标：只有四项有对照，两个拉应力没有 → 概括越界，停。
② 问它有没有把"小于"写成"小一至三成"：四个比值是本阶段算的，原文只写小于 → 不许当作原文结论，停。
③ 问结构、车速、荷载图形是不是同一个：换了任何一个，四个比值重算 → 停在这一步。
④ 若它用那个位移比推处治效果：三问口径 → 分子分母是两个深度的同刻位移、没有按层分解、随截断深度变 → 停。
⑤ 若它引车速那两句并用"由图可见"的口气：改成"作者口述"再谈。

停判点：第一步（概括越界）与第四步（位移比换成贡献率）是硬停——前者让整句结论作废，后者让因果链断掉。

缺什么：其它结构、其它车速的对照；两个拉应力的静力值；六缺里的任何一项；以及一整套按层分解的方法（本章没有）。

## A2 — 触发场景（用户口吻）

1. 移动荷载和静载算出来的响应到底差多少，能不能用静载代替。
2. 报告说"各指标均小于静力值"，我想知道这句覆盖了哪几项。
3. 有人拿"某层占弯沉多少"去论证处治该层有效，这个推理成不成立。
4. 我只有一个位移比，能不能反推各层模量。
5. 车速从低档提到高档，弯沉和层底拉应力怎么变，本章有没有可复核的图。
6. 两个拉应力没有静力对照，那它们能不能直接跟压应力比大小。

## E — 执行步骤

**输入契约**：

- 同一模型的动、静两套值（缺静力值就没有对照）；
- 每项指标的定义（位移、压应力、拉应力、剪应力不能混）；
- 结构、车速、荷载图形、四条假定（用来划适用面）；
- 那个位移比的分子分母各自是什么（不问清不许引用）。

**步骤**：

1. 分类：把七个数分成"有对照"与"无对照"两栏。
2. 成对相减：四项逐一，写出比值；标明"本阶段由转录值算出"。
3. 写适用面四条：结构、车速、荷载图形、假定。
4. 处理那个比例：按 I.3 三问写口径，只写成"两个位移相除、随截断深度变"。
5. 处理概括句：把两个无对照的拉应力单列，注明"无静力对照"。
6. 处理车速段：标"作者口述，图形不可复核"。
7. 六缺：凡出现七个数之一的段落，同段带六项。
8. 交付：四比值 + 两栏清单 + 口径声明 + 适用面。

**交付物**：一份只覆盖有对照项的对照表 + 一句口径正确的话 + 六缺清单。

## B — 边界

- **B65（高危）· 那个比例是模型内的位移比，不是材料性质。** 土基顶面位移除以路表位移得 87.9%；它是四米截断深度的函数——土基厚度本身就是"总高减三层"剩下的那一段。换成半空间口径（位移只在无穷远归零），这个数没有定义。处理：引它必须连"底面全约束、土基三米二四"一起写；**不得改写成某一层的贡献率，也不得改写成"处治某层能减多少"**。本卡只允许它出现为"两个位移相除得 88%，随截断深度变"。验证文档另有一条更严的口径：连"在这个模型里这个份额成立"这种读法都不得进卡——本卡按它执行，只保留"相除"与"随截断深度变"两句，不写"份额"。**这是红线 1 的落点。**
- **B66（中）· "各层指标都小于静力值"覆盖了没有对照项。** 真正有静力对照的只有四项；两个拉应力没有，却被这句概括一并收进去；而且拉应力与压应力比大小本来不是一回事。处理：概括句只能覆盖有对照的那几项；拉应力单独列，单独说明"无对照"。
- **禁令侧**：f25（读应力极值）与 f26（扫车速）都判 needs_review——f25 卡在"同一层表面同时出现压与拉、作者没给控制准则"，f26 卡在两张关键图没有图片。处理：这两条只作禁令与口述登记，不作依据；不给出"哪一项控制设计"的结论。
- **术语侧**：g09 只作词条登记，不作判据（它正是那个比例的术语侧载体）。
- **与别章的界**：弯沉盆反算、层间滑移、模量随频率取值都不在本章；本章只有两个位移值，没有盆形（见卡 10 第 2 条）。
- **六缺**：本卡已按 I.4 列全六项；引任何一个算例的数，都要连着它们一起写。
