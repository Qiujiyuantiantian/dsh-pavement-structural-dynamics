## R — 原文论点（转述，非摘录）

这一章通篇讲板搁在弹性地基上的力学，却挂在刚性路面的标题下。作者没有写接缝、没有写传荷、没有写板底脱空；界面一律按完全贴合处理，接触压力永远等于刚度乘位移。正文也没有给任何一个数：板厚、模量、泊松比、密度、基床系数、剪切参数、层厚、车速、轮压，全是符号。板在行进方向是无限长的条带，横向两侧简支，解域里没有第二块板，也没有自由边。于是板角与板边的荷位在这套几何里不存在，本章实际只有板中一档。作者给的位移，是界面处处贴合这个前提下解出来的量，与现场量到的弯沉不是同一个东西。全章十张图没有一张带图像内容，也没有一张带刻度。

（见 p95–p111，全章；词频与图形状态见 `coverage-audit.md`）

## I — 判据骨架

### I.1 三条必问（审别人报告时，先问这三条）

| # | 必问 | 若答「否」，意味着 | 本章的默认（作者未写进题设） |
|---|---|---|---|
| 1 | **无限长条带？** | 有限板却引本章闭式解 → 几何错配；有横缝、自由端 → 解域里没有 | 行进方向两端位移与应力衰减到零 → 无限长 |
| 2 | **界面不脱开？** | 有脱空、脱开、受拉截断 → 本章的接触关系表达不了这个状态 | 处处贴合、单向线性、无反力截断 |
| 3 | **无耗能？** | 要阻尼、蠕变、滞回 → 本章零供给 | 三套求解路线用的地基都不带耗能项 |

> **用法**：三条问完，任何一条答「否」而报告仍挂本章名，就是误用。误用不会报错，只会给出一个看着合理的数。

### I.2 三条不能问（问的是不存在的对象）

| 不能问 | 词层证据 | 几何层证据 | 界面层证据 | 能说的话 |
|---|---|---|---|---|
| 接缝、传荷能力 | 「接缝」「传荷」各 0 次 | 无限长条带、无横缝、无自由端 → 没有第二块板 | 无反力截断、无接缝单元 | 只能写「本章不处理」 |
| 板底脱空 | 「脱空」0 次 | 同上，解域里没有「局部失去支撑」的几何 | 反力＝刚度×位移，永远是单值线性，没有受拉截断 | 只能写「不能由本章判脱空」 |
| 拿算例对表 | 0 个案例条目 | 0 张表 | 十张图全无图像、无一有刻度 | 只能写「没有可比对的答案」 |

> **三层证据互相独立，任一条就足以判死。** 不是「本章讲得浅」，是模型里没有这个对象。

### I.3 为什么「从弯沉看脱空」在符号层就堵死

1. 本章的位移 $w$ 是在「界面处处贴合」这个前提下解出来的。
2. 现场量到的弯沉里包含界面脱开、层间滑移与基层压缩。
3. 两者之差，在本章内无法拆开——既不能归给脱空，也不能归给模型误差。
4. 所以拿 $w$ 去对实测弯沉，得到的差值没有归属；「差值大就是脱空」这一步没有依据（`g15`）。

### I.4 零数值与三个不可外推的数

全章正则扫描：力、应力、尺寸、速度、频率各类单位零命中；表 0 张、算例 0 个、带刻度的图 0 张。

| 数 | 页 | 它是什么 | 为什么不能当工程取值 |
|---|---|---|---|
| $\pi^2/12$ | p101 | 剪切修正因子的取值 | 未说对应何种边条件与振型；有限元那节又不用它（`g18`） |
| $13\rho b/16\gamma$ | p107 | 附加质量的一个分数 | 分母里两个符号全章无定义；密度也没说指土还是板（`g31`） |
| $1/4$ | p109 | 单元面积摊给链杆的比例 | 离散约定，不是实测值；无收敛性说明（`A13`） |

> 结论：任何要挂在本章名下的参数值，都必须写明另找的出处（`p13`）。

### I.5 荷位（`A09`）

板角是两条自由边的交点，板边是一条自由边。本章几何里两类边都不存在——只有两侧简支与两端无穷远。所以本章实际只有**板中**一档荷位；临界荷位结论不得由本章给出。

## A1 — 演练（合成场景，0 个数值结果）

【合成演练，非书中案例】本章 0 个算例、0 个工程取值；下面四段给「一份报告或一句话」，输出「能不能挂本章名／误用在哪一条」，**不出任何数值**。

**演练一（三问全不过）**
输入：一份「板—地基动力响应」报告，声称用本章解析解算了一块有限尺寸的板、考虑了板底脱空、并配了地基阻尼比。
→ 判：三问逐条——有限板 ≠ 无限长；脱空 ≠ 处处贴合；阻尼 ≠ 无耗能。
→ 输出：**误用**——三条各给证据；结论不能挂「刚性路面」名下，只能当「板—地基弹性体系的某解」。
→ 不输出：任何「修正后」的结论或数字。

**演练二（接缝传荷）**
输入：「这份分析算了接缝传荷对动力响应的影响，依据是本章。」
→ 判：词层 0 次；几何层没有第二块板；界面层没有反力截断。
→ 输出：**不能答**——三层证据任一条即判死；本章只能作背景。
→ 不输出：任何传荷系数或两侧挠度差。

**演练三（算例对表）**
输入：「我算出来想跟书上对一下。」
→ 判：0 个案例条目、0 张表、十张图无图像无刻度。
→ 输出：**没有可比对的答案**——任何数字都不能靠本章校核；校核须另找算例或实测。
→ 不输出：任何「书中值」。

**演练四（零数值）**

→ 输出：**停**——每个值另找出处并写明；不能挂本章名。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 待审的对象（一份报告／一句话／一个结论） | 文本 | 必需 | 缺 → 先要原文，不凭印象判 |
| 板的几何（无限长？有横缝、自由端、第二块板？） | 三元组 | 必需 | 缺 → 判「未声明」，按误用处理 |
| 界面条件（贴合／允许脱开／有受拉截断？） | 枚举 | 必需 | 缺 → 判「未声明」 |
| 是否有耗能、阻尼、蠕变 | 布尔 | 必需 | 缺 → 判「未声明」 |
| 要引的参数值及其出处 | 表 | 条件必需 | 缺出处 → 停（`p13`） |
| 荷位（板中／板边／板角） | 枚举 | 条件必需 | 非板中 → 停（`A09`） |
| 是否要拿算例校核 | 布尔 | 条件必需 | 为真 → 判「没有可比对的答案」 |

**步骤**

1. **先过三问**：无限长？界面贴合？无耗能？逐条要对方给出声明，不给声明就按默认处理并写明。
2. **再过三不能问**：接缝传荷、板底脱空、算例对表；命中即判「对象不存在」。
3. **查符号口径**：对方说的 $w$ 是本章的解还是实测弯沉；两者不能直接比。
4. **查数值出处**：每一个参数值都要有章外来源；没有就停。
5. **查荷位**：板角、板边一律停；本章只有板中。
6. **裁措辞**：允许写「在无限长条带、界面贴合、无耗能的前提下」；不允许写「按本章可判接缝／脱空」。
7. **出判决**：可挂名／须降级／误用，附证据页。

**停判点**

1. 对方答不上三问中的任一条 → 不判「可用」，只判「未声明」。
2. 题面出现接缝、传荷、脱空 → 停（`p12`）。
3. 题面要算例或书中值 → 停（0 案例）。
4. 题面要参数取值 → 停（0 个，`p13`）。
5. 题面要板角、板边临界荷位 → 停（`A09`）。
6. 题面要阻尼比、时程 → 停或转 ch4（`g20`、`g33`）。

**输出契约**——字段固定：

`三问｜三不能问命中否｜w 的口径｜数值出处｜荷位｜判决（可挂名／降级／误用）｜依据页`

表下固定三行：
- **公式状态**：本卡不复用式子。
- **数值状态**：本章 0 个工程取值；三个原文里的数不可外推。
- **依据页**：p95–p111。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **写「按本章可判接缝传荷」**：词层 0 次、几何层无第二块板、界面层无反力截断（`p12`）。
2. **写「按本章可从弯沉判脱空」**：本章的位移是贴合前提下的解，不是实测弯沉；差值无法在章内拆开（`g15`）。
3. **把本章当水泥混凝土路面分析**：章名承诺材料，内容与材料无关；「刚性路面」只是标签（`g01`）。换任何一种板状材料，本章一字不改。
4. **给板厚、模量、基床系数、车速取值**：本章 0 个；三个原文里的数不可外推（`p13`）。
5. **配阻尼比、要蠕变柔量**：「阻尼」全章只出现一次，还是「无阻尼自由振动」（`g20`）；带黏性系数的式子缺时间导数，此后弃用（`B19`）。
6. **要时程、逐步积分**：本章自己把时间积分推给第 4 章第 3 节（`g33`）；不得据此说本章会做时程。
7. **说本章能处理层状体系、乃至黏弹性层状体系**：只有一句话、无推导、无层间条件（`g37`）。
8. **混用符号族**：$k$、$K$、$\kappa$ 一族与 $E$、$\mu$ 一族，同一个字母多个所指（`g38`、`g39`、`B25`）；插值阵有九个名字（`B24`）。
9. **把弹性矩阵当本章结论**：与 ch2、ch4 是同一个各向同性矩阵，指回 ch2；本章只记一句「剪切对角元有转录问题」（`B20`）。
10. **拿板角、板边临界荷位结论**：本章只有板中一档（`A09`）。
