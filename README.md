# dsh-pavement-structural-dynamics

《路面结构动力学》（8 章 / 204 页）的蒸馏插件：**59 张能力卡**，一个入口。

## 这是什么

一本**判据手册，不是计算器**。它回答的是：

- 这套参数能不能进动力模型？
- 这份分析报告该怎么审？
- 这条计算链缺哪几件？
- 哪些式子抄走就错、哪些数不能互相引用？

它**不回答**：给我一个弯沉值、一个模量、一个疲劳寿命、一个脱空尺寸。

## 为什么这样组织

八章里有四章名不副实：

| 章 | 章名 | 实际内容 |
|---|---|---|
| ch2 | 结构动力学基础 | 纯经典力学——10,456 汉字里「路面」只出现 **2 次** |
| ch5 | 刚性路面力学响应 | 板 + 弹性地基——接缝／传荷／脱空**各 0 次**，正文一个物理单位都没有 |
| ch7 | 疲劳与断裂 | 只有「断裂」，没有「疲劳寿命」——无 S-N、无 N_f、无 K(a) |
| ch8 | 钢桥面铺装动力响应 | 与 ch4 的沥青路面是两套体系，**数字不可互引** |

按章名去查会得到「书上写了」的错误印象。所以 `SKILL.md` 第二节是章名对照表，不是卡片。
